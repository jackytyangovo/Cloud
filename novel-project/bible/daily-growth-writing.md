# 日常成长期写作规范（✓ 用户确认）

> **适用**：异世界长篇 **前 1–2 卷 / 前 ~50 章** 的「日常 · 养成 · 治愈」阶段。  
> **考验**：写好了 → 治愈、温馨、陪伴感；写砸了 → 水字数、流水账、弃坑。  
> **宏观衔接**：见 [`narrative-structure.md`](narrative-structure.md)（1–3–9 埋线、两拐点）。  
> **本作**：**卷一**（序章–第二十九章）为主力日常成长期；**6–7 岁**、领地 + 灰港，见下文 **「卷一映射」**。

---

## 一、要注意什么（4 个黄金守则）

### 1. 微型升级流 — 积攒家底的快乐

日常 **≠ 原地踏步**。读者要的是生存养成感：**从零一点点攒家底**，物质生活肉眼可见变好 → 满足感与陪伴感。

| 阶段（示例） | 写法 |
|--------------|------|
| 第 1–5 章 | 漏雨破屋、又硬又苦的黑面包 |
| 第 10 章 | 现代知识 → 过滤水/调味 → 第一口热乎好饭 |
| 第 20 章 | 卖低级药水赚第一笔钱 → 破屋变带火炉的砖房 |

**撰写要点**：每几章让读者感到 **生活级微小升级**（住处、饮食、工具、技能熟练度、人际信任、小金库）。

### 2. 冲突降维 — 鸡毛蒜皮，不是生死存亡

日常期 **不要** 魔王杀手；**不能** 没冲突。把打杀换成 **找麻烦 / 解难关**。

| 类型 | 示例 | 日常期 |
|------|------|--------|
| **生死**（此期不写） | 黑衣人夜袭、拼死抵抗 | ✗ |
| **生活**（此期最爱） | 铁匠铺砸场子；魔兽幼崽拱了邻居菜园要赔偿 | ✓ |

**效果**：有热闹、有张力，**不破坏** 轻松温馨基调。

### 3. 情绪锚点 — NPC 人情味

写日常是为了给后期冒险/救世 **赋予意义**。读者对「家」无感 → 后期毁家只会冷漠翻页。

**写法**：每个日常 NPC 至少一个 **萌点 / 温情细节**。

- 傲娇老板娘嘴嫌体正直，夜里留最肥烤肉
- 吹牛老头偷偷用养老金帮主角买练习耗材

**效果**：人物写暖写活 → 读者把主角的家当成自己的家。

### 4. 设定融入吃喝拉撒 — 禁止设定说明书

**不要** 整章解释魔法等级、货币换算。

| 错误 | 正确 |
|------|------|
| 「货币分为金币银币，1 金币 = 100 银币……」 | 买肉包掏出森林捡的银币，老板瞪眼：「够买我一车包子，找不开！」→ 货币价值 + 微爽 |

**撰写要点**：经 **「我」的日常体验** 漏设定；符合 `style-guide.md` **常识/高级知识分级**。

## 二、千万不要（4 条生死红线）

### 1. 不要打卡流水账

**红线**：早上六点起床 → 洗脸 → 早饭 → 练剑两小时 → 和 NPC 两句 → 睡觉。

**规则**：凡对 **推进感情、展示新设定、展示实力提升** 无帮助的琐事，**一笔带过**。

**改法**：「如此这般，平静的半个月过去了。」→ 切到 **这一天发生了不一样的有趣事**。

> 本作：可用 **工序 montage**（「第 N 次冥想」「又过去三天」），但须接 **具体事件**，忌空转（见 `style-reference.md` §11–12）。

### 2. 不要过早引入不可抗力致郁

读者奔 **轻松、种田、养成** 而来。

**红线**：日常阶段 **血腥屠村**、最讨喜小萝莉 NPC 被恶霸打死/卖掉。

**后果**：剧毒/喂屎 → 画风撕裂 → 休闲读者愤怒弃坑。

> **本作硬约束**：卷一 **温馨为主**；**不写** 灭领、屠村、幼主角亲身 R18；目睹 R18 须 outline 标【R18·目睹】且服务剧情。

### 3. 不要无敌且无事可做

满级大佬体验生活，忌 **连续十章搬凳晒太阳**。

**红线**：「无敌」可以，**不能无欲无求**。

**改法**：给 **日常偏执的小追求**（例：实力毁天灭地，执念却是种出全异世界最甜西瓜 → 与虫灾、偷瓜兽斗法）。

> **本作**：莉莉娅 **非满级**；日常执念可来自 **身份（男转女/装乖）、魔法启蒙、家族期待 #2、隐藏净章** 等 **可见小目标**。

### 4. 不要新手村圣母或怨妇

| 红线 | 说明 |
|------|------|
| **怨妇** | 天天「呜呜想回地球、没 WIFI」（偶尔吐槽可，天天烦） |
| **圣母** | 谁占便宜都笑呵呵忍（可善良，**须有底线与反击**） |

**正派人设**：随遇而安、乐观、有点小聪明；**不主动惹事，不怕事，吃不得不懂事的亏**。

> **本作**：前世对照 **须有具体落点**；忌空泛「不像前世」。装乖藏觉醒 = 社交伪装，非怨妇。

## 三、日常章自查公式（写每章必问）

| # | 问题 | 合格标准 |
|---|------|----------|
| 1 | 主角有没有在 **某个小细节** 上变强/变富/变手熟？ | **成长的正反馈** |
| 2 | 有没有让读者 **会心一笑** 或觉得 **某配角可爱** 的瞬间？ | **情绪价值** |
| 3 | 核心事件是不是主角 **主动** 做的，或为解决 **有趣的生活麻烦**？ | **拒绝无聊流水账** |

> 三问 **至少满足其二**；最好三条全中。可与 `style-guide.md` **章内小高潮（约每 1000 字）** 并用。

## 四、本作卷一映射（莱恩菲尔 · 6–7 岁）

> 小贵族 **非** 破屋黑面包开局；「微型升级」须 **贴合身份**，勿硬套贫民种田模板。

| 黄金守则 | 卷一落地（示例） |
|----------|------------------|
| **微型升级** | 冥想/感知进步；赛温课 **工序感**；与艾娜/洛伦默契；赴灰港 **见世面**；净章后 **压分/隐藏** 的小熟练；领地认路、带表弟出栅 |
| **生活冲突** | 孩童摩擦、土系期望 #2、轻微社交冷落（夜聚起）、抢窗/挤车、芬恩式捣乱、身体不便（裙、幼力）—— **非** 生死战 |
| **情绪锚点** | 洛伦话少护女、艾娜嘴快、盖伦敦厚、米拉照孩、赛温师生、莉安娜侧室空位、芬恩/埃里克对照 |
| **设定融入** | 觉醒/净阶/维洛 **耳闻**；灰港市集、仪场礼序；**【附】** 仅首次；禁百科段 |

| 红线 | 卷一边界 |
|------|----------|
| 流水账 | 第三–四幕 **课表 montage** 须接 **具体章事件** |
| 致郁 | **禁止** 灭领、屠村、绑架幼主；摩擦 **宜小不宜大** |
| 无事可做 | 每章仍有 **觉醒倒计时、家族线、身份线** 小目标 |
| 圣母怨妇 | 装乖莉莉娅；**#2 压力** 时洛伦护短，非主角烂好人 |
