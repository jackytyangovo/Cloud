# 宏观叙事结构：日常 · 冒险 · 危机（✓ 用户确认）

> **类型参照**：《无职转生》《Re:从零开始的异世界生活》、经典 JRPG 主线。  
> **目的**：避免三阶段 **断层感**（日常开心 → 突然沉重冒险/救世 → 读者觉「画风突变」弃书）。  
> **硬规则**：日常、冒险、危机 **不是三块互不相干的 U 盘**；须 **埋线、收束、动机同源**。

---

## 一、整体结构：埋线的「1–3–9」规律

| 阶段 | 代号 | 功能 | 与本作关系（滚动） |
|------|------|------|-------------------|
| **日常生活期** | **1** | 建立羁绊、文化碰撞、读者情感投资 | **卷一** 序章–第四幕：领地/灰港 **生活记录**、家族、觉醒前后 |
| **冒险成长期** | **3** | 离开舒适圈、可见成长、小队化学反应 | **卷二起** 学院/旅途；卷一末–卷二初可 **短冒险**（赴城、仪场）作过渡 |
| **危机收束期** | **9** | 终局之战、善缘全线开花、大团圆收束 | **中期以后**（用户定）；**不预设** 魔王/邪神名 |

### 1 · 日常生活期（埋线）

- 主角可以天天在村里/领地里过日子、和亲人朋友相处。
- **背景须偶尔有一句传闻**（当时不影响日常，却是中后期引线），例如：
  - 「听说北方最近在抓壮丁」
  - 「森林里的魔兽好像变多了」
  - 「河域牌照查得紧」
- **本作卷一示例**：ambient 维洛教、觉醒名册、土系期望 vs 光系、盖伦城脉、#5/#7/#9 等 **轻量伏笔**（见 `outline.md` 伏笔表）——**不写** 终局 Boss、**不** 突然灭村。  
- **日常成长期 4要4不要、章自查公式** → [`daily-growth-writing.md`](daily-growth-writing.md)（✓ 用户确认）。

### 3 · 中期冒险期（动机）

- 冒险动力须来自对日常的 **守护** 或 **被迫打破**。
- 日常里最珍视的人、物、平静生活遭外部威胁 → 逼主角走出舒适圈。
- **本作**：卷一 **仪场/净章** 是「人生节点」而非无脑刷怪；卷二 **Writ / 学院** 是「离开领地的主动+家族抉择」，非雷劈村子。

### 9 · 后期危机期（同源）

- 终极大 antagonist **不能凭空蹦出**。
- 往往是中期 **家园受创/世界异变** 的始作俑者；主角不是在盲目救世，而是在 **报仇** 或 **夺回属于自己的生活**。
- **本作**：长线走 **八线脉络**（`outline.md`「全文叙事脉络」），世界真相线 **慢热**，定稿后再填具体。

## 二、三阶段实操规律

### 1. 前期 · 日常生活 —「日常中的不寻常」

| 要点 | 说明 |
|------|------|
| **忌** | 流水账（只写吃饭睡觉） |
| **规律** | **文化/认知碰撞** — 现代人或特殊身份视角，把异世界普通过得 **有趣** |
| **直观做法** | 别只写「吃饭」；写用魔法+当地食材 **复刻现代味**，把土著馋懵（本作须 **6 岁尺度**、符合 `style-guide.md`） |
| **关键任务** | **疯狂刷 NPC 好感 / 立羁绊** — 家人、朋友、邻居、宠物越温馨，后期遇险时读者与主角 **痛苦面具** 越稳、动力越足 |
| **本作** | 卷一 **温馨为主、偶有摩擦**；#2 土系期望、#7 盖伦城脉、#9 容貌、洛伦/赛温师生 — 均服务羁绊 |

### 2. 中期 · 冒险成长 —「公路片」

| 要点 | 说明 |
|------|------|
| **忌** | 无脑刷怪 |
| **规律** | **一站一风景，一站一成长** |
| **成长须可见** | 技能 **或** 心智（离开前不敢杀鸡 → 被骗光钱学会防人 → 见同伴受伤学会杀伐/新技能） |
| **核心看点** | **小队化学反应** — 性格迥异的人吵架、分赃、互相挡刀 |
| **本作** | 卷二 **学院同窗**；卷一 **盖伦府/灰港逛街/路途** 可作「短站」；战力须符合净阶≠即战力 |

### 3. 后期 · 解决危机 —「收束与大团圆」

| 要点 | 说明 |
|------|------|
| **忌** | 机械降神、主角单人救世 |
| **规律** | **人人为你，你为人人** — 战线收束 |
| **直观做法** | 中期去过的国家、救过的配角、前期新手村铁匠，**终局皆发挥作用**；绝境时小国军开拔、老法师燃命开路 — **善缘开花结果** |
| **本作** | 盖伦城脉、教会线、家族线 **中期以后** 收束；卷一 **不写** |

## 三、两个丝滑过渡转折点（避坑）

### 🛑 拐点 A：日常 → 冒险（第一拐点）

| | 内容 |
|---|------|
| **错误** | 村里过好好的，突然一道雷劈村、主角流浪（**强行发便当**） |
| **规律** | **主动 + 被动结合** |
| **做法** | 先为 **日常里的小危机** 主动接任务（给妹妹买药、村子要交税）→ 路上/远方时村子被反派 **顺手** 所毁 → 主观目标（买药）+ 客观仇恨（复仇）**双动机** |
| **本作** | 卷一：**觉醒名册 / 赴灰港 / 仪场** 为 **家族已知节点**（序章耳闻、第一章启程）；**非** 雷劈灭领。卷二：**Writ** 为 **7 岁主动抉择**，非被动流浪 |

### 🛑 拐点 B：冒险 → 危机（第二拐点）

| | 内容 |
|---|------|
| **错误** | 冒险正嗨，突然「你是预言救世主，去杀魔王吧」（主角：？读者：俗） |
| **规律** | **私人恩怨 → 世界危机** |
| **做法** | 一路追查杀同伴的凶手/神秘组织 → 连根拔起时发现只是冰山一角 → 终极计划献祭大陆 → 为 **自保+保护同伴** 站救世第一线 |
| **本作** | 教会/世界真相/#6 神圣隐线 **慢热**；**禁止** 卷一让「我」之口点破救世主预言 |

## 四、撰写自检（防断层）

写 **新卷/新幕/大事件** 前对照：

- [ ] 本段日常里是否已有 **1–2 句背景引线**（不影响当下，可后收）？
- [ ] 冒险启动是否绑在 **已建立的羁绊或具体目标** 上（非作者硬切）？
- [ ] 危机 antagonist 是否能在 **中期/前期** 找到影子或因果？
- [ ] 日常章是否有 **认知碰撞/不寻常**（非流水账）？
- [ ] 冒险章是否有 **可见成长 + 人物互动**（非纯战斗报告）？
- [ ] 终局设计是否预留 **配角/势力回报** 位（非主角单打）？
- [ ] 两拐点是否避开 **雷劈村、天降预言** 式生硬过渡？
