## 一、时代与基调

- **时代**：中世纪奇幻
- **人类主导**：文明、人口、政治以人类为核心
- **天赋决定阶级天花板**：越强越高；贵族必为觉醒者
- **人类成年**：**14 岁**（法律与社会公认成年）
- **订婚**：社会上**最早 12 岁**即可订婚（多为贵族联姻、家族安排；成婚礼仪通常在成年后）

## 二、力量体系

### 2.1 魔法总览

```
魔法
├── 元素魔法（七种基础元素）
│   ├── 风 / 火 / 水 / 土 / 电 / 光 / 暗
│   └── 衍生元素（由基础元素派生，非独立天赋）
│       ├── 冰 ← 水元素衍生
│       ├── 生命 ← 光元素衍生
│       └── 死灵 ← 暗元素衍生
├── 变种魔法（非元素系）
│   ├── 精神魔法（读心、暗示、幻术、精神冲击等）
│   └── 空间魔法（含封印；需特殊变异天赋）
└── 禁术/不存在
    └── 时间魔法 —— 本世界不存在
```

### 2.2 天赋觉醒与社会结构

**觉醒比例**（光/暗/电与战斗级均以「所有觉醒者」为基数）：

- 约 **90%** 无法觉醒魔法天赋
- 约 **10%** 能觉醒
- 其中 **99%** 极弱，仅生活用途，无战斗价值
- **战斗级**：觉醒者中 **1%**（≈ 总人口 0.1%）
- **光 / 暗 / 电**：各自约占觉醒者 **1%**

**人类天赋觉醒制度**：

- **六岁时**统一举行觉醒仪式
- 检测结果：**属性** + **净阶**
- 贵族与平民同一制度，资源与期望不同
- **仪典册**：孩童出生登记后，六岁前由家族向指定仪场**报达名册与场次**；**仪式日直赴仪场**，入城后**无需临期再登记**（序章 领地核对名册即此流程）

### 2.3 天赋净阶

> 魔法越弱杂质越多；净阶衡量纯净度与上限潜力，与元素种类正交。

| 净阶 | 名称 | 直观含义 | 大致对应 |
|------|------|----------|----------|
| 一 | **浊痕** | 杂质浓重，几乎只能生活用 | 觉醒者绝大多数 |
| 二 | **蒙纱** | 可用但混沌；光/暗/电起步净阶 | 弱觉醒 / 少见元素下限 |
| 三 | **澄纹** | 杂质可控，**战斗级门槛** | 标准战斗法师 |
| 四 | **明印** | 清晰稳定，同阶强者 | 精锐、重点培养 |
| 五 | **净章** | 高纯少杂 | **标准仪式可测上限** |
| 六 | **澈冕** | 极净 | 仪式测不出 |
| 七 | **无垢** | 理论完美 | 衍生/万里挑一；仪式测不出 |

- 标准仪式**最高测至净章**
- 光/暗/电觉醒者净阶**起步为蒙纱**

### 2.4 元素稀有度

| 层级 | 元素/天赋 | 占所有觉醒者 | 备注 |
|------|-----------|------------|------|
| 常见 | 风、火、水、土 | 战斗级主体 | 四元素主流 |
| 少见 | 光、暗、电 | 各自约 1% | |
| 极稀有 | 冰、生命、死灵、空间 | 万里挑一 | 顶层博弈筹码 |

**元素规则**：

- 每人 1–2 个主元素亲和
- 衍生须先修基础元素再专精
- **疗伤**：无「医师/医生」独立职业；以 **生命魔法** 施疗者仍是 **魔法师**（多具生命属性亲和），入 **魔法师公会**（若满足条件），**无**单独公会或职业名——见 §2.10
- 消耗魔力（MP），可冥想、魔晶、药剂恢复
- 等级框架：学徒 → 正式法师 → 高阶 → 大法师（命名可世界观化）

### 2.5 剑术与剑术天赋

**剑术 = 技能，非魔法**

- 通过训练习得（流派、招式、奥义）
- 剑术天赋觉醒 ≠ 学会剑术，而是有利于剑术成长的先天能力

**剑术天赋类型（示例）**：速度强化、力量强化、悟性强化等【随剧情补充】

**觉醒比例**（与魔法类似）：

- 90% 无法觉醒
- 10% 觉醒，其中 99% 弱化型（体魄略强，约一打二、一打三）
- 战斗级：觉醒者中 1%（以一敌十；顶尖者以一敌百）

**魔武双修**：魔法与剑术天赋相互独立，双修极稀有，资源与时间成本翻倍。

### 2.6 魔法战力成长规则（硬约束）

1. **天赋净阶决定上限，不决定即战力**
2. **高净阶概率指数级降低** → 前期数值克制
3. **年龄与修习年限不可替代** — 孩童高净阶打不过成年修习数十年者
4. **战力成长维度**：魔力强度、魔力上限（MP 池）、咒语熟练度、施法速度、战术经验

| 场景 | 允许 | 避免 |
|------|------|------|
| 莉莉娅觉醒净章 | 震惊仪式、引发关注 | 觉醒当日碾压成年人 |
| 埃里克明印 | 同龄佼佼者 | 以一敌多成年法师 |
| 洛伦澄纹 | 领地护卫战力 | 被 6 岁女儿压制 |

### 2.7 天赋与社会阶级

- 天赋越强 ≈ 地位越高
- 贵族与统治阶级**必定为觉醒者**（可弱，但必须有）
- 天赋具有遗传性；弱家族出强天赋为**罕见变异**
- 统治阶层通过联姻、资源垄断觉醒者身份

### 2.8 年龄、成年与婚约（用户确认）

| 项目 | 规定 | 备注 |
|------|------|------|
| **成年** | **14 岁** | 法律与社会公认；此前为未成年 |
| **最早订婚** | **12 岁** | 社会上已存在；贵族圈更常见 |
| **天赋觉醒** | **6 岁** | 与婚约无直接绑定，但觉醒结果影响联姻价值 |

**社会含义**：

- 贵族子女：真正订婚通常不早于 **12 岁**；**6–7 岁正文可提及**制度（大人闲谈「十二岁才订」「净章将来好说亲」），**不展开**订婚过程或「我」的婚约情节线。
- 莉莉娅（6 岁）、芬恩（5 岁）**无订婚情节**；埃里克（10 岁）距最早订婚约两年——可作背景一句。
- 光系净章将抬高其**未来**社会关注；**婚约政治/高层觊觎**留待**中期**（12 岁+ 情节），用户提及时再规划章节。
- **订婚 ≠ 成婚**：订婚多为文书与家族承诺；完婚、同居等一般在**成年后（14 岁+）**。
- 其他种族婚龄：【随剧情补充】

**与 R18 边界**：本作幼年主角无亲身 R18；目睹戏须服务剧情。**6–7 岁卷不写联姻情节发展、不写王室高层直接接触**。

### 2.9 职业公会（✓ 用户确认）

> 详述见下；灰港 **行会监护处**（Guild Wardenship）兼管**手艺行会**与部分**职业公会**城市登记。与 [`outline.md`](outline.md) 家庭教师线联动。

**总则**：

- 主大陆各主要职业皆有**公会**（**Guild**）；与纯手艺 **行会**（Craft Fellowship · 铁匠、织工、商栈等）**并行**，大城往往**同城共馆**或相邻官厅。
- **能合法挂牌授课、受 guild 仲裁保护的魔法教师**，通常须**自身天赋与教学资格**达到一定门槛；**小贵族请不起**名籍在册的名师，只能走**私交**、**野法师**或**未入会**的游历者——见卷一 **伊拉·赛温**。

**魔法师公会 · 补充**：

- **不入会**：不违法，但**无 guild 牌**；在贵族府邸**私聘**合法，**乡间**更常见；邻领可能嘴碎「野法师」「没挂籍」。

- 莱恩菲尔级采邑：**请不起**艾什福德/灰港**在册名师**（薪酬、礼金、guild 抽成）。
- 洛伦走 **家族私交**：约 **三年前** **伊拉·赛温** 过领时**遭遇魔兽**，得洛伦一家**庇护疗伤**、住领 **半月**，**欠恩在赛温** → 觉醒后洛伦修书邀约，她以 **低酬 + 食宿** 应允住领 **约半年至一年**。

### 2.10 生命魔法疗伤 · 圣息使（✓ 用户确认）

> **世俗**：会 **生命魔法** 施疗者 **仍是魔法师**，**无**单独职业名、**无**单独公会（见 §2.4）。  
> **教会**：疗伤神职称 **圣息使**；**仅教内** 培育、按立；**绝无外聘**。教会 **元素构成** 见 §5.2.0「教会与元素」。

| 维度 | 内容 |
|------|------|
| **神职名** | **圣息使** · **Vitae Envoy** |
| **性质** | **神职**（与司铎、执事、辅祭等同属教阶体系）；专司 **生息圣礼**（Vital Rite）与 **生命魔法** 施疗 |
| **教义** | **维耶洛**「**初光予生**」——**生命**为 **光** 之衍生；**圣息** = 初光所赐 **息**（生机）；**使** = 代行此恩之 **神职** |
| **职能** | 教区 **温养院**（House of Vital Warmth）或 **传教队** 中施疗、济世、辅传教 |
| **来源** | **仅** 教区/修会 **信徒** 培育；自 **光系** 神职路径中 **极少数** 再显 **生命魔法** 恩赐 → **圣息遴选** → 专学 → **按立圣息使** |
| **与魔法师公会** | 教籍为主，多数 **不挂** Arcane Guild |
| **与赛温** | **伊拉·赛温** 为世俗 **风系** 法师，**非** 教籍、**非** 圣息使 |

**教区设置（概要）**：

- 大教区 **温养院** 常驻 **圣息使**；**小堂区**（基层堂区）由上级 **轮调** 或传教队随行。
- **禁止** 外聘世俗法师充任 **圣息使**。

## 三、种族

| 种族 | 天赋倾向 | 状态 |
|------|----------|------|
| **人类** | 无特殊限制 | 主导种族 |
| **亚人**（兽人/龙人/半龙人） | 体能为主，魔法偏少 | 地位低，为奴者多；战斗级天赋可与人类平起平坐 |
| **精灵**（普通/远古/黑暗） | 魔法为主，体能弱；偏远程 | 普通精灵居北脉/中脉森林 |
| **矮人** | 偏体能；采矿冶炼锻造 | 地下聚居，位置不明；与人类无公开建交 |
| **魔族** | 【随剧情补充】 | 极北聚居 |
| **龙族** | 最高贵种族 | 人魔大战后绝迹近千年 |

### 精灵分支

- **普通精灵**：无特殊亲和；北脉、中脉麓林
- **远古精灵**：失传远古魔法；寂语山脉（Silmor Range，北脉）
- **黑暗精灵**：暗元素亲和；遭排斥，混迹野外或人类社会

### 亚人

- 半龙人 = 蜥蜴、蛇等下等龙裔，不得与龙族等同
- 整片大陆均有分布

#### 5.2.0 信仰与教会（✓ 全球唯一大宗教 · 定稿）

> **命名**：教阶专名须 **Western 原文 + 中世纪风中文**；禁止「司 / 署 / 局 / 处长」等现代或东方官僚语感（见 `WORKFLOW.md`）。  
> **范围**：**已探索世界唯一大宗教**；主大陆诸国、帝国、西平原三国皆在其下；南境部落/绿洲仅有**边缘异俗或地方灵鬼**，**不构成**与教会并列的另一套教权体系。维兰提亚帝国与三国一样向 **圣环城** 纳贡/承认教宗权威，但各自与教廷争任命权——**近期正文不写**。

**神学要点（写章可引用，勿角色长篇布道）**：

- **比照天主教之创世教义**（用户确认）：**维耶洛创世、秩序、照见灵魂** 为 **社会底层逻辑**——誓言、历法、婚丧、道德常识、节日称谓皆默认在此框架内；**写作时不必布道**，但人物 **不会** 像无教背景的现代人对生死/誓言/节日毫无概念。
- **一神论**：维耶洛独一；暗、混沌、谎言为「影幕」，非与神等格的对立神。
- **光与魔法**：教会认为**元素光**是神恩在尘世的**借形**，净阶越高越「接近初光」——**不**等于自动入教或成圣；**光系法师≠司铎**。
- **天赋觉醒**：六岁仪式为**王国户籍与魔力登记**；教会派**礼颂司铎**诵 **初光祝**（First-Light Canticle），**检测本身由世俗官/法师主持**（见第四章大纲）。
- **死与生**：承认**生命**为光之衍生（与魔法体系一致），但**死灵**为禁途；异端审判留**中期**再写。

##### 教会与元素（✓ 用户确认）

> **逻辑链**：信众奉 **初光** → 教内 **神职** 以 **光系** 为常态 → **生命** 为光之衍生 → 自光系神职中 **极少数** 显 **生命魔法** 恩赐者，按立 **圣息使**，代行 **圣息**（生机）之职。

| 项目 | 内容 |
|------|------|
| **神职** | 教会 **职位皆为神职**（司铎、执事、辅祭、**圣息使** 等）；**无** 世俗外聘 Magister 充任教职 |
| **元素主流** | 教内具魔力之 **神职者 / 修会成员**，**光系占绝对多数**——与 **维耶洛**「初光之守」教义一致；礼颂、仪典、传教核心皆围绕 **光** |
| **少数元素** | **风、水、土、火、电** 等 **可为教内神职**，但属 **少数**，多任 **辅职**（行旅、护卫、仓廪、文书等），**非** 礼颂与教义象征之核心 |
| **禁入** | **暗系**：教义视为 **影幕** 之赐，**不得入教**、**不得** 按立神职；教内 **无暗系** 成员【发现处置 → 中期】 |
| **圣息使** | **光系** 神职路径上，再显 **生命魔法**（光衍极稀恩赐）者，按立 **圣息使**；**非** 独立元素门派，而是 **初光予生** 之专职神职 |
| **与世俗** | 教外 **光系/生命系** 法师 **≠** 圣息使；**圣息使** 必 **教籍 + 按立** |

**写章提示**：勿写成「教会雇法师」；邻领请疗 → **请圣息使** / **温养院** / **等教区轮调**。

**权力制衡（常态，非理想）**：

| 层级 | 职能 | 中世纪参照 |
|------|------|------------|
| **国王** | 最高领主、司法终审、封臣效忠对象、召集议会 | 英/法王权 |
| **大贵族** | 持有采邑（领地/封地），军事义务，地方司法与征税权 | 公爵/侯爵/伯爵 |
| **议会** | 批准王国级税赋、重大法令、对外条约；代表各等级利益 | 英国议会 / 法国三级会议 |
| **城市** | 特许状（Charter）换自治权；向王庭/领主纳贡；城内职官自理日常 | 自治市 / 汉萨式商城要素 |

**与天赋/贵族规则衔接**：

- 封爵与采邑**原则上限于觉醒者**；无天赋者最多至自由民、行会首领或市议席，不得世袭贵族头衔。
- 议会**贵族院**席位随采邑与封号；**市民院**席位由特许城市选派（**城邦执政**、富商、行会长老等）。
- 天赋净阶不直接决定官职，但影响**受封可能、联姻与资源**，进而间接决定政治位置（如盖伦蒙纱让位家主、改任城职）。

#### 5.2.3 等级议会（Parliament of Estates）

每年或遇战、加税、继承危机时，由国王**召集**；三地结构相同，席次比例因国而异。

| 等级 | 名称 | Western | 组成 | 典型议题 |
|------|------|---------|------|----------|
| 第一等级 | **教士院** | Clergy | **西境总主教**、各**主教**、具席**大修道院长**（**维耶洛普世圣教**；见 `worldbuilding.md` §5.2.0） | 教产税、什一税、道德法令 |
| 第二等级 | **贵族院** | Lords Temporal | 公爵至男爵、部分骑士代表 | 兵役、封地、战争 |
| 第三等级 | **市民院** | Commons | 特许城市**城邦执政**、**市议员**、大商人与行会长老 | 关税、河运、市律、贸易 |

**运作要点**：

- **征税须议会同意**（王国级）；国王可借「紧急军饷」绕过，但损威望、易引贵族反制。
- 法案经三院或两院（教士常并入贵族院表决【可随国别微调】）辩论后，国王**批准或否决**。
- **灰谷**：农牧与冶炼厚，**市民院**中商都代表（如灰港）话语权高于雷文堡；**雷文堡**：贵族院军事领主权重更大；**卡斯尔顿**：市民院最强，与帝国贸易绑定深，独立性最弱。

#### 5.2.4 城市职官（以灰港为例 · ✓ 框架定稿）

> **命名**：官职/官厅专名须 **Western 原文 + 中世纪奇幻风中文**；禁止「司 / 署 / 局 / 司长」等东方或现代官僚用语（见 `WORKFLOW.md`）。

大城持**国王特许状**（Royal Charter）：城内日常由**城邦执政**（Burgomaster）与**市议会**（Town Council）自理；**治安官**（Sheriff）代表王权；各 **Office（官厅）** 分掌税、河运、仓廪、防务。官职为**任命 + 行会/议会举荐 + 贵族兼任**混合，非近代选举民主。
