> 卷一相关人物优先；其余随剧情追加。  
> **撰写**：语言、神态、动作、容貌描写均须 **贴合本表**；正文新增形象细节 **须同步回填** 本条。

## 人物撰写要点（✓ 用户确认）

| 原则 | 说明 |
|------|------|
| **恒定 vs 章区** | 各人物条：**恒定设定**（身份、天赋、性格底色）+ **按章区形象**（随章节/场景变化） |
| **写哪章查哪区** | 撰写 **第 N 章** 时，只取该章及之前已定的 **对应章区** 行；**勿**用后续章区状态写当前章 |
| **首次出场** | 该章区须带 **容貌或体态** 一两笔（若本章区为首次实写） |
| **言行神态** | 语言、动作、神态 **服务当前章区** 人设；用 **侧面描写** 烘托 |
| **同步** | 正文定稿的新形象/关系变化 → **回填** 该人物 **对应章区** 行；未定稿处标 `【随剧情补充】` |
| **发色 vs 发型**（✓ #97） | **发色** → **恒定设定**（相对不变）；**发型** → **按章区**（可日变/场变，**勿**写进恒定条） |
| **画像/回忆** | 已故人物可写 **很漂亮**；**不写** bible 内部分数 |

**性格与缺陷**（撰写默认，可改）：

- 前世理性、习惯用结构思维分析问题
- 现世幼女身体限制行动，易焦躁
- 男转女身份摩擦持续；对「被宠爱」既依赖又不适
- 缺陷：过度依赖前世经验，忽视孩童身体的社交规则
- **目睹 R18 / 暗黑场面**：内心**完全看懂**（**前世的我**），表面**装不懂**以隐藏觉醒、维持幼女形象
- **前世定位**：**工具性记忆**；**重点在现世新人生**，不铺前世剧情线  
- **前世对照（撰写）**：**须有具体落点**（如觉醒制度 vs 前世无魔法、男体/女体差异、具体物件）——**笼统模糊则不写**（如「不像前世」「要是以前」等空对照属废话）

**天赋规则与代价**（卷一阶段）：

- 光系净章：仪式读数震撼，但 **6 岁几乎无实战输出**；须从冥想、感知魔力起步
- 生命（隐）：中期觉醒前无自觉；觉醒后代价【随剧情补充】

**角色弧光（卷一–卷二方向）**：

- 从「我是谁」的身份混乱 → 接受「这一世的莉莉娅」作为行动主体
- **卷一**：6 岁觉醒净章 → **回领** → **家庭教师**启蒙 → **6–7 岁**魔法课与领地日常
- **卷二**：**7 岁**收 Writ → 北上 → **王立魔法学院** 初级部；隐藏/控制光系净章锋芒

> **6–7 岁**：可**提及**联姻/订婚制度，**不展开**婚约情节；**不涉及**王室及政治高层直接接触（见 `outline.md`）。
