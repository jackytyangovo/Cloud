# 正文草稿（Drafts）

> **正文单一目录**：章节正文写在这里。预览/审阅某章时，优先读本目录下对应文件。

## 文件命名

| 格式 | 示例 |
|------|------|
| `chapter-NNN.md` | `chapter-003.md` → Ch.3 |
| `chapter-NN.md` | `chapter-03.md`（可选，与三位数并存时优先匹配 outline 章号） |

章号与 `bible/outline.md` 的 **Ch.N** 对应。

## 与 bible 的关系

- 设定以 `bible/` 为准；正文不得擅自改写世界观。
- 旧目录 `chapters/` 如有遗留稿，以本目录 **`drafts/`** 为最新正文来源。
