# 文风指南（Style Guide）

## 叙事视角（用户确认）

### 主视角：第一人称（莉莉娅）

- 正文**默认**以 **「我」** 叙述，即莉莉娅·莱恩菲尔（Lilia Lenfiel）的第一人称主视角。
- 前世记忆、男转女摩擦、自嘲与心理活动可直接用「我」呈现，与用户样章语感一致（见 `style-reference.md`）。
- 读者所见所闻所感以「我」的感知为边界，**不写入「我」当时不可能知道的信息**（除非事后得知并明确交代）。

### 辅视角：偶尔插入第三人称限知旁白

- **偶尔**插入**短段**第三人称限知叙述，用于：
  - **旁白描写**（环境、氛围、场面调度等，第一人称不便展开时）
  - **设定补充**（觉醒制度、净阶、势力格局等，避免主角大段科普腔）
  - **短暂切到他人限知**（如仪式台上检测官所见、洛伦在别处的反应）——须与当前剧情直接相关
- **篇幅**：单次插入宜短（一般 **不超过一章的 20%**）；一章内不宜连续多段旁白。
- **切换标记**（正文可选用以下之一，全书统一即可）：
  - 空行 + 第三人称段落（无「我」）
  - 或以 `※` / `——` 引导的独立短节（【随正文定稿时统一】）
- **切回**：旁白段结束后，下一段恢复「我」，避免长期双视角并行。

### 撰写禁忌

- 不要用全知旁白揭穿「我」尚未知晓的阴谋（除非改为「我后来听说」）。
- 第三人称段内仍保持**平直简单**，不要突然变成百科词条体。
- R18、战力等硬约束在两种视角下均适用。
- **容貌**：bible 可用内部标尺（5–6、7–8 等）；**正文不写数字打分**，用旁人反应与具体描写侧写。

### 与样章的关系

- 用户文风样章即为**第一人称**；本作主视角与之对齐，**无需再做「她」的系统性改写**。
- 第三人称插入为**新增规则**，样章未覆盖的部分按本节执行。

### 对话与节奏（样章 3 确认）

- **叙述为主**仍是默认；**社交/谈判段**对话可升至 **30–40%**（见 `style-reference.md` §五）。
- 对话须配**动作一行**与「我」的内心对照，避免纯话剧。
- 节间可用独立行 `*` 或空行分段，**全书统一**即可。

### 身体喜剧与打断（样章 3 确认 · 卷一尺度）

- 允许**突发的、丢脸的**小物理事故（绊裙、摔软垫、车门碰头）作节奏刹车；**6 岁尺度**，不用 R18 余韵。
- 「门外打断 + 内心窘境」可作章首钩子（见 `style-reference.md` §六）。

## 文风基调

- **平直简单**：用直接、清楚的语言叙述，不堆砌辞藻，不刻意文艺腔。
- **可迭代调整**：初稿按本指南执行；用户审阅后按具体修改习惯（句式长短、细节密度、口语程度等）逐步微调，不必一次定死。
- **风格参考**：详见 [`style-reference.md`](style-reference.md)（基于用户样章分析；**持续更新**——用户发样文 → Composer 分析入库）。
- **综合型节奏**：升级、生存、权谋、冒险可交织，单章可偏重其一；觉醒震撼写「影响」而非「碾压」。

### 卷一前期（第二章–第四章 · 用户确认）

- **生活记录感**：像随家族出行的日记/行记，**以日常所见所感为主**，不急于推主线冲突。
- **基调**：**温馨为主，偶有摩擦**（身体不便、孩童吵闹、无心比较、轻微社交冷落）；摩擦宜小不宜大，不写成持续虐点。
- **小危机夸张**（样章 5）：可用「空前危机 → 其实很小」开篇（抢窗、冷、挤、明日仪式）；**6 岁尺度**，男忆内心可一句带过前世对照。
- **温馨 montage**（样章 5）：固定工序链 + 「自从……日子变快」；陪伴改变日常节奏（见 `style-reference.md` §12.3）。
- **旁观 + 拌嘴**（样章 8）：观战/演示宜 **快收**；战后高密度吐槽与「哄小孩的说法」—— 见 `style-reference.md` §15.7。
- **仪式 + 文书**（样章 9）：魔法启动感官栈、`*` 闪回、见官方信胃翻/想逃 —— §16；**卷二第三十章**用 **Writ of Matriculation**，非女王令。
- **抵达 + 登记 + 制服**（样章 10）：§17；**卷二**第三十四–三十五章；卷一无抵校。
- **季节 + 节庆/市集 + 夜话**（样章 11）：冬景开篇、八卦涟漪、浴想、吹发/梳头、第三人闯门 —— §18；**卷一第二–三章** 生活记录与盖伦府温馨段。
- **一日结构**（样章 4）：可写「从晨到夜」的**工序感**（重复句、第 N 次、收工后小杂务）；**理想宣言后同章或次章可现实打脸**（见 `style-reference.md` §11.4）。
- **世界观**：借**当地风貌**（地貌、物产、市集、码头、仪场）自然带入；禁止大段说明文、百科腔。
- **第三章 起**：**聚会前无社交摩擦**；白天表哥领逛街**买东西、见世面**，温馨为主。**仪式前夜小聚**起才有贵族圈轻视；仪式日（第四章）收束为庄严紧张。

## 内容分级（用户确认 · R18）

本作定为 **R18**，面向成年读者，**可出现成人向内容**，包括但不限于：

- 暴力、伤亡的直白描写
- 情欲、亲密关系相关场面（**配角 / 他人**）
- 暗黑权谋、压迫、伦理边界议题
- 成人向心理与身体感受（**主角成年后**；男转女身份摩擦的成熟表达）

### R18 边界（用户确认 · 硬约束）

| 类型 | 卷一幼年「我」 | 说明 |
|------|----------------|------|
| **主角亲身参与** | **禁止** | 莉莉娅幼年（卷一 6 岁起）**不发生**任何涉及自身的性爱 / 自慰等 R18 描写 |
| **目睹他人** | **允许** | 可**撞见、偷听、部分看见**配角的成人向或暴力暗黑场面，用于推动情节 |
| **主角成年后** | 待定 | 随剧情年龄增长，经 `outline` 标【R18·主角】后再写；笔法见 `style-reference.md` §7（含 §7.7 驱身型、§7.9 情感离别型） |

**目睹他人时的写法**：

- **「我」能看懂**：前世 **男忆**（**刚毕业学生**，无履历线）完整，对成人向 / 暗黑场面**内心完全明白**。
- **装不懂**：表面上装作孩童的困惑、害怕或懵懂——**社交伪装**，避免暴露记忆觉醒（见 `characters.md`）。
- 叙述可呈现**双层**：外在反应（孩童表演）+ 内心独白（成年认知、评判、恶心或冷静分析）。
- 须**服务剧情**（家族丑闻、权力压迫、把柄、信任崩塌等），禁止无铺垫福利。
- 过强场面仍可用**侧面进入**（先闻声、后瞥见），但「我」的内心清楚那是什么。
- 第三人称短插可补「我」未入镜的全貌，仍须克制。

**撰写原则**：

| 原则 | 说明 |
|------|------|
| 服务剧情 | 成人向内容须推动人物、冲突或世界观，避免无铺垫堆砌 |
| 节奏 | 卷一以身份、家族、觉醒为主线；**幼年主角无亲身 R18**；目睹他人须在 outline 标【R18·目睹】 |
| 文风一致 | 即使成人向场景，仍保持**平直简单**；目睹戏写孩童心理冲击 |
| 战力不变 | R18 不突破战力成长硬约束（见下节） |

> Sonnet 5 写正文时须遵守本节；具体章节须在 `outline.md` 标注【R18·目睹】或【R18·主角】（后者仅成年后）。

## 每章须兼顾的四层（用户确认）

写作时除推进剧情外，每章尽量覆盖以下四类内容（比重可随场景浮动）：

| 层次 | 要求 |
|------|------|
| **人物动作** | 具体可见的行为，尤其幼女身体的动作限制 |
| **神态与语言** | 表情、语气、对话；符合年龄与身份 |
| **环境变化** | 场景、天气、光线、声响、领地/城内陈设等随情节推移而变化 |
| **主角心理** | 「我」的内心反应：前世记忆与现世身份的摩擦、判断与情绪 |

> 背景与设定**融入**以上四层中交代，避免大段旁白式说明。  
> **序章 / 初入新世界段落**（用户确认）：**环境认知层加重**——「我」所见所闻所触所嗅宜占全章 **约 45–55%**；心理 **短句穿插**；前世 **刚毕业男学生** 仅作 **一句式对照**，**重点在开启这一世生活**（见 `outline.md` 序章撰写比例）。

## 章节惯例

| 项目 | 规范 |
|------|------|
| 目标字数 | 约 **3000 字/章** |
| 开篇 | 场景切入，尽快进入动作或对话 |
| 结尾 | 悬念断章 |
| 时间跳跃 | 章首简要标注（如「觉醒前二十三天」） |
| 开篇设定密度 | **序章 + 第一章**完成主要背景与家族设定交代，不拖至第五章 |

## 战力与数值（撰写硬约束）

- **天赋净阶 = 上限**，不等于当前战力。
- 孩童高净阶（如埃里克明印、莉莉娅净章）**绝不能**在正面对抗中胜过成年修习数十年的法师（如洛伦澄纹）。
- 战力成长须体现：**魔力强度**、**魔力上限（MP 池）**、咒语熟练度、经验。
- 前期整体数值克制；高净阶概率指数级降低。

## 专有名词

- 首次出现：**中文（Western）**，如 莉莉娅·莱恩菲尔（Lilia Lenfiel）。
- 净阶、元素、地名保持一致，以 `worldbuilding.md` 为准。
- 未设定内容标注 `【随剧情补充】`，不在正文擅自定稿。

## 叙事脉络（章节配比参考）

> 定稿框架见 `outline.md` **「全文叙事脉络」**；共 **八线**，卷比重以 outline 表为准。

1. **成长线**（含魔法修为）— 能力、认知、选择；冥想/感知/净章潜力
2. **身份线** — 男转女 + 前世记忆
3. **情感线** — 依恋、信任、师生/父女羁绊（6–7 岁无恋爱主线）
4. **人物关系线**（含容貌凝视 · 家族/两房）— 人物网络、吸目、莱恩菲尔结构
5. **权力斗争线** — 家族、地方、王国博弈（卷一轻）
6. **教会线** — 维洛教、圣息使与光/生命天赋张力
7. **世界真相线** — 禁忌、种族、历史（长线，慢热）
8. **学院线** — **卷二起**；卷一不涉及
