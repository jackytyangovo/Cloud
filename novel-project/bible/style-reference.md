## 一、核心文风特征

### 1. 开篇：总结 + 反讽

- 用**时间跨度一句收束**（「满打满算十五个年头」）→ 立刻转折打脸读者预期。
- 先写「理应怎样」（美少女、帝王生活）→ 再写「实际怎样」→ 形成落差。
- **可借鉴**：卷一可用类似结构——先写「六岁觉醒本该怎样」，再写「我」内心的错位与不安。

### 2. 叙述语气：平直里的苦

- 句子不华丽，但**情绪密度高**；幽默是冷的、自嘲的（「少年妄想」「我就是个笑话」）。
- 常用**短判词句**收束段落（「简言之」「也就是说」「正因如此」）。
- **可借鉴**：「我」有前世 25 岁男性记忆，用**成熟内心的冷幽默**对照幼女外表。

### 3. 结构：列举与分条

- 重大信息用**「其一、其二、其三」**或分条列出，读者一眼抓住。
- 回忆按**年龄节点**推进（四岁、九岁、十岁…），时间清晰。
- **可借鉴**：身份、家族、天赋规则可用分条嵌入回忆或对话；复杂设定可交给**短段第三人称旁白**（见 style-guide）。

### 4. 心理描写：不粉饰、承认跑题

- 内心**直白**写出不适、嫉妒、羞耻、错位，不强行「正能量」。
- 叙述者**自知跑题**并拉回（「有点跑题了」）→ 像真人思绪，降低说教感。
- **性别认知**：客观知自己是女，主观仍残留男性习惯——与莉莉娅设定高度相关，**第一人称「我」直接呈现即可**。

### 5. 对话：少而准

- 大段以叙述与心理为主；**对话占比低**，出现时多为家庭日常、关键一句。
- **可借鉴**：莱恩菲尔家场景不必话多；洛伦宠溺、盖伦一家来访，用少量对话 + 神态足够。

### 6. 环境 / 身体感受：贴情绪

- **饥饿、寒冷、火**等感受具体写在身体里，不是空洞形容词。
- **长短句结合**：环境、动作勿连续短句堆砌；用长句铺陈，短句点睛（见 `style-guide.md`）。
- **可借鉴**：领地晨景、灰谷赴城——写出光线、温度、气味；第一人称写「我」所感，场面宏观处可用第三人称短插。

### 7. 世界观：从个人经历长出

- 禁止饮酒、女性歧视、学费等，全由**「我遇到过」**带出。
- **可借鉴**：觉醒仪式、净阶等，优先经「我」的经历与回忆；制度细则可用**第三人称旁白短段**补充，避免「我」像念课本。

### 8. 悲剧与 R18（日常向）：克制直白

- 苦难、死亡、情欲窥探写**事实与感受**，不煽情堆砌。
- **可借鉴**：暗黑或暧昧日常仍用**平直、有因果**笔法。

### 8b. R18 亲密场景笔法（见第七节）

- 样章即第一人称，**本作直接沿用「我」**；心理抗拒与身体反应并用。

### 9. 节奏与章末

- 段落偏长，逗号串联；关键处用短句刹车。
- 章末可落在意象或情绪余韵，也可悬念。

## 四、写作时 DO / DON'T

### DO

- 主段用**「我」**；设定必要时**短段第三人称**切换
- 具体感受代替空泛情绪；前世记忆自然打断
- 列举、年龄节点理清信息
- 保持句子可读：口语化书面语

### DON'T

- 不要长篇第三人称抢戏
- 不要全知旁白揭穿「我」未知信息
- 不要照抄样章情节
- 不要因 R18 浮夸描写

## 七、R18 笔法参考

> 用户样章为**成年主角第一人称**亲密戏，供**成年后【R18·主角】**或语感参考。  
> **卷一幼年莉莉娅禁止亲身 R18**；可写**目睹配角**（标【R18·目睹】）。

### 7.0 三类 R18 场景

| 标签 | 谁 | 卷一幼年 | 写法 |
|------|-----|----------|------|
| 【R18·主角】 | 莉莉娅亲身 | **禁止** | 成年后按 7.1–7.5；样章笔法 |
| 【R18·目睹】 | 配角；「我」在场 | **允许** | 内心看懂、**表面装不懂**；双层叙述 |
| 【R18·旁白】 | 他人；「我」不在场 | 慎用 | 仅第三人称短插，须与剧情直接相关 |

### 7.0b 【R18·目睹】专条（用户确认）

**核心**：「我」**看得懂，装不懂**——前世 25 岁男性记忆使人内心了然；外在装作孩童不该有的懵懂或半懂不懂，是**保护色**。

**DO**

- **双层叙述**：外（装）— 缩手、捂耳、问「他们在吵架吗」；内（真）— 冷静判断、恶心、记仇、盘算后果
- 写「我」为何必须装：怕暴露记忆、怕大人灭口、幼女身体无力介入等
- 侧面进入场面后，用内心一句点破「我」其实懂（不必明说给旁人听）
- 推动情节：把柄、家族污点、对某人的评价彻底改变

**DON'T**

- 不要让叙述真的写成「我」智商上不懂（除非对极少数世界观独有事物）
- 不要让幼年「我」亲身参与性爱描写
- 不要无剧情铺垫的目睹福利

**目睹示例句型（原创）**

> 「洛伦叔叔，里面在做什么呀？」我仰着头，尽量让声音像六岁该有的那种黏糊。二十五岁的那个男人已经在心里把场景拼完了。我说不准细节，但足够恶心。

> 门没有关严。我停了一下，装作被吓到的样子往后退。实际上每一个音节我都知道是什么意思——正因为知道，才更不能让人发现我也知道。

### 7.1 场景功能（【R18·主角】· 成年后）

| 功能 | 表现 |
|------|------|
| 性别认同 | 「男子气概 / 骑士梦」vs 女性身体 |
| 自我说服 | 「只是舒缓」「绝对不是喜欢」 |
| 事后羞耻 | 「下次不能再做了」 |
| 前世对照 | 「作男生时没有这种感觉」 |

### 7.2 结构节奏

```
日常切入 → 更衣/镜像 → 自言自语正当化 → 动作递进 → 前世对比
→ 失控 → 高潮后乏力 → 自责收尾
```

### 7.3 语言与感官

- 词汇直白，经「我」的感知与自责过滤
- 自言自语可用引号
- 环境音（静、隔壁）参与紧张感
- **第三人称不宜插入此类私密场景内部**；若需事后旁白，仅写外部结果（如「夜里领地静得出奇」）

### 7.4 男转女核心句型（第一人称示例）

> 我对着镜子拉平裙摆，心里想的却是别种装束。二十五岁的那个男人从未为一条裙子费过心思，可这具身体却记得蕾丝边蹭过膝盖的痒。

> 「……只是解压。」我听见自己这么说，像说服另一个还留在前世的自己。

### 7.5 DO / DON'T（【R18·主角】· 成年后）

**DO**：日常切入；心理抗拒 ↔ 身体反应；前世对照；事后心理；第一人称「我」

**DON'T**：无心理纯肉体；无铺垫福利；未标【R18·主角】章节强写；幼年主角适用

### 7.6 与 style-guide 的 R18 边界

- 幼年莉莉娅：**仅【R18·目睹】/【R18·旁白】**，禁止【R18·主角】
- 具体章节须在 `outline.md` 标注类型

### 7.7 魔法 / 异常驱身型（样章 6 · 【R18·主角】· 成年后）

> **卷一 6 岁莉莉娅禁止**；供**中期以后**标【R18·主角】章节，或改写为**非性**魔法异常时参考**结构**。

**叙事框架**

```
日常工序（繁忙季）→ 走神写错 → 身体异常多日
  ↓
自我解释 → 发现不对（纹章 / 非普通冲动）
  ↓
同事打趣 → 「我」否认 + 社死
  ↓
* · 归途议论 → 决定「今晚问某人」
  ↓
* · 登门 / 暧昧日常 → 口误越界
  ↓
未完成求证 → 独处 · 多轮 → 空虚收尾
```

**独处段（成年后 · 结构要点）**

- 多轮升级：快 → 不够 → 慢而猛 → 呼名 → **事后仍空虚**。
- 男转女自厌：「软弱/淫靡」与男忆对照。
- 清洁换衣、回床、异常暂静 —— **写 aftermath**。

**「几乎发生」张力（可不写完成性行为）**

- 吹发/触碰逐点触电；口误「给你看」「抱上床」→ 误会 → 独处收场。
- **→ 卷一**：可改为找洛伦看检测异常；**无 R18**，保留 embarrassment。

### 7.8 同伴直球打趣（样章 6）

- 恋爱？→ 更粗直球 → 否认 → 社死；同伴仍帮改错表。
- **→ 卷一**：仅「发呆/脸红」级；**6 岁无发情/下流词**。

### 7.9 离别前 · 情感驱动型（样章 7 · 【R18·主角】· 成年后）

> **卷一禁止**。与样章 6（魔法驱身·独处·空虚）成对照：**两情相悦·互为主体·泪与告白**。

**长线结构**

```
洗浴后日常（走廊/炉火/擦发）→ 窗外 + 长篇「触不到的远方」
  ↓
阶级/残疾自责（「不该束缚他」）→ 敲门 → 非性亲密（吹发）
  ↓
沉默对话（明天走）→ 拽衣角 → 「就今晚……离别纪念」
  ↓
纹章/印记 **因情感** 亮起（非强制魔法）→ 「你要负责」
  ↓
R18：「我」主动带节奏 + 对方迟钝 → 中途泪与「我爱你」→ 结合中哭泣
  ↓
aftermath：分离、余温、命令式告别（「不准忘记我」）
```

**情感 R18 要点**

| 要点 | 写法 |
|------|------|
| **主动方** | 「我」挑逗、吐槽「笨蛋/呆瓜」；对方木讷 → **反差的甜** |
| **无障碍** | 残疾/动线限制 → 对方**用抱/托/调整**弥补；不写「可怜」，写**默契** |
| **泪与性并存** | 高潮前后可哭；「我爱你」选在高情感点，非纯福利 |
| **我最后的任性** | 体力耗尽仍想为对方动一下 → 对方接手 → **双向** |
| **收束** | 命令句排比（不准…不准…）+ 身体余温 + 未完成的日期/未来 |

**与样章 6 对照**

| | 样章 6 | 样章 7 |
|---|--------|--------|
| 驱力 | 魔法/异常 | 离别 + 情感 |
| 性 | 独处为主 | 双人全程 |
| 事后 | 空虚 | 悲伤但**共同完成** |
| 印记 | 折磨 | 见证（「因你而亮」） |

**→ 卷一非 R18 借用**：拽衣角、「就今晚 only」、不能说「别走」的自责、炉火/擦发/窗外月；**北上前夜**对洛伦可写**无 R18** 版。

## 五、对话与社交场景（样章 3 补充）

> 样章 1 偏叙述；样章 3 证明**社交段对话可占 30–40%**，仍保持第一人称心理主导。

### 5.1 对话功能

| 功能 | 写法 |
|------|------|
| **推情节** | 康拉德一句「来当柜台小姐」完成转折；信息由对话落地，非旁白公告 |
| **显性格** | 对方热情过头 → 「我」用类比吐槽（体育教师）；对方粗线条 → 「我」炸毛回嘴 |
| **藏尴尬** | 「我」答短、偏头、装没事；对话表层正常，叙述层补湿裙摆/余韵 |
| **节奏刹车** | 长解释后接一句短对白（「喂！什么叫我很笨呀？！」） |

### 5.2 对话 DO / DON'T

**DO**

- 每人有**口癖/句式**（会长：「你这妮子」；「我」：「……嗯。」「哇啊！」）
- 对话间插**动作一行**（鼓嘴、瞥头、缩肩、盯地板）
- 「我」可**半句打断**、**重复对方关键词**（「工作……？」「不是？」）

**DON'T**

- 不要全员书面语
- 不要用对话堆设定；规则仍从「我」的经历带出（禁裤→盔甲例外）

### 5.3 推荐句型（原创 · 仿样章 3 语感 · 适配莉莉娅）

> 「埃里克表哥！」我尽量让声音甜一点，「你再说一遍『莱恩菲尔肯定出土』试试？」

> 「……没什么。」我盯着地板，「真的没什么。」  
> 心里把理由列成三条，一条比一条说不出口。

## 六、突发打断与身体喜剧（样章 3 补充）

### 6.1 「门外来人 + 体内窘境」开篇

- **先危机后解释**：敲门 → 「我」才意识到昏迷/刚做过坏事/身体余韵 → 双重压力。
- **时间用体感估**：「从这个量看昏迷多久？一小时？两小时？」——**不查表**，用慌乱推测。
- **物理细节优先于形容词**：床单深色浸染、裙摆湿、地板「碰」一声、头冒金星。

### 6.2 身体喜剧（可克制用于卷一）

- **突发的、丢脸的**物理失误（轮椅滑走、摔地）→ 短句收束（「……疼。」「糟了，没锁门。」）
- 喜剧**不消解**悲剧底色；同章可接轮椅/双腿/小队全灭回忆。
- **卷一莉莉娅**：可改为裙绊、上车不便、夜聚前打翻水——**尺度对应 6 岁**，不用 R18 余韵。

### 6.3 节间分隔

- 样章用独立行 `*` 分 **「闯门—对话—独处反思—次日制服」** 四段；本书可选用 `*` 或空行，全书统一即可。

## 十、样章 3 · 社交尴尬 + 事业转折 · 第一人称（2026-07-16 入库）

> **来源**：用户样文（露露安娜 · 冒险者公会线）。**不移植情节**；只提炼与莉莉娅（男转女 · 平直苦叙）可迁移的笔法。

### 10.1 样章概览

| 项目 | 观察 |
|------|------|
| 篇幅 | 约 **4500 字**（含对话、回忆、两次 R18 余韵呼应） |
| 场景 | 私密窘境被打断 → 社交掩饰 → 对话推转职 → 独处悲剧回忆 → 次日制服喜剧 → 倔强宣言收束 |
| 对话占比 | 约 **35%**（社交段可话多） |
| 基调 | 尴尬 → 苦中作乐 → 立志 → 再被命运打脸 → **「不幸人生」式自嘲收束** |

### 10.2 可迁移核心特征

**① 双层叙述（社交伪装）**

- 外在：扭捏、合拢腿、低头、说「没什么」。
- 内在：数湿痕、否认取向、骂自己失控。
- **→ 莉莉娅**：装乖女童 vs 25 岁男忆；【R18·目睹】同样「看懂装不懂」（§7.0b）。

**② 自我否定循环（喜剧钩子）**

- 「今后禁止色色！」→ 章末再犯/再忘。
- **→ 卷一**：「我再也不……」式**落空决心**，不必 R18。

**③ 男魂 × 女身 × 社会规训**

- 否认「会喜欢男人」；智力下滑焦虑；禁裤→盔甲漏洞；昵称恼火。
- **→ 莉莉娅**：裙、莉莉娅名、土系期望；写「算数要想很久」式体感，**不写 IQ 数字**。

**④ 世界观贴个人**

- 禁裤、盔甲例外、妇从夫姓、公会流程——经抱怨与回忆带出。
- **→ 本作**：觉醒、净阶、维洛教、灰港职官，同样**禁止百科段**。

**⑤ 悲剧回忆插入时机**

- 对话落定后独处再写：全灭、双腿、唯一幸存者——**不开场倒叙**。
- 回忆后接**具体使命**（阻止热血青年送死）。
- **→ 卷一**：母亲/莉安娜短回忆 **200–400 字**，不抢当章主事件。

**⑥ 收束：倔强宣言 + 反讽尾句**

- 「堂堂出道！」+「不幸人生」——**先扬后摔**。
- **→ 章末**：一句硬宣言 + 一句自嘲。

### 10.3 R18 余韵型（非当场 · 样章 3）

| 步骤 | 写法 |
|------|------|
| 1 | **后果**：床单浸染、身体余韵、外界刺激再起反应 |
| 2 | **否认 + 羞耻**（「不可能喜欢男人」） |
| 3 | 敲门/摔落**强行打断** |
| 4 | 社交段**绝口不提**，只写掩饰动作 |
| 5 | 独处再提 → 再次「禁止……！」 |

- **卷一**：幼年无亲身 R18；此型用于【R18·目睹】后遗，或成年后【R18·主角】事后（§7）。

### 10.4 人物塑造映射

| 样章 | 本作可映射 |
|------|------------|
| 热情长辈（康拉德） | 洛伦、盖伦、埃里克「表哥请」 |
| 激将「你这妮子/笨」 | 同辈嫉妒、埃里克无心比较 |
| 揉头等亲昵 | 米拉梳发、洛伦抱膝（温馨） |
| 对方不知底细 | 无人知男忆/光系恐惧 |

### 10.5 仿写句（原创 · 给 Sonnet）

**打断开篇**

> 门外有人叫我的名字。我这才反应过来自己刚才差点从凳子上滑下去——裙角还皱着，手心全是汗。不行，先开门。  
> ……不对，先决定开门之后装什么表情。

**宣言 + 自嘲收束**

> 北上艾什福德。去上学。  
> 听起来像人生终于要开始了——如果我还没在第三章把灰港贵族小孩全得罪光的话。

### 10.6 迁移 / 不迁移

| 迁移 | 不迁移 |
|------|--------|
| 双层心理、自嘲、对话推情节 | 公会、柜台、轮椅、地下城全灭 |

## 十一、样章 4 · 平凡一日 · 职场 + 回忆悲剧 · 第一人称（2026-07-16 入库）

> **来源**：用户样文《露露安娜的平凡一日》。**不移植**公会、轮椅、维帕梅拉女神、柯莱蒂等；提炼笔法。

### 11.1 样章概览

| 项目 | 观察 |
|------|------|
| 篇幅 | 约 **5500 字** |
| 结构 | 紧张入场 → 理想宣誓 → `*` → 上班厌烦/社交耗神 → `*` → 收工杂务 → **长回忆杀** → 回归当下 → **双微笑收束** |
| 对话 | 公式化工作用语 + 少量同事对白；**叙述与回忆占主** |
| 基调 | 倔强不妥协 → 立刻被「上班」打脸 → 劳役现实感 → 悲剧深挖 → 强撑的温柔结尾 |

### 11.2 可迁移结构：「平凡一日」

```
章首：公共场合的紧张（汗、制服、被注视）
  ↓
仪式化动作（闭眼只听轮子/心跳 → 睁眼上岗）
  ↓
短宣言（「永远不会妥协」「来日方长」）
  ↓
* 分隔 *
  ↓
日常工序：重复句、厌烦、人际消耗（可写「今天第 N 次……」）
  ↓
应对策略：外笑脸内压火 + 制度/文书反制（本作可换为装乖/父亲挡在前）
  ↓
* 分隔 *
  ↓
收工后杂务（打扫、整理）→ 触发跨世界/阶级对比（短，≤一段）
  ↓
长回忆（失去之人；梦想对照；**情感高潮**）
  ↓
切回当下：同事推轮椅/家人牵手 → 集市找人脸 → 找不到
  ↓
章末：买小物 + **对人笑两次**（表演性温柔）
```

**→ 莉莉娅卷一映射**

| 样章块 | 可作 |
|--------|------|
| 紧张入场 | 入灰港、进仪场、初到学院 |
| 闭眼听声 | 夜聚前/检测前压惊 |
| 宣言→打脸 | 「这次一定不出光」→ 第四章 |
| 重复工序 | 逛街一整天、候场听叫名 |
| 外笑内怒 | 第三章夜聚 |
| 长回忆 | 莉安娜（**200–600 字**，勿抢主事件） |
| 双微笑收束 | 章末装乖给洛伦看 |

### 11.3 感官抽离（ overwhelmed 时）

- 闭眼 → 只写**心跳、滚轮/脚步、自己的呼吸** → 再睁眼重新接受光线。
- **不写**心理形容词堆叠，写**关掉视觉**后的听觉序列。
- **→ 莉莉娅**：仪场等待、被全场看时可用；**6 岁**，缩短至 2–4 句。

### 11.4 理想宣言 ↔ 现实立刻反讽

- 前段：「永远不会妥协」「来日方长」「世界很大总会有办法」——**排比、硬**。
- 后段：`*` 后第一句「先前的想法完全被熄灭了」「世界上绝对不会有任何一个人想要上班，绝对！」——**同章打脸**，不等到下章。
- **→ 卷一**：「我一定能测出土系」→ 同一章或下一章现实击碎；语气可幼化，**结构保留**。

### 11.5 分条析理（社交/制度）

- 搭讪厌烦：**第一点 / 第二点** 分条；用**重复次数**（第二、第三次就无波澜）代替抽象「厌烦」。
- 制度细节（保险、契约）由**「我」工作体验**带出，非说明文。
- **→ 本作**：净阶、仪典册、维洛教初光祝，可用「第一点……第二点……」式内心清单，**宜短**。

### 11.6 跨世界阶级对比（异世界自觉）

- 前世加班/劳动法 ↔ 本世奴隶、贵族、十小时「已算不错」↔ 酒馆女侍更惨——**三四句对照**，引出发「幻想世界也难逃」。
- **→ 莉莉娅**：25 岁男忆可偶发**一句**（「前世六岁还在幼儿园」vs「这里六岁测天赋定终身」）；**勿每章都写**，卷一 1–2 次即可。

### 11.7 悲剧回忆插入（样章 4 型 · 重）

| 要素 | 写法 |
|------|------|
| **触发** | 收工打扫、同事一句、相似名字 |
| **时间标记** | 具体年龄（十岁、十一岁）、具体物件（茅草屋、省下的钱） |
| **梦想对照** | 「我」：女骑士/冒险者；她：嫁喜欢的人——**两种梦想都碎** |
| **失去** | 火焰、永别；**不渲染血腥**，写「很自然、很无情地破坏」 |
| **余韵** | 「好想再见一面」→ 人群里找脸 → 找不到 → 抱苹果/物 **拼命** |
| **切回** | 同事在身后推轮椅——**温情动作**承接悲伤 |

- **→ 卷一**：莉安娜之死宜 **侧写**（序章遗物、父亲不提全名）；**完整回忆杀**留中期；6 岁**不写**同龄人生死大火现场。

### 11.8 表演性温柔收束

- 章末**连续两次**对外微笑（摊主 + 同事），中间**抱紧袋子**——读者知是强撑。
- 与 §10「宣言+自嘲」不同：这里是**不哭给外人看**（§10 是自嘲命运）。
- **→ 莉莉娅**：对洛伦「我很好呀」+ 内心清单未消 —— 双层收束。

### 11.9 公式化台词（ ritual ）

- 入门欢迎词、窗口重复句——**同一套话一天说 N 遍** → 写出机械感与厌烦。
- **→ 本作**：觉醒礼颂、家族问候礼、学院礼仪课——可复用「背熟了但心里在别处」。

### 11.10 仿写句（原创 · 莉莉娅）

**感官抽离**

> 我闭上眼睛。只听见自己的呼吸，还有远处仪场方向隐约的号声。等再睁开，洛伦已经把我的领口理好了。

**宣言→打脸**

> 没事的。六岁的小女孩，测出什么都能活。  
> ……  
> 我太高估「装乖」这件事了。第三个人问「你妈妈是不是平民」的时候，我已经想把桌子掀了。

**双微笑收束**

> 「谢谢爸爸。」我冲洛伦笑。  
> 又冲米拉笑。  
> 糖纸捏在手心，捏得有点响。应该没人听见。

### 11.11 迁移 / 不迁移

| 迁移 | 不迁移 |
|------|--------|
| 一日结构、抽离、宣言打脸、分条析理 | 公会、柜台、十小时班、保险契约 |
| 回忆杀结构、双微笑收束 | 柯莱蒂、火焰具体剧情、维帕梅拉女神 |
| 阶级/劳动短对比 | 轮椅、性骚扰详细清单（卷一不用） |

## 十二、样章 5 · 日常小危机 · 同居温馨 + 夸张叙事 · 第一人称（2026-07-16 入库）

> **来源**：用户样文《日常生活的小小危机》。**不移植**爱丽丝、约尔、租房贷款等；提炼 **卷一温馨段** 与 **轻喜剧危机** 笔法。

### 12.1 样章概览

| 项目 | 观察 |
|------|------|
| 篇幅 | 约 **4200 字** |
| 危机类型 | **伪史诗级**开场 → 实为「床太小」→ 找房 → 意外解法（造访约尔家） |
| 基调 | 温馨充实 → 季节推移 → 轻微焦虑 → 回忆不舍 → **喜剧对话**收钩子 |
| 对话 | 约 **25%**；爱丽丝高能量、约尔结巴、「我」吐槽兼圆场 |

### 12.2 「小危机夸张法」（卷一核心技法）

**结构**

```
标题/首段：「前所未有的危机」「不输给任何大事！」
  ↓
立刻降格：「说起来很小……床铺太小」
  ↓
从头说起：时间快进 + 日常 montage（为何走到这一步）
  ↓
实际问题 + 理性列举方案（换床/换房/贷款买房……）
  ↓
情感阻力：对旧居回忆清单（第一次……第一次……）
  ↓
行动碰壁 / 误伤旁人（忘了告诉约尔）
  ↓
意外线索 → 对话喜剧 → **章末惊讶句**（「……可以。」「欸欸欸?!」）
```

**→ 莉莉娅映射**

| 样章危机 | 卷一对等 |
|----------|----------|
| 床太小 | 马车挤、与芬恩抢窗、盖伦府客房窄 |
| 入冬抢被 | 第二章傍晚冷、驿站一条毯 |
| 找房失败 | 入城前以为住店其实住伯父家的小落差 |
| 忘了告诉某人 | 洛伦/盖伦兄弟小分歧（3-4） |

- **6 岁尺度**：危机限于孩童能懂的事（冷、挤、饿、衣饰、明日仪式）；男忆内心可**一句**带过「前世这种叫房贷」。

### 12.3 温馨日常 montage（样章 5 · 卷一急需）

**写法**

- **固定工序链**：叫人起床 → 洗漱 → 穿制服 → 早餐 → 出门 → 傍晚同车回家 → 路上聊天。
- **时间加速句**：「自从……来了之后，时间过得非常快」「往日无聊发闷的日子一去不复返」。
- **陪伴改变节奏**：重复中的变化（从尴尬到「几乎无所不谈」）。
- **季节一笔**：蝉鸣 → 清翠 → 深秋 —— **景物带出时间**，不写日期表。

**→ 莉莉娅**：序章–第二章晨起/上车/午歇；第三章 3-3 逛街 = 「充实一日」幼童版。温馨段摩擦 **0–1 处**。

### 12.4 回忆清单（轻量 · 非悲剧型）

- 触发：要离开旧居 → 「许多回忆涌现」。
- **排比「第一次……」**：5–7 条，每条一行，不展开。
- 哲理句后不煽情：「不斩断过去就不会迎接未来」→ 立刻行动。
- **→ 卷一**：离开领地时用；莉安娜全量回忆仍留样章 4 型。

### 12.5 多人动态（对话性格）

| 角色型 | 样章 | 本作可映射 |
|--------|------|------------|
| 高能量同伴 | 爱丽丝举手、三连问 | 芬恩、日后 #4 |
| 沉默型 | 约尔板脸、结巴 | 洛伦、盖伦 |
| 「我」 | 吐槽 + 圆场 + 男忆共情 | 莉莉娅装乖 + 内心评 |
| 误伤喜剧 | 忘了告诉约尔 | 表亲「忘了跟谁说」 |

- **章末 escalating**：「……可以。」→「欸？」→「欸欸欸?!」

### 12.6 男忆共情（非恋爱）

- 「作过一回男人的我，非常能够理解约尔的心情」——理解**男性社交窘迫**；前世一句 →「算了不想了」。
- **→ 莉莉娅**：理解洛伦/盖伦面子；理解埃里克「表哥请」。

### 12.7 仿写句（原创 · 莉莉娅）

**夸张开篇**

> 我和芬恩表弟，正面临一场空前危机。  
> 说出来很小。  
> 但坐在马车里的时候，我觉得这比觉醒仪式还难办。  
> ——窗只有一边，而他一定要靠在那边看风景。

**温馨 montage**

> 自从盖伦一家来了领地，日子忽然变快了。  
> 早上仍是洛伦给我梳头；多了埃里克在院里练土系，芬恩在旁边瞎喊。  
> 晚上家宴散后，我躺在床上，竟然有点想明天继续。

### 12.8 迁移 / 不迁移

| 迁移 | 不迁移 |
|------|--------|
| 小危机夸张、温馨 montage、第一次清单 | 爱丽丝/约尔、贷款、B 级冒险 |
| 季节推移、找房碰壁、对话喜剧 | 双人同居、造访异性家恋爱线 |

## 十三、样章 6 · 年末繁忙 + 魔法异常驱身 · R18·主角（2026-07-16 入库）

> **来源**：用户样文（年末公会 · 纹章异常 · 独处段）。**【R18·主角】成年主角**；**卷一 6 岁莉莉娅禁止亲身 R18**。入库为**成年后笔法** + **可迁移非 R18 结构**。

### 13.1 样章概览

| 项目 | 观察 |
|------|------|
| 篇幅 | 约 **8500 字** |
| 结构 | 繁忙日常 → 异常症状 → 同事打趣 → `*` 归途 → `*` 登门张力 → 独处多轮 → 空虚收尾 |
| 非 R18 块 | 年末氛围、写错表、克莱丽莎改错、车厢拌嘴 |
| R18 块 | 成年后主角独处；详见 §7.7 |

### 13.2 非 R18 · 可迁移（卷一）

| 特征 | 莉莉娅用法 |
|------|------------|
| **节庆/季末繁忙** | 觉醒季灰港人多、仪场候场喧嚣 —— 景+声开头 |
| **走神写错** | 第四章前写错名字/场次；内心别处，手先动 |
| **症状外显** | 手汗、听不进、指尖抖 —— **不写**性热，可写紧张/发烧恐 |
| **同事帮擦屁股** | 米拉整理衣饰、盖伦圆场 |
| **车厢议论** | 第二章 2-5 驿堂/2-6 车队；决定「到了要问」 |
| **魔法印记 mystery** | 中期 **#6 生命隐线** / 觉醒异常；**6 岁仅光系检测异象** |
| **`*` 分段** | 候场 | 检测 | 归途 等 |

### 13.3 双层否认（非性版 · 卷一）

- 「才没有！」「我没有……容易××的体质！」—— 可用于**被说漂亮/像妈妈/不像土系**时的炸毛。
- 声音太大 → 旁人回头 → 想钻地 —— **第三章夜聚**可用。

### 13.4 卷一边界（硬）

| 样章内容 | 卷一 |
|----------|------|
| 发情/性热/独处 R18 | **禁止** |
| 纹章 + 生理渴望 | 改为 **检测柱异常 / 光象**（第四章–五） |
| 找男性独处吹发等 | 改为 **洛伦梳头 / 米拉理衣**（无 R18） |
| 同事「发情了？」 | 改为 「你怎么一直发呆？」 |
