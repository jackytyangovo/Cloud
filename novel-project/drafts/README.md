# 正文草稿（Drafts）

> **正文单一目录**：章节正文写在这里。预览/审阅时，**按大纲章名**找对应文件。  
> **叙事**：序章拟 **插叙**（正文暂空）；**正叙自第一章**。按当前 `bible/outline.md` 撰写。

## 文件命名（与大纲对齐）

| 大纲章名 | 文件 |
|----------|------|
| **序章** | `prologue.md`（插叙 · 提纲待交） |
| **第一章** | `chapter-001.md` |
| **第三十一章** | `chapter-031.md` |
| **第N章** | `chapter-NNN.md`（三位数字） |

**卷一**止于 `chapter-031.md`；**卷二**自 `chapter-032.md`（入学许可）起。

## 与 bible 的关系

- 设定以 `bible/` 为准；正文不得擅自改写世界观。
- 旧目录 `chapters/` 如有遗留稿，以 **`drafts/`** 为准。

## 定稿归档（`finalized/`）

- **已定稿**章节复制到 `../finalized/`，与 drafts **同名**（如 `prologue.md`）。
- **预览同步**：有定稿用定稿；无定稿才同步本目录初稿。
- Agent **不得**改定稿目录，**除非**用户说 **「章节定稿」**。
- 详见 `finalized/README.md`。
