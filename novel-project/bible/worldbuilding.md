## 一、时代与基调

- **时代**：中世纪奇幻
- **人类主导**：文明、人口、政治以人类为核心
- **天赋决定阶级天花板**：越强越高；贵族必为觉醒者
- **人类成年**：**14 岁**（法律与社会公认成年）
- **订婚**：社会上**最早 12 岁**即可订婚（多为贵族联姻、家族安排；成婚礼仪通常在成年后）

## 二、力量体系

### 2.1 魔法总览

```
魔法
├── 元素魔法（七种基础元素）
│   ├── 风 / 火 / 水 / 土 / 电 / 光 / 暗
│   └── 衍生元素（由基础元素派生，非独立天赋）
│       ├── 冰 ← 水元素衍生
│       ├── 生命 ← 光元素衍生
│       └── 死灵 ← 暗元素衍生
├── 变种魔法（非元素系）
│   ├── 精神魔法（读心、暗示、幻术、精神冲击等）
│   └── 空间魔法（含封印；需特殊变异天赋）
└── 禁术/不存在
    └── 时间魔法 —— 本世界不存在
```

### 2.2 天赋觉醒与社会结构

**觉醒比例**（光/暗/电与战斗级均以「所有觉醒者」为基数）：

- 约 **90%** 无法觉醒魔法天赋
- 约 **10%** 能觉醒
- 其中 **99%** 极弱，仅生活用途，无战斗价值
- **战斗级**：觉醒者中 **1%**（≈ 总人口 0.1%）
- **光 / 暗 / 电**：各自约占觉醒者 **1%**

**人类天赋觉醒制度**：

- **六岁时**统一举行觉醒仪式
- 检测结果：**属性** + **净阶**
- 贵族与平民同一制度，资源与期望不同

### 2.3 天赋净阶

> 魔法越弱杂质越多；净阶衡量纯净度与上限潜力，与元素种类正交。

| 净阶 | 名称 | 直观含义 | 大致对应 |
|------|------|----------|----------|
| 一 | **浊痕** | 杂质浓重，几乎只能生活用 | 觉醒者绝大多数 |
| 二 | **蒙纱** | 可用但混沌；光/暗/电起步净阶 | 弱觉醒 / 少见元素下限 |
| 三 | **澄纹** | 杂质可控，**战斗级门槛** | 标准战斗法师 |
| 四 | **明印** | 清晰稳定，同阶强者 | 精锐、重点培养 |
| 五 | **净章** | 高纯少杂 | **标准仪式可测上限** |
| 六 | **澈冕** | 极净 | 仪式测不出 |
| 七 | **无垢** | 理论完美 | 衍生/万里挑一；仪式测不出 |

- 标准仪式**最高测至净章**
- 光/暗/电觉醒者净阶**起步为蒙纱**

### 2.4 元素稀有度

| 层级 | 元素/天赋 | 占所有觉醒者 | 备注 |
|------|-----------|------------|------|
| 常见 | 风、火、水、土 | 战斗级主体 | 四元素主流 |
| 少见 | 光、暗、电 | 各自约 1% | |
| 极稀有 | 冰、生命、死灵、空间 | 万里挑一 | 顶层博弈筹码 |

**元素规则**：

- 每人 1–2 个主元素亲和
- 衍生须先修基础元素再专精
- 消耗魔力（MP），可冥想、魔晶、药剂恢复
- 等级框架：学徒 → 正式法师 → 高阶 → 大法师（命名可世界观化）

### 2.5 剑术与剑术天赋

**剑术 = 技能，非魔法**

- 通过训练习得（流派、招式、奥义）
- 剑术天赋觉醒 ≠ 学会剑术，而是有利于剑术成长的先天能力

**剑术天赋类型（示例）**：速度强化、力量强化、悟性强化等【随剧情补充】

**觉醒比例**（与魔法类似）：

- 90% 无法觉醒
- 10% 觉醒，其中 99% 弱化型（体魄略强，约一打二、一打三）
- 战斗级：觉醒者中 1%（以一敌十；顶尖者以一敌百）

**魔武双修**：魔法与剑术天赋相互独立，双修极稀有，资源与时间成本翻倍。

### 2.6 魔法战力成长规则（硬约束）

1. **天赋净阶决定上限，不决定即战力**
2. **高净阶概率指数级降低** → 前期数值克制
3. **年龄与修习年限不可替代** — 孩童高净阶打不过成年修习数十年者
4. **战力成长维度**：魔力强度、魔力上限（MP 池）、咒语熟练度、施法速度、战术经验

| 场景 | 允许 | 避免 |
|------|------|------|
| 莉莉娅觉醒净章 | 震惊仪式、引发关注 | 觉醒当日碾压成年人 |
| 埃里克明印 | 同龄佼佼者 | 以一敌多成年法师 |
| 洛伦澄纹 | 领地护卫战力 | 被 6 岁女儿压制 |

### 2.7 天赋与社会阶级

- 天赋越强 ≈ 地位越高
- 贵族与统治阶级**必定为觉醒者**（可弱，但必须有）
- 天赋具有遗传性；弱家族出强天赋为**罕见变异**
- 统治阶层通过联姻、资源垄断觉醒者身份

### 2.8 年龄、成年与婚约（用户确认）

| 项目 | 规定 | 备注 |
|------|------|------|
| **成年** | **14 岁** | 法律与社会公认；此前为未成年 |
| **最早订婚** | **12 岁** | 社会上已存在；贵族圈更常见 |
| **天赋觉醒** | **6 岁** | 与婚约无直接绑定，但觉醒结果影响联姻价值 |

**社会含义**：

- 贵族子女：觉醒仪式后（6 岁起）即可能被纳入**家族联姻盘算**，但真正订婚通常不早于 12 岁。
- 莉莉娅（6 岁）、芬恩（5 岁）尚未触及订婚年龄；埃里克（10 岁）距最早订婚还有约两年。
- 光系净章等高天赋将显著抬高联姻筹码，可与权谋线挂钩。
- **订婚 ≠ 成婚**：订婚多为文书与家族承诺；完婚、同居等一般在**成年后（14 岁+）**。
- 其他种族婚龄：【随剧情补充】

**与 R18 边界**：本作幼年主角无亲身 R18；目睹戏与联姻政治可并行，但须服务剧情。

| 种族 | 天赋倾向 | 状态 |
|------|----------|------|
| **人类** | 无特殊限制 | 主导种族 |
| **亚人**（兽人/龙人/半龙人） | 体能为主，魔法偏少 | 地位低，为奴者多；战斗级天赋可与人类平起平坐 |
| **精灵**（普通/远古/黑暗） | 魔法为主，体能弱；偏远程 | 普通精灵居北脉/中脉森林 |

### 精灵分支

- **普通精灵**：无特殊亲和；北脉、中脉麓林
- **远古精灵**：失传远古魔法；寂语山脉（Silmor Range，北脉）

### 亚人

- 半龙人 = 蜥蜴、蛇等下等龙裔，不得与龙族等同
- 整片大陆均有分布

### 5.2 西平原三国

```
              [雷文堡王国]
                 北 · 丘陵要塞
                    ╱╲
    [灰谷王国]  ╱        ╲  [卡斯尔顿王国]
      西 · 农牧冶炼    东南 · 贸易商路
```

| 王国 | 方位 | 皇室 | 定位 | 与帝国 |
|------|------|------|------|--------|
| **雷文堡** Ravensburg | 北 | 雷文哈特 Ravenhart | 军事最硬 | 较独立 |
| **灰谷** Ashvale | 西 | 艾什伯恩 Ashborn | 物产最厚 | 较独立 |
| **卡斯尔顿** Castleton | 东南 | 霍尔维斯 Holvis | 贸易最活跃 | 依赖最深 |

**三国政体**：**封建分封 + 议会制**并行（三国共通框架；各国实施细节除灰谷外暂标占位）

#### 5.2.1 封建分封层级

| 层级 | 头衔 | 说明 |
|------|------|------|
| 一 | **国王**（King） | 名义最高统治者、名义最大封建领主 |
| 二 | **公爵 / 伯爵**（Duke / Count） | 受封大片领地，统辖数个男爵领 |
| 三 | **男爵**（Baron） | 受封一片领地（如**莱恩菲尔家**），向上效忠纳贡 |
| 四 | **骑士**（Knight） | 领主下属武装力量，可持小片采邑 |

- 效忠链：国王 → 公爵/伯爵 → 男爵 → 骑士；逐级纳贡、战时按约定出兵
- 领地内部：领主对佃农/农户有司法与征税权，治理近似庄园制
- **贵族头衔与天赋**：头衔世袭，但天赋净阶仍是个人能力的真实标尺——弱天赋贵族（如盖伦蒙纱）常转往文官仕途而非领兵治领（见 5.2.3）

#### 5.2.2 议会制（三级会议）

- 王国设**议会**（Estates / Parliament），由若干"等级"（Estate）构成：
  - **领主院**：公爵、伯爵、男爵等封建贵族
  - **教会席位**：【随剧情补充，视本作是否引入教会体系】
  - **市民院**：各大特许城市推举的代表，多为行会、商会领袖（见 5.2.3）
- **议会权力**：审议新税、王室重大决策（宣战、王位继承争议等）——**咨询与制衡**为主，最终裁决权仍归国王，非现代民主议会
- 三国各设议会，具体席位分配、召开频率等实施细节：**灰谷**见下；雷文堡、卡斯尔顿【随剧情补充】

#### 5.2.3 城市自治与官职体系（以灰谷城为例）

大型城市多为**特许自治城市**（Chartered City）：向王室缴纳固定税款 / 效忠换取自治权，不直属某个封建领主。治理权集中在**评议会与少数专职官员**手中，由城中望族与行会共治，**不是自上而下的层级衙门**——这更贴近真实中世纪西欧自由市镇（如汉萨同盟城市、英国的特许自治市）的**寡头共治**模式，而非中央集权式的科层制。

**市议会**（City Council / Common Council）：

| 职位 | 说明 |
|------|------|
| **市长**（Mayor / Lord Mayor） | 由评议会推举产生，任期制（如一年一任）；主持议会、对外代表全城——是"评议员之首"，不是独断的长官 |
| **评议员**（Alderman / Échevin） | 议会正式成员，多由城中望族或行会代表出任，常各自兼管一个城区或一项政务 |
| **行会代表**（Guild Warden / Guildmaster） | 各行会（商会、工匠会）推举产生，进入议会为本行发声，是城市政治的核心构成之一 |

**专职官员**（Warden / Officer）：经议会委任处理具体政务，未必本人是评议员：

| 官职 | 职责 |
|------|------|
| **司库**（Chamberlain） | 掌城市财库、税收账目 |
| **书记官**（Town Clerk / Recorder） | 文书、契约、法令存档 |
| **治安长**（Constable / Captain of the Watch） | 城市巡防、缉盗 |
| **营造总管**（Warden of Works） | 城墙、道路、桥梁修建维护 |
| **水利总管**（Warden of Waterworks） | 河道、灌溉、排水、水闸；灰谷"物产最厚"依赖此职维系农牧——**盖伦·莱恩菲尔现任此职** |
| **粮秣总管**（Warden of the Granary） | 储粮、赈灾 |

- **官职 ≠ 贵族头衔**：官职经议会委任产生；贵族头衔世袭。两者可并存于一人（如**盖伦·莱恩菲尔**：男爵家出身，同时任**水利总管**，让位家主后走文官仕途的具体落点；不是评议员，是议会委任的专职官员）
- 其他大城市的官职侧重可能不同，也不必照搬灰谷这套完全对应：雷文堡以军事立国，最高职位可能更接近戍卫总督（Warden / Governor）而非民选市长；卡斯尔顿"贸易最活跃"，行会代表与司库的话语权可能更重。具体差异：【随剧情补充】
