# 正文草稿（Drafts）

> **正文单一目录**：章节正文写在这里。预览/审阅时，**按大纲章名**找对应文件。

## 文件命名（与大纲对齐）

| 大纲章名 | 文件 |
|----------|------|
| **序章** | `prologue.md` |
| **第一章** | `chapter-001.md` |
| **第二章** | `chapter-002.md` |
| **第N章** | `chapter-NNN.md`（三位数字，N 与「第N章」一致） |

示例：预览 **第二章**（启程）→ `drafts/chapter-002.md`

## 与 bible 的关系

- 设定以 `bible/` 为准；正文不得擅自改写世界观。
- 旧目录 `chapters/` 如有遗留稿，以 **`drafts/`** 为准。
