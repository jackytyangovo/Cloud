## 主角

### 莉莉娅·莱恩菲尔（Lilia Lenfiel）

| 项目 | 内容 |
|------|------|
| 年龄/性别 | 6 岁女 |
| **作品分级** | **R18**（幼年主角无亲身 R18；可目睹配角成人向场面推动剧情） |
| 前世 | 25 岁男性（来源：【随剧情补充】） |
| 转生类型 | **男转女**；土著身体 + 觉醒之前世记忆（非肉体穿越） |
| 出身 | 灰谷王国 · 小贵族莱恩菲尔家 |
| 开局 | 距六岁天赋觉醒还有 1 个月；**第一章记忆觉醒** |
| 天赋（表） | **光系 · 净章**（仪式可读上限） |
| 天赋（隐） | **生命属性**（中期觉醒，可能揭示无垢） |
| 光系来源 | 遗传母亲莉安娜（平民），非父亲土系祖传 |
| **容貌** | **继承母亲居多**；幼时即**出挑**（见下「莱恩菲尔家容貌」） |

**容貌（✓ 已定 · 撰写用内部标尺，正文勿写「几分」）**：

| 阶段 | 标尺（10 满） | 说明 |
|------|-------------|------|
| **现时（6 岁）** | **7–8** | 从小就很惊艳；幼童身量下**尚难完全看出**终局，但已明显优于常人 |
| **成年后（预期）** | **9** | 随成长只会**越来越好看**；光系净章后关注度将与容貌叠加 |
| 对比 | 莱恩菲尔本家 **5–6**；母亲莉安娜 **8** + 身材姣好 | 「我」更像母亲，不像父亲一系 |

- **男转女心理**：对外貌**复杂**——承认「这一世长得好」，前世男性认知仍会带来不适与警惕。
- **社交后果**：**吸引目光** → 议论、搭讪、同辈**嫉妒** → 摩擦（Ch.4 夜聚等）；**长线**常引陌生人靠近（善意/恶意皆有），与权谋、R18 边界线挂钩（见 `outline.md`「容貌线」）。

**性格与缺陷**（撰写默认，可改）：

- 前世理性、习惯用结构思维分析问题
- 现世幼女身体限制行动，易焦躁
- 男转女身份摩擦持续；对「被宠爱」既依赖又不适
- 缺陷：过度依赖前世经验，忽视孩童身体的社交规则
- **目睹 R18 / 暗黑场面**：内心**完全看懂**（25 岁男忆），表面**装不懂**以隐藏觉醒、维持幼女形象

**天赋规则与代价**（卷一阶段）：

- 光系净章：仪式读数震撼，但 **6 岁几乎无实战输出**；须从冥想、感知魔力起步
- 生命（隐）：中期觉醒前无自觉；觉醒后代价【随剧情补充】

**角色弧光（卷一方向）**：

- 从「我是谁」的身份混乱 → 接受「这一世的莉莉娅」作为行动主体
- 从被保护者 → 开始用前世认知做有限主动选择

**联姻语境**：人类 **14 岁成年**、**最早 12 岁订婚**；莉莉娅 6 岁尚未触及，但光系净章后贵族圈可能**提前议论**其未来联姻价值。

## 莱恩菲尔家

### 莱恩菲尔家 · 容貌（✓ 已定）

> 内部标尺供撰写对照；**正文用具体描写，不写数字打分**。

| 范围 | 标尺（10 满） | 备注 |
|------|-------------|------|
| **家族整体**（洛伦、盖伦、埃里克等父系一脉） | **5–6** | 中等；不出挑，符合小贵族常貌 |
| **莉安娜**（母系） | **容貌 8 · 身材姣好** | 平民出身因貌嫁入；已故 |
| **莉莉娅** | 幼 **7–8** → 成年预期 **9** | **继承母亲更多**；越长越显 |

- 洛伦当年娶莉安娜，貌是重要原因之一（门第不对等时的常见补偿逻辑）。
- 莉莉娅在亲戚中「不像莱恩菲尔土系一家」的外貌，偶被私语。

### 盖伦·莱恩菲尔（Garen Lenfiel）— 伯父

| 项目 | 内容 |
|------|------|
| 天赋 | 土系 · **蒙纱** |
| 容貌 | **5–6** |
| 职务 | **灰港河域副监**（Underwarden of the Riverward · 河域官厅 Riverward） |
| 居住 | **灰港**（Grayport）盖伦府 |

**与主角**：家族长辈；埃里克、芬恩之父；让位家主给洛伦；**入城后于灰港府邸收留洛伦一行住客房**

**职务说明**：

- **河域长官**（River Warden）麾下**副官**；佐理内河航道、牌照、河运税等日常，无独立任命权。
- 小贵族任此职属常见路径：有实务与人脉，但位阶、话语权低于长官及大商贾；与关税官厅、港务官、商栈行会仍有往来。
- 天赋蒙纱偏弱，以**实务与协调**立足；洛伦守乡领、盖伦入城任副职，兄弟分工明确。

**叙事功能**：河运/码头线有限人脉（副官身份）；府邸为 Ch.4 灰港见闻起点；仪式后政治线可写「借长官渠道 vs 家族自保」的张力——盖伦本人**拍不了板**
