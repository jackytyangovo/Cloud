# 文风指南（Style Guide）

## 叙事视角

- **第三人称限知**，始终跟随主角 **伊莱娅·莱恩菲尔** 的感知与认知。
- 前世记忆可在内心独白中呈现，但与现世幼女身体的感受须形成持续摩擦（男转女、成人思维 × 孩童躯体）。

## 文风基调

- **偏克制叙事**：注重身份、阶级、天赋政治的张力，不堆砌形容词。
- **适度爽感节奏**：升级与天赋反馈要有，但不灌水；觉醒震撼写「影响」而非「碾压」。
- **综合型**：升级、生存、权谋、冒险四条线交织，单章可偏重其一，但不宜长期偏废。

## 章节惯例

| 项目 | 规范 |
|------|------|
| 目标字数 | 约 **3000 字/章** |
| 开篇 | 场景切入，避免大段设定说明 |
| 结尾 | 悬念断章，促使连续阅读 |
| 时间跳跃 | 章首简要标注（如「觉醒前二十三天」） |

## 战力与数值（撰写硬约束）

- **天赋净阶 = 上限**，不等于当前战力。
- 孩童高净阶（如埃里克明印、伊莱娅净章）**绝不能**在正面对抗中胜过成年修习数十年的法师（如洛伦澄纹）。
- 战力成长须体现：**魔力强度**、**魔力上限（MP 池）**、咒语熟练度、经验。
- 前期整体数值克制；高净阶概率指数级降低。

## 专有名词

- 首次出现：**中文（Western）**，如 伊莱娅·莱恩菲尔（Elia Lenfiel）。
- 净阶、元素、地名保持一致，以 `worldbuilding.md` 为准。
- 未设定内容标注 `【随剧情补充】`，不在正文擅自定稿。

## 四条叙事线（章节配比参考）

1. **个人成长线** — 身份、修炼、天赋代价
2. **势力权谋线** — 家族、王国、帝国博弈
3. **世界真相线** — 禁忌、种族、历史（长线，慢热）
4. **情感羁绊线** — 【随剧情补充】
