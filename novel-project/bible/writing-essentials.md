# 写作要领（纠察 / 写稿速查）

> **模仿对象（最高）**：[`finalized/prologue.md`](../finalized/prologue.md)——用户 **已满意的序章定稿**。写卷一/改第一章时，**先读、对照、学语气与节奏**；本文件是从该定稿与后续手改 **提炼出的辅助清单**，**不能代替**读序章正文。  
> **用途**：写稿/纠察时的 **自检与红灯**——宜学/勿学、模仿卡、写场六步。  
> **阅读顺序**：  
> ① **先读序章定稿** → ② **§一** 逻辑 → ③ **§三** 六步 → ④ **§三·附** 宜学/勿学 → ⑤ **§二** 红灯 → ⑥ **§〇** 卡（查漏/入库）→ ⑦ **§四** 自检。  
> **冲突优先**：用户最新手改 / 最新确认 > **序章定稿语感** > 本文件模仿卡 > `style-guide` > `#N` 档案。  
> **手改入库**：每处 → **一张模仿卡（§〇）** + `user-style-iteration-log` `#N`；能硬化 → 红灯表。  
> **档案**：[`user-style-iteration-log.md`](user-style-iteration-log.md)；样章泛化技巧见 `style-reference`（**次于**序章定稿）。

## 〇、用户手改 · 模仿卡（Agent 写前必读）

> **格式（固定，便于扫读）**  
> `### 卡名 · 一句话规则`  
> `✗` 用户删/打回的写法  
> `✓` 用户改定的写法  
> `→` 以后怎么写 / 禁什么  
> （可选）`为什么`：用户原话  
>  
> **原则**：一张卡只教一件事；优先贴 **真实改前/改后**；宁短勿空讲。

### 手改入库流程（硬）

1. **只对照用户改动**，不臆测未改处  
2. 每处手改 → **一张卡**（写入本节）+ log `#N`（改前/改后/提炼/为什么）  
3. 若成硬规则 → 同步 **红灯表** / `style-guide` 对应条  
4. **勿擅自改** `characters.md`（无用户点名）  
5. 用户说定稿 → 再同步 `finalized/`

### 读者看不懂 = 反例（硬 · ✓ 用户确认）

> 用户以 **读者视角** 问「××是什么 / 看不懂」→ 该词/该说法 **读者也看不懂** → **视为反例，正文须避免或改掉**。  
> Agent **同轮**：① 红灯表追加（或本条下「看不懂词表」）② 模仿卡一张（✗原词 ✓通俗替法）③ log 一条。  
> **改法**：换成一听就懂的说法；必要设定用 **简单词白说**，勿用生僻宅造词硬撑氛围。

| ✗ 看不懂（陆续追加） | ✓ 宜换 / 处理 |
|----------------------|----------------|
| **侧翼**（#104） | **客厢** / **客厢那边**；勿写「绳结在侧翼里」 |
| **叙述者无来源的全知句**（#105） | 须写清「我」怎么得知（亲耳/目睹/被告知），或删掉改由对话/眼前事带出 |
| **又满泥了吧？** 类（#106） | 改直说嗔怪：`又沾泥了！`；忌「……了吧？」假商量 |
| **举止比盖伦一系顺眼些**（#114） | 删；改可见：`眉眼生得软和`；禁「××一系」 |
| **尘气**（#122） | **干热气**；勿造「尘+气」含糊词——读者分不清在写尘还是气 |
| **你们这儿还是这么香**（#122） | 删；无情节/形象作用且读者看不懂在夸什么 |

### A · 感知与起笔

#### 卡A1 · 感官进身，少「我先」
- ✗ `我先闻见亚麻被褥的气味……`
- ✓ `涌入鼻腔的，是一股厚厚的亚麻被褥的气味……`
- → **视 → 嗅听 → 触**；气味/声音可直接扑面，少用「我先……」

#### 卡A2 · 外物先动，忌日记起笔
- ✗ `我追了猫。` / `我去了侧室。`
- ✓ `一只花猫从廊下窜了过来，我一时不知哪来的兴趣……` / `忽然想去看侧室里母亲的画像……`
- → 情节起笔：**外物/他人先动 → 我一时反应**；要即时感，不要流水账标题句

#### 卡A3 · 他人神态看脸，不写「语气里」
- ✗ `语气里带着一点打趣`
- ✓ `脸上透露着一点打趣`
- → 第一人称近环：**脸上/动作**；语气仅兜底

### B · 删 meta / 报告 / 替人总结

#### 卡B1 · 正文不出现章节 meta
- ✗ `与序章那些晨间热奶相比……` / `上一章……` / `男忆`
- ✓ 直接写气味、记忆、前世的我
- → 读者只活在当前场景里

#### 卡B2 · 禁止报告体归纳
- ✗ `所以我既知道……又……` / `两堆记忆缠在一起` / `一时松了，一时又绷着`
- ✓ 定名一句 / 顺叙一件事 / **一个**情绪落点
- → 不替读者做结构说明

#### 卡B3 · 禁止替人总结心理
- ✗ `像怕我也学舌` / `没拆台` / `像在说我多问也无妨` / `装出来的稳重垮了一截`
- ✓ 只写可见动作、对话、耳根红、尾音飘了
- → **动作写到即止**，不解释他人动机

#### 卡B4 · 禁止照办纲要入文
- ✗ `并不亲自动手` / `——不举高` / `——不抢主位` / `——不写让位旧事` / `**小把戏**`
- ✓ `仆役把菜一道道传上来；米拉替芬恩系上餐巾，低声嘱咐慢些`；搂孩子埋进呢料（不举高写成动作）
- → bible/大纲的「不×」是作者约束，**不是**正文句子

### C · 一句一意 / 篇幅

#### 卡C1 · 多句禁止只表一意
- ✗ `不像父亲一系平常相貌，倒更近侧室油画里的母亲`（两截=像母亲）
- ✓ `侧室油画里的母亲，缩成了六岁的样子。`（一句说完）
- → 同一信息只出现一次；容貌用**可看见的具体**，忌眉眼软/唇色淡套话

#### 卡C2 · 默认扩写 2–3 句
- ✗ 用户改一词，Agent 跟 5–8 句解释
- ✓ 只改点名处；未指定字数 → **两三句**
- → 打字不便时的删改指令 = **按语义删整句/整段**

#### 卡C3 · 通俗易懂，忌 Agent 臃肿
- ✗ 冗长因果、文言腔、英文入正文（`bustle`）
- ✓ 口语白描，一听就懂
- → 行文口气像讲故事

### D · 内心与身魂

#### 卡D1 · 内心直写，删前置标签
- ✗ `我心里想……` / `忍不住吐槽……`
- ✓ 直接写内心句（如：`我不是男的吗？！`）
- → 人格=前世、记忆=莉莉娅；穿越用昨晚/今早口语，不当场论文

#### 卡D2 · 身魂要物+心事，宜侧面
- ✗ 只写`没胃口`/`不习惯`/`这一世长成这样，我别扭`
- ✓ `黑面包粗硬……与前两天比`；镜段写完容貌 → `指尖在凳沿上按了按，目光挪开`
- → 卷一未适应期对照**不吝笔墨**，但忌口号式「别扭」

#### 卡D3 · 场末一个落点
- ✗ 章末排比：空碗/站直/装乖/灰港/仪场 checklist
- ✓ `我已经搞清楚……只剩莉莉娅·莱恩菲尔`；或裙料 vs 裤管一点收束
- → 每场结束读者须知道「落在哪」

### H · 第一章手改（从第一段起 · 持续追加）

> 用户说「从第一章第一段开始」后开启。下列为开场已收紧处；**你的新手改**继续往下贴，按处补卡。

#### 卡H1 · 章首勿报告「不说记忆」
- ✗ `远客还没到，宅里却先忙了。我仍不对任何人说记忆的事；白日里……——仍是莉莉娅会做的那些，只是跑起来时，膝盖和裙角总比我记得的更容易沾泥。`
- ✓ `远客还没到，宅里却先忙了。白日里我在内庭和侧廊间跑……膝盖和裙角总比记忆里更容易沾泥。`
- → 用跑、喊水、沾泥**演**幼身；删「不说记忆」「莉莉娅会做的那些」报告句

#### 卡H2 · 开场宜短句分行（外物先动）
- ✗ 绳结、仆役、父亲吩咐、艾娜交代挤在一两长句里
- ✓ 绳结一句 → 仆役一句 → 父亲吩咐 / 艾娜交代分行
- → 与序章开篇节奏对齐：一眼一事，少用分号串场

#### 卡H3 · 禁「侧翼」；写清是客厢、在绑行李
- ✗ `绳结在侧翼里勒紧又松开` / `侧翼里仆役来回搬铺盖`
- ✓ `客厢门口，行李绳勒紧又松开` / `客厢那边仆役来回搬铺盖`
- → **侧翼**读者不懂；地点用客厢/廊下等已出场词；绳子要落到**行李**上，勿悬空「绳结在×里」
- 为什么：用户（读者视角）问「侧翼是什么？为什么绳结在侧翼里？」

#### 卡H4 · 「我」得知的事须有渠道
- ✗ `父亲前两日吩咐过客厢。`（叙述直接抛事实，读者问：我怎么知道？）
- ✓ 删叙述句，改由艾娜对仆役说：「……老爷前天就吩咐过了，听见没有？」——「我」在柱根边听见
- → 限知：凡「我」知道的旧事，须 **亲耳/目睹/当时在场**；否则删，或让眼前对话带出
- 为什么：用户问「父亲前两日吩咐过客厢。我是怎么得知的？」

#### 卡H5 · 对话忌 AI 假商量尾
- ✗ `「哎哟我的小姐，您瞧瞧这鞋——又满泥了吧？」`
- ✓ `「哎哟我的小姐，瞧瞧您这鞋，又沾泥了！」`
- → 侍女嗔怪用 **直指+感叹**；忌「……了吧？」「满不满」式软确认（听着像 AI）
- 为什么：用户问「又满泥了吧？这是 ai 才会说的话吧？」

#### 卡H6 · 破折号外貌勿插进「却」字句
- ✗ `艾娜瞪我一眼——深褐发挽得紧——却把壶里温水分我半杯`
- ✓ 发色前置：`她深褐发挽得紧，「嘘」着……`；转折保持：`艾娜瞪我一眼，却把壶里温水分我半杯`
- → **却**表转折，中间禁塞外貌补丁；发色与发型可另句/先前写（亦合发色发型分场）
- 为什么：用户指出插句突兀，打乱「却」的转折结构

#### 卡H7 · 发色序章已写，章内勿无故再点
- ✗ `又伸手替我把发梢深紫的那绺别到耳后`（序章已写深紫；此处无新信息）
- ✓ `又伸手替我把耳后那绺头发别好`
- → 已出场形象 **不重复报色**；只写当下动作。对照需要时（如栗发一家 vs 紫发）再点
- 为什么：用户指出序章已提发色，这里多余

#### 卡H8 · 对话说明白，忌对人讲谜语
- ✗ 叙述可用：`远客还没到，宅里却先忙了。`  
  对话忌：`「远客要来呢，别在廊下疯跑啊」`
- ✓ `「盖伦老爷他们就要到了，别在廊下疯跑啊，听见没？」`
- → **环境叙述**可抽象（远客、那边）；**人物对「我」说话**须落到人名/关系，切忌谜语
- 为什么：用户指出「远客还没到」叙述没问题，但艾娜对我说话不该用「远客」

#### 卡H9 · 陌生新场：环境由远及近、动态写
- ✗ `午后，土路扬起尘，车马铃从坡底拖上来，一下，又一下。`（太薄）
- ✓ 日头/院石 → 坡底反光与黄尘 → 铃→蹄→车停院门、马喷白气（远→近，动起来）
- → 读者完全陌生的新环境，忌一句交代；要看见东西**过来**
- 为什么：用户指出新一场太简单，须由远及近动态描写

#### 卡H10 · 情节有头有尾，勿只写结果
- ✗ 人已在栏边看车（缺：怎么发现、怎么过来、车如何停、谁迎接）
- ✓ 院中玩 → 远处看见马车 → 好奇跑到栏边注视 → 车到门口停下 → 父亲出门迎接
- → 一场戏：**起因—过程—落点**写满；用户确认此动线饱满
- 为什么：用户描述并确认「这样有头有尾而且很饱满」

#### 卡H11 · 句末语气词须有明确口气
- ✗ `「站这儿看就行，别探出去，啊？」`（「啊？」说不清：求应？商量？软化？）
- ✓ `「站这儿看就行，别探出去，听见没？」`（艾娜叮嘱口癖，要回应）
- → 语气词要能回答「想表达什么」；答不上来就换掉。忌悬空「，啊？」
- 为什么：用户问「最后一个语气词是想表达什么？」

#### 卡H12 · 禁电报式人物形象
- ✗ `先下来的是盖伦伯父——敦厚相，身形壮实，栗发，脸圆，笑时整张脸舒开。`
- ✓ `车帘一掀，先下来的是盖伦伯父。肩宽背厚，栗发被风掀起一点，圆脸上的笑比脚步还先到。他一把抓住父亲的手……`
- → 首次出场可写外貌，但须 **嵌进动作/先后**；忌破折号后「词，词，词」清单（圣经词「敦厚相」尤勿直接入文）
- 为什么：用户指出「人物形象电报式描写又来了」

#### 卡H13 · 谁赶路、谁问路上
- ✗ 盖伦（远来）问洛伦：「路上顺不顺呀？」／又问车轴、宿处（主客颠倒）
- ✓ 父亲问：「路上顺不顺？」盖伦答：「顺！车轴也结实……」父亲：「客厢收拾好了，先进去歇。」
- → 对话先问：**谁刚赶完路？** 远来者答路况；主人管安置。忌套用寒暄模板反客为主
- 为什么：用户问「赶路的不是伯父一家吗，为什么变成伯父问父亲路上顺不顺？」

#### 卡H14 · 说话动作勿用单字「应」
- ✗ `我应：「好呀。」`
- ✓ `我扬起脸，答得脆生：「好呀。」`
- → 「回答」要用 **多个词** 写出神态/动作；忌 `我应/他道` 电报引语（「应了一声」作轻应答可留）
- 为什么：用户问说话动作不应是「应」这种单字，想表达回答就多写几个词

#### 卡H15 · 禁「××一系」与词不搭配的比较
- ✗ `举止比盖伦一系顺眼些`（举止≠顺眼；「一系」是设定黑话）
- ✓ 删比较；写可见可闻（浅金发、理碎发、声音软）
- → 好看就写眉眼/脸；忌 bible 缩略「父系/盖伦一系」入正文；忌用错搭配硬比
- 为什么：用户问「举止比盖伦一系顺眼些是什么玩意？」

#### 卡H16 · 对人说话前要有可见神态
- ✗ `再转向我，伸手理我额前碎发，声音也软：「……」`（只有动作，脸是空的）
- ✓ `再转向我，眼里先漾开一点笑，伸手理我额前碎发，声音也软：「……」`
- → 第一人称近环：先看见 **脸/眼的神态**，再动作与话；忌纯动作流水
- 为什么：用户指出只有动作太单调，要加上「我看到的人物神态」

#### 卡H17 · 同类动作再现用「再」呼应前文
- ✗ 前有`欠了欠身`见伯父，后见伯母又写`我欠身：「伯母好。」`（两处平摆，无勾连）
- ✓ `我再欠身：「伯母好。」`
- → 同一场里 **重复相近礼节/动作** 时，用「再」与前文勾连，形成节奏呼应；勿每次都像第一次
- 为什么：用户改「我欠身」→「我再欠身」，与上文「欠了欠身」前后呼应

#### 卡H18 · 父系同姓用「堂」不用「表」
- ✗ `表哥埃里克` / `莉亚表妹` / `表姐` / `表弟哥`（盖伦是伯父＝父之兄）
- ✓ `堂哥埃里克` / `莉亚堂妹` / `堂姐` / `堂兄弟`；出场可写`堂弟芬恩`
- → **堂**＝父系同姓（伯父/叔父子女）；**表**＝母系或姑舅姨旁系。莱恩菲尔两房互称 **一律堂**
- 为什么：用户问「埃里克为什么是表哥？表不是母系亲戚的称呼吗？」

#### 卡H19 · 称谓可贴名前置；发色勿同场连复
- ✗ `那孩子一头栗发，探头探脑的` + `最后下来的是堂哥埃里克。他也是一头栗发`
- ✓ `那孩子探头探脑的` + `埃里克堂哥最后下来。他也是一头栗发`
- → **称谓可贴名前置**（`埃里克堂哥`／`堂弟芬恩`皆可）；同场后文将点发色时，先出场的孩子 **先不复写**发色，留「也是」给后到者
- 为什么：用户手改删芬恩「一头栗发」，并把「最后下来的是堂哥埃里克」改为「埃里克堂哥最后下来」

#### 卡H20 · 耳根红后宜短补一笔可见神态
- ✗ `埃里克耳根红到脖子；他转向我……`
- ✓ `埃里克耳根红到脖子，忙把下巴压低；他转向我……`
- → 脸红之后 **再加≤10字可见动作/神态**（宜呼应前文，如刚「下巴微抬」→「忙把下巴压低」），勿只停在血色描写
- 为什么：用户要求「耳根红到脖子」扩写神态，10字以内，使其更形象

#### 卡H21 · 对照贴「我」所想；客观事实禁用「像是」
- ✗ `我瞧着车边这一家，栗发一个色；只有我辫梢那点深紫，像是从母亲那边单独落下来的。`
- ✓ `车边这一圈莱恩菲尔们中，伫立着一抹与众不同的黯紫。见面的招呼结束了，不再多虑，我抬腿跟上了已经走入内院的父亲。`
- → 发色/家系对照可以写，但须是 **「我」一眼扫过时的内心意象**，不是旁白替读者总结；已知客观事实（紫发随母）**禁止**用「像是…」装比喻——那是废话
- 为什么：用户指出须时时刻刻维持第一人称代入；「像是从母亲那边单独落下来」把遗传事实假扮成不确定比喻

#### 卡H22 · 场切勿垫忙乱尾；对话勿缺称呼主语
- ✗ 已「跟上父亲入内院」后仍写仆役搬铺盖、盖伦一路让客；艾娜念叨「待会儿席上要乖啊。」
- ✓ 场切后只写 `回到宅里。`；「小姐，待会儿在席上可别闹腾了。」
- → **场景变换末尾**勿再堆无关忙乱；下一场用短句落地即可。人物对白须 **有称呼/主语**（仆对小姐先「小姐」），忌结构残缺的 AI 嘱咐句
- 为什么：用户删进宅垫笔；改艾娜台词并指出「席上要乖啊」缺主语

#### 卡H23 · 落地短句可贴下句；禁含糊造词与空对话
- ✗ 单独成段 `回到宅里。`；`干热尘气`；盖伦喊「洛伦，你们这儿还是这么香！」+ 父亲应一声
- ✓ `回到宅里，艾娜领我去……`；`干热气`；删该句对白（及无着落的「应了一声」）
- → 场切落地 **逗号接下动作**（勿句号拆开）；气味词须一词一意；对话须服务情节或形象，读者一看就懂，否则删
- 为什么：用户要「回到宅里」连艾娜（逗号）；问「尘气」写尘还是气；盖伦「这么香」无用且看不懂

#### 卡H24 · 禁场标起笔；对照须有前文可溯
- ✗ `晚宴在大厅。`（日记场标）；`比父亲那晚饭桌边的一闪更久`（晚宴未写此闪）
- ✓ 从「进大厅时…」入场；对照用**已写/已听**记忆（如序章父亲掌心土块儿）
- → 新场用动作/感官进入，勿「××在××。」标签句；凡「比刚才/那晚…」须前文真有

#### 卡H25 · 旁听勿写大纲缩略词串
- ✗ `父辈那边仍说着赴城、住府、同程`
- ✓ `盖伦还在说进城、住府、两家同路`；「我」只留听感/远近感
- → 旁听写**听见的白话**，禁把大纲节拍词塞进叙述

#### 卡H26 · 近距勿复写同一光感
- ✗ 上段「烛火把窗棂照得发亮」→ 下段「烛火已经把长桌照亮了」
- ✓ 上段已写烛火 → 进场只写「进大厅」+ 菜/热气/人
- → **同一光/声/气味** 刚写过，隔一两句勿换个宾语再报一遍

## 一、纠察总原则

### 一句话

**感官进身 → 外物先动 → 内心直写 → 设定白说 → 身魂对照写透 → 场末一个落点；删 meta、删 Agent 废话、删东方宫廷语感。**

### 五层逻辑（用户手改在反复做的事）

| 层级 | 追求什么 | 典型操作 |
|------|----------|----------|
| **感知** | 读者跟着身体进场 | 涌入鼻腔；脸上而非语气里；视→嗅听→触 |
| **删 meta** | 正文只留可演画面 | 删报告体、「信不信」、前世毛病声明 |
| **口语白描** | 一听就懂 | 饭后非早膳；天赋/仪式直说；通俗对举 |
| **身魂线** | 卷一现代我 vs 莉莉娅身写透 | 「我不是男的吗」；午饭粗陋；熬夜 vs 早睡 |
| **场末落点** | 每场一个清楚收束 | 又多松一口气；躲不过的大事；我已经搞清楚 |

### Agent 与用户分歧（必记）

| Agent 习惯 | 用户改法 | 规则 |
|------------|----------|------|
| 扩写 5–8 句解释 | 删或 **2–3 句** | 未指定字数默认两三句 |
| 「我心里…」「忍不住…」 | **直写**内心 | 省略前置标签 |
| 两堆/既知道/理不清 | **一团记忆 + 定名一句** | 忌报告体 |
| 早膳/用膳/小几/空箸 | **饭后/大厅/小桌/空匙** | 西方中世纪宅 |
| 我追了猫 / 我去了侧室 | **猫窜来 / 我忽然想** | 外物先动；我主动 |
| 帮用户「补全」未点名印象 | **整段撤回** | 只写用户点名的句意 |
| 章末归纳多天事项 | **身魂单段收** | 忌排比 checklist |

### 卷一模仿优先级（高→低）

1. 身魂对照 · 感官链 · 内心直写  
2. 通俗易懂 + 2–3 句扩写 · 外物先动  
3. 中世纪用语 · 仆主应答  
4. 情绪单一落点 · 近距不重复  
5. 设定直说 · 首次称谓（堂哥/堂弟）  
6. 第一章续：§〇 **H 卡** + 红灯 #20–#41

## 二、红灯表（见即打回）

| # | 违规 | 改法 |
|---|------|------|
| 1 | **meta**：写「序章」「上一章」「男忆」等跳出叙事层 | 删；正文只用读者能懂的说法 |
| 2 | **报告体**：「所以我既知道……」「两堆记忆」「一时松一时绷」 | 定名一句 / 顺叙 / **单一情绪落点** |
| 3 | **替人总结**：「像怕我也学舌」「没多戳破」「像在说我多问也无妨」 | 动作写到即止，不解释他人心理 |
| 4 | **照办纲要**：「并不亲自动手」「照孩」「#2」「**不写**××」「**不举高**」等 bible/大纲缩略或否定约束入文 | 改日常动作/对话；**禁止**把「不写/不×」提纲句与 markdown 加粗技法写进正文 |
| 5 | **日记起笔**：「我追了猫」「我去了侧室」 | **外物/他人先动** → 我一时反应 |
| 6 | **身份标签滥写**：「是幼童特有的……」（全章至多一二处） | 用动作、心理、神态呈现 |
| 7 | **内心前置**：「我心里……」「忍不住吐槽」 | **直写**内心句 |
| 8 | **语气优先**：「语气里带着打趣」 | **脸上/动作** 近环；语气仅兜底 |
| 9 | **近距重复**：刚说过的地点再罗列一遍 | 用指代（「父亲说的那些地方」） |
| 10 | **东方宫廷语**：膳、餐室、空箸、小几、杂役 | **大厅、饭后、空匙、小桌、仆从** |
| 11 | **午饭在大厅/饭桌** | **端进卧房**；午后 **出了卧房** |
| 12 | **仆对主人单「嗯」** | **「好的，小姐。」**（可单独成行） |
| 13 | **只写没胃口/不习惯**（卷一未适应期） | **心事 + 具体物**（粗硬/咸/淡；与前两天比） |
| 14 | **场末 checklist** 排比回顾 | **一个落点**；「我已经搞清楚」 |
| 15 | **Agent 废话**：未点名扩写、5–8 句解释、英文入正文 | **2–3 句**；只写点名句意 |
| 16 | **【附】悬空**（前文无专名） | 先叙事引入专名，再附；无词则删附 |
| 17 | **高级知识**提前点破（澈冕、公会章程等） | 常识可写；高级等剧情到了再写 |
| 18 | **幼年主角亲身 R18** | 禁止；目睹须标【R18·目睹】且服务剧情 |
| 19 | **多句只表一意**（废话连篇）：两句/两截反复说同一意思 | **同一信息只写一次**；见下「反例」 |
| 20 | **读者看不懂的词**：用户以读者视角追问的词/说法 | **视为反例**；换通俗说法或简单白说；入库「看不懂词表」+ 模仿卡 |
| 21 | **无来源全知**：「我」未目睹/未听说却写出事实（如「父亲前两日吩咐过…」） | 写清得知渠道，或改由对话/眼前动作带出；见卡 H4 |
| 22 | **AI 腔对话**：软绵确认句、假商量尾（「……了吧？」「……呢吧？」） | 改成人口语：直指、感叹、嗔怪；见卡 H5 |
| 23 | **破折号插入打断转折**：`瞪我一眼——发色——却……` | 发色/外貌另句或前置；**却**前后只留动作对照；见卡 H6 |
| 24 | **已写过的发色/外貌再点一次**（无新信息） | 删；动作即可（「别好耳后那绺」） |
| 25 | **人物对话讲谜语**：用「远客」等抽象称呼对「我」说话 | 对话须说明白（人名/关系）；抽象词仅限环境叙述；见卡 H7–H8 |
| 26 | **新场环境一句了事**（陌生场景） | **由远及近、动态写**；见卡 H9 |
| 27 | **情节只有结果没有过程**（如人已在栏边） | 写清发现→靠近→抵达→应对，有头有尾；见卡 H10 |
| 28 | **悬空语气词**：句末「，啊？」说不清在求应、叮嘱还是软化 | 改成明确口气（「听见没？」/感叹号）；见卡 H11 |
| 29 | **电报式形象**：`——敦厚相，身形壮实，栗发，脸圆，……` | 外貌拆进动作/反应里写，忌破折号后顿号清单；见卡 H12 |
| 30 | **赶路/主客颠倒**：远来者问主人「路上顺不顺」 | 谁赶路谁答；主人问或来客自报；见卡 H13 |
| 31 | **说话动作用单字电报**：`我应：「……」` | 写成完整动作/神态+答（扬起脸、答得脆生等）；见卡 H14 |
| 32 | **设定黑话入文**：`盖伦一系`、`举止比…顺眼`（词不搭配/读者莫名） | 写可见眉眼/动作；禁「××一系」；见卡 H15 |
| 33 | **对话前只有动作链**：转向、伸手、理发，无「我」看见的神态 | 加可见脸/眼（漾笑、眉眼等）；见卡 H16 |
| 34 | **同场重复礼节无勾连**：第二次欠身仍写「我欠身」 | 用「再欠身」等与前文呼应；见卡 H17 |
| 35 | **堂/表称谓用错**：父系同姓写成「表哥/表妹/表姐」 | 盖伦房称 **堂哥/堂弟/堂姐/堂妹**；见卡 H18 |
| 36 | **假比喻废话**：用「像是…」包装已知客观事实（如紫发随母） | 事实直说或干脆不说；对照改「我」的所见/内心意象；见卡 H21 |
| 37 | **旁白式对照丢代入**：第三人称总结外貌差异，无「我」的看见/想象 | 以内心一闪的意象承载，对照完立刻回到「我」的动作；见卡 H21 |
| 38 | **场切末垫笔**：情节已入下一空间，仍堆仆役/声量等无关忙乱 | 删；下一场用短句落地（如「回到宅里。」）；见卡 H22 |
| 39 | **对白缺称呼/主语**：`待会儿席上要乖啊` 类残句 | 补称呼与完整祈使（「小姐，……可别闹腾了」）；见卡 H22 |
| 40 | **含糊造词**：`尘气` 等一词两意、读者分不清指什么 | 拆成明白词（`干热气`）；入看不懂词表；见卡 H23 |
| 41 | **空对话**：不推进情节、不立形象、读者看不懂在说什么 | 删（连带无着落的应答）；见卡 H23 |
| 42 | **场标起笔**：`晚宴在大厅。` 类标签句 | 用进场动作/感官起笔；见卡 H24 |
| 43 | **假回调**：比附前文未写之事 | 只对照已写/已听；见卡 H24 |
| 44 | **大纲缩略入旁听**：赴城/住府/同程等节拍词串 | 改白话听见的内容；见卡 H25 |
| 45 | **近距复写同一光感**：窗棂烛火刚写完又写长桌烛火 | 换感官落点或删；见卡 H26 |

### 反例 · 多句只表一意（#95 · 铜镜段）

**✗ 打回（笼统老套 + 同义叠写）**  
> ……便撞上一张幼小的脸——眉眼软，唇色淡，鼻尖还带着一点未醒的红；编好的发贴着肩，整张脸不像父亲一系那种平常相貌，倒更近侧室油画里的母亲。

问题：①「眉眼软/唇色淡/鼻尖红」空泛套话；②「不像父系平常」与「更近母亲」**两截只表达「像母亲」一个意思**。

**✓ 宜学**  
> ……铜光里映出光洁的额角，两根没压住的碎发翘着；瞳仁深，睫毛投下一排细影，颊侧还鼓着软肉——侧室油画里的母亲，缩成了六岁的样子。

## 三、写场六步（对照序章定稿）

| 步 | 做什么 | 宜学例 |
|----|--------|--------|
| 1 | **视 → 嗅听 → 触**；少「我先……」 | 涌入鼻腔的，是一股厚厚的亚麻… |
| 2 | **外物/他人先动** | 花猫从廊下窜过来 → 一时不知哪来的兴趣 |
| 3 | **动作链**可连串；幼体加乖乖/下意识 | 刚一用力就酸…乖乖躺回去 |
| 4 | **对话** + 脸上/动作；仆敬称分行 | 艾娜脸上一点打趣；「好的，小姐。」 |
| 5 | **身魂**（卷一）：物 + 心事；**宜侧面**（动作/挪开视线），忌直说「这一世/别扭/不习惯」 | 黑面包粗硬…与前两天比；镜中只写容貌，不适用动作带过 |
| 6 | **单点收束** | 我已经搞清楚…只剩莉莉娅·莱恩菲尔 |

### 章末收束型（序章 #86–#87 · 宜学）

- **身份落点**：上一世荡然无存 → 只剩这一世的莉莉娅·莱恩菲尔  
- **判断完成态**：「至少有一件事**我已经搞清楚**」（非「清楚了」）  
- **身魂最后一击**：惯于熬夜 vs 中世纪睡得格外早 → 翻来覆去  
- **忌**：空碗/试额/装乖排比 checklist；场外再埋无关一线

## 四、交稿自检（两遍）

**落笔前 / 交稿前各扫一遍：**

1. 这段外物先动了吗？有无日记体？  
2. 有无报告体 / meta / 替人总结可删？  
3. 扩写是否超过三句，或写了用户没点的意思？  
4. 卷一有无身魂对照（还是只写没胃口）？  
5. 场末是不是一个落点？有无 checklist？  
6. 有无膳/小几/箸/餐室，或近距重复地点？  
7. 内心是否直写？他人神态是否先看脸？  
8. 有无英文、提纲语、bible 缩略入正文？  
9. 有无读者看不懂的词 / 含糊造词 / 空对话？（红灯 #20 #40 #41）  
10. 对话是否缺称呼主语？是否 AI「……了吧？」？（H5 / H22）  
11. 第一人称代入还在吗？有无假比喻「像是」包装事实？（H21）  
12. 父系称谓是否用「堂」？（H18）

## 五、视角与设定（硬）

| 项 | 要领 |
|----|------|
| **人称** | 主段严格「我」；短段第三人称旁白可补设定/场面，单次宜短，结束立刻回「我」 |
| **限知** | 不写「我」当时不可能知道的事（除非事后交代） |
| **未启蒙** | 可写异象，不可用「我」点破术式/净阶定名；专名靠对话或后文启蒙 |
| **设定** | 先叙事引入专名 → 「A是……，B则是……」直说；【附】只释本节已出现词 |
| **常识 vs 高级** | 觉醒/四系/净阶民间档/维洛日常 = 常识；澈冕、教廷编制、MP 池等 = 高级 |
| **正文专名** | 只写中文；Western 仅留 bible |
| **四层** | 每章兼顾：动作、神态语言、环境、心理；序章环境约 45–55% |
| **字数** | 约 3000 字/章；约每 1000 字一处小高潮 |

## 七、人物与场面（卷一速记）

| 点 | 要领 |
|----|------|
| **写哪章查哪区** | `characters.md` 只取当前章区；勿用后续状态写当前 |
| **发色 / 发型** | 发色恒定（主角紫系、父系栗、艾娜深褐、米拉浅金）；发型按章区；可分场写；男子短发默认不写发型 |
| **首次出场** | 容貌/体态一两笔；亲属带称谓（堂哥/堂弟） |
| **贵族宅** | 夫人照孩、督内务；**仆役布菜**，夫人不亲传盘 |
| **亲族到客** | 先与主人见礼再顾妻儿；不在门前举高戏耍孩童 |
| **盖伦** | 对洛伦不叫「哥」；声大热络 |
| **对话** | 口语+语气词；每人口癖区分；配动作一行 |
| **身体喜剧** | 6 岁尺度（绊裙、磕膝）；不用 R18 余韵 |
| **战力** | 净阶≠即战力；孩童高净阶不碾压成年修习者 |

## 八、日常成长期（卷一）

**4 要**：微型升级 · 生活冲突降维 · NPC 人情味（须与「我」双向互动）· 设定融入吃喝拉撒  

**4 不要**：打卡流水账 · 过早致郁 · 无敌无事 · 圣母/怨妇  

**章自查三问**（至少中三）：小成长正反馈？会心一笑/配角可爱？事件主动或有趣生活麻烦？NPC 是否对我说话/做事？

## 九、纠察 / 手改工作流（本角色）

```
写稿/纠察：
1. **先读** `finalized/prologue.md`（模仿对象）
2. 再按：§一 → §三 → §三·附 → §二 → §〇（查漏）→ §四
3. 打开本章 drafts/*.md；对照序章语气写/改
4. 违规 → 先回序章找同类写法，再按模仿卡 / 宜学表重写 → 再扫一遍
5. rebuild preview + push

用户手改到达后（推送 / 粘贴 / 点名改句）：
1. 逐处 diff：只记用户改了什么
2. 每处 → §〇 新增一张模仿卡（✗/✓/→）
3. log 追加 #N（改前/改后/提炼/为什么）
4. 能硬化 → 同步红灯表 / style-guide
5. 用户若说定稿 → 复制到 finalized/
```

**「全文」= 当前章**；未点名不改他章。  
用户逐条改：只改点名处；「X删掉」= 按语义删整句。
