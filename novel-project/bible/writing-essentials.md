# 写作要领（纠察 / 写稿速查）

> **用途**：把 `style-guide` · `style-reference` · `user-style-iteration-log` · `daily-growth-writing` · `characters` · `WORKFLOW` 等 **提炼成一份可执行清单**。  
> **定位**：**纠察与交稿自检的主对照表**；细则仍以各源文件为准，冲突时以 **用户最新确认 / 序章 pass 入库条** 优先。  
> **对纠察的帮助**：有。逐段打回时先过本文件「红灯表」与「场次六步」，比来回翻多份长文更快、更稳；发现新反例再回填本表。

---

## 一、纠察总原则（一句话）

**感官进身 → 外物先动 → 内心直写 → 设定白说 → 身魂对照写透 → 场末一个落点；删 meta、删 Agent 废话、删东方宫廷语感。**

---

## 二、红灯表（见即打回）

| # | 违规 | 改法 |
|---|------|------|
| 1 | **meta**：写「序章」「上一章」「男忆」等跳出叙事层 | 删；正文只用读者能懂的说法 |
| 2 | **报告体**：「所以我既知道……」「两堆记忆」「一时松一时绷」 | 定名一句 / 顺叙 / **单一情绪落点** |
| 3 | **替人总结**：「像怕我也学舌」「没多戳破」「像在说我多问也无妨」 | 动作写到即止，不解释他人心理 |
| 4 | **照办纲要**：「并不亲自动手」「照孩」「#2」「**不写**××」「**不举高**」等 bible/大纲缩略或否定约束入文 | 改日常动作/对话；**禁止**把「不写/不×」提纲句与 markdown 加粗技法写进正文 |
| 5 | **日记起笔**：「我追了猫」「我去了侧室」 | **外物/他人先动** → 我一时反应 |
| 6 | **身份标签滥写**：「是幼童特有的……」（全章至多一二处） | 用动作、心理、神态呈现 |
| 7 | **内心前置**：「我心里……」「忍不住吐槽」 | **直写**内心句 |
| 8 | **语气优先**：「语气里带着打趣」 | **脸上/动作** 近环；语气仅兜底 |
| 9 | **近距重复**：刚说过的地点再罗列一遍 | 用指代（「父亲说的那些地方」） |
| 10 | **东方宫廷语**：膳、餐室、空箸、小几、杂役 | **大厅、饭后、空匙、小桌、仆从** |
| 11 | **午饭在大厅/饭桌** | **端进卧房**；午后 **出了卧房** |
| 12 | **仆对主人单「嗯」** | **「好的，小姐。」**（可单独成行） |
| 13 | **只写没胃口/不习惯**（卷一未适应期） | **心事 + 具体物**（粗硬/咸/淡；与前两天比） |
| 14 | **场末 checklist** 排比回顾 | **一个落点**；「我已经搞清楚」 |
| 15 | **Agent 废话**：未点名扩写、5–8 句解释、英文入正文 | **2–3 句**；只写点名句意 |
| 16 | **【附】悬空**（前文无专名） | 先叙事引入专名，再附；无词则删附 |
| 17 | **高级知识**提前点破（澈冕、公会章程等） | 常识可写；高级等剧情到了再写 |
| 18 | **幼年主角亲身 R18** | 禁止；目睹须标【R18·目睹】且服务剧情 |

## 三、写场六步（对照序章定稿）

| 步 | 做什么 | 宜学例 |
|----|--------|--------|
| 1 | **视 → 嗅听 → 触**；少「我先……」 | 涌入鼻腔的，是一股厚厚的亚麻… |
| 2 | **外物/他人先动** | 花猫从廊下窜过来 → 一时不知哪来的兴趣 |
| 3 | **动作链**可连串；幼体加乖乖/下意识 | 刚一用力就酸…乖乖躺回去 |
| 4 | **对话** + 脸上/动作；仆敬称分行 | 艾娜脸上一点打趣；「好的，小姐。」 |
| 5 | **身魂**（卷一）：物 + 心事；**宜侧面**（动作/挪开视线），忌直说「这一世/别扭/不习惯」 | 黑面包粗硬…与前两天比；镜中只写容貌，不适用动作带过 |
| 6 | **单点收束** | 我已经搞清楚…只剩莉莉娅·莱恩菲尔 |

## 四、交稿自检（两遍）

**落笔前 / 交稿前各扫一遍：**

1. 这段外物先动了吗？有无日记体？  
2. 有无报告体 / meta / 替人总结可删？  
3. 扩写是否超过三句，或写了用户没点的意思？  
4. 卷一有无身魂对照（还是只写没胃口）？  
5. 场末是不是一个落点？有无 checklist？  
6. 有无膳/小几/箸/餐室，或近距重复地点？  
7. 内心是否直写？他人神态是否先看脸？  
8. 有无英文、提纲语、bible 缩略入正文？

## 五、视角与设定（硬）

| 项 | 要领 |
|----|------|
| **人称** | 主段严格「我」；短段第三人称旁白可补设定/场面，单次宜短，结束立刻回「我」 |
| **限知** | 不写「我」当时不可能知道的事（除非事后交代） |
| **未启蒙** | 可写异象，不可用「我」点破术式/净阶定名；专名靠对话或后文启蒙 |
| **设定** | 先叙事引入专名 → 「A是……，B则是……」直说；【附】只释本节已出现词 |
| **常识 vs 高级** | 觉醒/四系/净阶民间档/维洛日常 = 常识；澈冕、教廷编制、MP 池等 = 高级 |
| **正文专名** | 只写中文；Western 仅留 bible |
| **四层** | 每章兼顾：动作、神态语言、环境、心理；序章环境约 45–55% |
| **字数** | 约 3000 字/章；约每 1000 字一处小高潮 |

## 六、用语速查

| ✓ 用 | ✗ 不用 |
|------|--------|
| 大厅、饭后、快吃完时 | 早膳/用膳/晚膳、餐室 |
| 仆从、空匙、小桌、窗棂 | 杂役、空箸、小几 |
| 书斋、管事间、客厢 | 小账房、东方宫廷空间名 |
| 前世的我 / 前世的记忆 | 男忆 |
| 父亲说的那些地方 | 隔几行再列内庭、侧廊… |
| 与前两天 / 与原来的字迹 | 动辄「与我前世…」声明 |

**仆主**：仆→「好的，小姐。」；「我」对仆可「嗯」。  
**用餐**：晨/晚大厅同桌；午饭仆人端进卧房。

## 七、人物与场面（卷一速记）

| 点 | 要领 |
|----|------|
| **写哪章查哪区** | `characters.md` 只取当前章区；勿用后续状态写当前 |
| **首次出场** | 容貌/体态一两笔；亲属带称谓（堂哥/堂弟） |
| **贵族宅** | 夫人照孩、督内务；**仆役布菜**，夫人不亲传盘 |
| **亲族到客** | 先与主人见礼再顾妻儿；不在门前举高戏耍孩童 |
| **盖伦** | 对洛伦不叫「哥」；声大热络 |
| **对话** | 口语+语气词；每人口癖区分；配动作一行 |
| **身体喜剧** | 6 岁尺度（绊裙、磕膝）；不用 R18 余韵 |
| **战力** | 净阶≠即战力；孩童高净阶不碾压成年修习者 |

## 八、日常成长期（卷一）

**4 要**：微型升级 · 生活冲突降维 · NPC 人情味（须与「我」双向互动）· 设定融入吃喝拉撒  

**4 不要**：打卡流水账 · 过早致郁 · 无敌无事 · 圣母/怨妇  

**章自查三问**（至少中三）：小成长正反馈？会心一笑/配角可爱？事件主动或有趣生活麻烦？NPC 是否对我说话/做事？

---

## 九、纠察工作流（本角色）

```
1. 打开本章 drafts/*.md（finalized/ 未点名不定稿覆盖）
2. 逐段对照「红灯表」+「写场六步」
3. 违规段：打回 → 按正例重写 → 再扫一遍
4. 记入 user-style-iteration-log（改前/改后/提炼）
5. rebuild preview + push；书签用 preview 分支
```

**「全文」= 当前章**；未点名不改他章。  
用户逐条改：只改点名处；「X删掉」= 按语义删整句。
