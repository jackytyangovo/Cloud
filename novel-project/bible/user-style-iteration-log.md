# 用户文风迭代记录 · 序章定稿 pass

> **用途**：用户以个人写作手法修改序章时，**逐条记录**每一次改动；定稿 pass 结束后 **汇总分析**，提取规则并 **高优先级** 写入 `style-guide.md` / `style-reference.md` / 写作 skill。  
> **Agent 约束**：用户指定修改时 **只改用户说的部分**；未点名段落 **不动**。  
> **删改解读**：用户打字不便时指令可能不完整（如「记忆中很漂亮删掉」= 删整句「记忆中的画里的人很漂亮，」）；**按语义删整句/整段**，删后若留半截残句则一并收干净，**不要**只抠字面词片。  
> **扩写默认**：用户授权 Agent 扩写而未指定字数时，**两三句即止**；一句比喻或感官 + 一句对举即可，不铺长链。  
> **写作自检**：落笔与交稿前各 **对照 `style-guide` / 本 pass 提炼想一遍**（单字描写、比喻扣前文、第一人称、扩写篇幅等），**多思考两遍**，勿写完才补规范。  
> **行文默认**（✓ #31）：**通俗易懂**——像口头转述、读者一听就懂；忌叠床架屋（#30 式长串解释）。对举句宜 **短、白、带一点语气**（呢、吧），不必把每个词都解释满。  
> **设定直说**（✓ #36）：常识设定 **用最简单词汇直说**（「天赋是……」「觉醒仪式则是……」），**不必**严格套莉莉娅限知口吻。**须接在专名首次出现之后**，**勿删**引入该专名的叙事句。  
> **省略号**（✓ #44）：用户写 **「……」/「…..」** = **由 Agent 补具体细节**（如「昨晚还在……」→ 补「赶论文」），**勿**留「说不清」等占位。  
> **不加废话**（✓ #44）：**只写用户点名的句意**；不叠用户未说的解释、归纳、身体动作链。  
> **感官优先级**（✓ #49 · 已入库）：**视 → 嗅、听 → 触**；**语气** 等 **仅当视听嗅触皆无效** 时才写。  
> **内心独白**（✓ #50）：第一人称 **可省略**「我心里……」「忍不住吐槽」等 **前置定语**，**直写**内心句。  
> **卷一·身魂对照**（✓ #70）：**第一卷**、尚未完全适应新身份新生活时，遇 **不符前世现代生活认知** 之事（饮食、器物、礼俗等）→ **不吝笔墨** 写 **心事 + 前世对照** 双层（如午饭 **粗陋难咽**）；适应后 **再收**。忌只点「没胃口/不习惯」一笔带过。  
> **全局**（✓ 2026-07-19）：**章节纲要 + 正文** 均须 **严格参照** 写作规范；见 `WORKFLOW.md` · **写作规范适用范围**。
