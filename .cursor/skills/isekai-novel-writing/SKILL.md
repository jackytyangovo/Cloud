# 异世界重生小说 · 写作 Skill

本 skill 汇总当前定稿的**写作方法与硬约束**。细节以 `novel-project/bible/` 为准；本文件供 Agent **写正文前必读、改稿时对照**。

## 何时启用

- 撰写、润色、扩写 `novel-project/drafts/` 下章节
- 用户要求检查文风、附块、剧透、维洛教表述
- 修改正文后需重建 `preview/standalone.html`

## 单一事实来源

| 路径 | 用途 |
|------|------|
| `bible/outline.md` | 当前章节拍、卷一边界 |
| `bible/style-guide.md` | 文风、视角、R18、附块 |
| `bible/style-reference.md` | 样章语感与节奏参考 |
| `bible/worldbuilding.md` | 世界观、维洛教、魔法制度 |
| `bible/characters.md` | 人物、容貌标尺、行为默认 |
| `drafts/prologue.md` 等 | 正文（可改） |

**正文不得擅自定稿** bible 中 `【随剧情补充】` 的内容；发现冲突时指出并请用户/Composer 补 bible。

## 写前清单（按顺序）

1. 读 `outline.md` 中**当前章**场景与「不写」列表
2. 读上一章正文，保持衔接与视角标记一致

5. 写完后自检：文风、附块、剧透、单字、维洛教、卷一边界

## 叙事视角

### 第一视角最高优先级（✓ 用户确认 · 写正文时第一条自检）

- 正文 **必须** 严格 **第一人称「我」**——所见、所闻、所感、所忆，均经 **「我」当下或可追溯的经验** 呈现
- **禁止** 跳出叙事层（如「序章」「上一章」「莉莉娅的记忆告诉我……」式元叙述）
- **禁止** 报告体归纳（「我懂，是……」「把……拼起来：……」「像分工，不像吵架」式替读者总结）
- **禁止** 模糊单字/指代（如「那种慢」「领」「声低」→ 写清楚：日子怎样慢、领地上、声音压得很低）
- **禁止** 作者说明式旁白（如「——没有在宅门前举高，因为……」；规则只写在 bible/skill，**不进正文**）

### 主视角：第一人称「我」（莉莉娅）

- 读者所见以「我」的感知为界；**不写入「我」当时不可能知道的信息**（除非事后得知并交代）
- **序章 / 未启蒙段**：环境仅感官与幼女常识；**不得**用「我」点破魔法专名（咒痕、净阶、术式名）——可写所见异象，不可下定名判断
- 专名由**他人对话**、**【附】块**或后文启蒙带入

### 辅视角：偶尔第三人称限知旁白

- 用于：环境/场面、设定短补、他人限知（检测官、洛伦别处的反应）
- **单次宜短**（一般不超过一章 20%）；一章内不宜连续多段
- 切换：空行 + 第三人称，或 `※` / `——` 引导（全书统一一种）
- 旁白段结束**立即回「我」**；仍保持平直，忌百科体

### 世界观短插（序章场 2 等）

- 可用第三人称呈现**莉莉娅原记忆**中的常识；限于幼女所知
- 单次 ~1000 字内；用 `※` 或空行标界；结束回「我」
- **短插结束后忌总结复述**：禁止「这就是 XX 知道的事：……」式报告体；不归纳前文已写信息，直接接具体场景切回

## 文风硬规则（用户多次确认）

### 总原则：读者先看懂

- **平直简单**：意思能直说就直说
- **忌**费解隐喻、拟人、象征式省略（如「油画替大人说话」「热闹日子的色块」）

### 句法

- **长短句结合**：环境/神态/动作可写细、可写长
- **同一句内忌** 2–3 字短语连续铺陈（如「窗大。光落。肩宽。指粗。」）
- 宜以复句、从句串联，关键处再用短句点睛
- **忌强求对仗/排比**：自然流畅优先于句式整齐

### 用词

- **忌电报式省略**（如「发挽得紧」「今日安静」「不算最虔的人」→ 写完整自然句）
- **少用单字指代**（「领」→ 领地/领地上；「红」→ 红印；「声低」→ 声音压得很低）
- 汉字多义，优先**多字词语**，意思写清楚
- **正文禁用「男忆」**；须写 **「前世的我」**「前世的记忆」
- bible 提纲可用简称，**drafts/ 正文禁用**

### 身份错位

- 忌反复用「带着幼童……」「是幼童特有的……」等**直接标签句**（全章至多一二处）
- 余以心理、神态、动作呈现男转女 friction

### 比喻

- 本体与喻体不可重复

### 人物形象（✓ 用户确认）

- **`characters.md` 按章区形象表**：写第 N 章只取 **对应章区**；定稿后 **回填** 该章区行
- **首次实写**：带容貌或体态一两笔
- **侧面描写** 烘托；画像可写很漂亮

### 贵族宅邸礼仪（✓ 用户确认）

- **夫人/伯母**：照孩、礼数、内务 **督理**；**不**亲自动手布菜传盘（仆役/侍女上菜）
- **亲族称谓**：盖伦为 **伯父**（洛伦之兄）；兄弟对话 **不叫**洛伦「哥」——易与「我」视角的伯父身份混淆；可用「还是偏莉亚」「这话在理」等
- **到客宅**：先与主人见礼，再顾妻儿；不在主人家门前 **举高戏耍** 孩童
- **孩童装大人**：长辈 **笑而不戳破**，正文已写出的，删直白点破句

## 设定知识分级（✓ 硬规则）

> 详见 `style-guide.md`「设定知识分级」。写前先分类：

| | 常识 | 高级知识 |
|---|------|----------|
| **何时出现** | 随时：正文、对话、【附】 | 仅经学习/专业场合/特殊途径 |
| **净阶** | 浊痕→净章名号与民间好坏；【附】可写细 | 澈冕、无垢、与即战力关系、比例 |
| **元素** | 风、火、水、土四系；**光、暗、电** 少见但 **知其名** | 冰、生命、死灵、空间及光暗电 **精确比例与修习规则** |
| **教会** | 维耶洛、教父、乡村教堂、轮徽、温养院/圣息使耳闻 | 教堂三级、司铎编制、教廷、按立路径 |
| **专名** | 中文即可 | Western 原文 **不进正文** |

## 【附】设定块（硬规则 · 必遵守）

### 何时插入

读者需对齐、而 **「我」当时说不深** 的名词，在**第一次出现处下方**插入【附】。

### 写什么

- **常识类**（净阶各档、四元素等）：主角本就知晓，**可略写细**
- **半常识**（温养院、圣息使）：各一句
- **高级知识**：**不进附**，等剧情带入

### 禁止写什么

- 教堂三级、司铎编制等 **高级知识**
- 剧透、重复、总结前文
- 正文/附块内 **`**` 强调专名**

### 专名与英文

- **`drafts/` 正文仅中文**，不写 Western 对照
- **`bible/`** 保留中英对照

## 每章四层（比重可浮动）

| 层次 | 要求 |
|------|------|
| 人物动作 | 具体可见行为，尤其幼女身体限制；**符合人设** |
| 神态与语言 | 表情、语气、对话；**首次出场宜带容貌/体态**；言行 **服务 `characters.md` 形象** |
| 环境变化 | 场景、天气、光线、声响、陈设随情节推移 |
| 主角心理 | 「我」的内心：前世与现世摩擦、判断与情绪 |

设定**融入**以上四层，避免大段说明文。

### 序章 / 初入新世界

- 环境认知宜占全章 **约 45–55%**
- 心理短句穿插；重点在**开启这一世生活**

### 前世对照

- **须有具体落点**（觉醒制度 vs 无魔法、男体/女体差异、具体物件）
- **笼统模糊则不写**（「不像前世」「要是以前」等空对照属废话）

## 主角与家庭（撰写默认）

- **莉莉娅 / 莉亚**：6 岁女；男转女 + 序章觉醒**前世的我**（刚毕业男学生，**不展开**履历）
- **天赋（表）**：光系净章；**（隐）** 生命属性中期再写
- **光系来源**：遗传母亲莉安娜，非父亲土系
- **小名**：父亲/近侍称 **莉亚**；文书/仪场用 **莉莉娅**
- **莱恩菲尔家**：维洛信众、**非虔**；偶尔赴**乡村教堂**；宅内**无教堂**，有**初光轮徽**、**莉安娜画像**（侧室）
- **领上礼拜**：**教父**主持，**非**司铎常驻

## 维洛教 · 教堂三级（bible 高级知识 · 正文前期不写）

> 以下供 bible 对照；**卷一序章–前期正文属高级知识**，勿写进【附】或「我」之口。

> **编制逻辑**：**有高级神职的教堂** → 下辖**完整低级编制**；**仅设低级神职的教堂** → **不设**高级神职常驻。

| 层级 | 规模 | 常驻神职 |
|------|------|----------|
| **大教堂** | 都城 | **司铎**（高级）+ **执事、辅祭** + 礼颂官、圣器监、书记副官 |
| **分区教堂** | 大城市 | **执事、辅祭**、读经员、传谕使；**无司铎** |
| **乡村教堂** | 乡间聚落 | **教父、修女**；**无司铎、无执事** |

### 觉醒仪式（常规仪礼）

- **六岁觉醒**的 **初光祝** 由 **分区教堂** 依例主持
- 属**常规**仪礼，**非**隆重大典；**执事**即可，**不必司铎到场**
- **检测**由世俗官/法师主持
- ✗ 不写「须大教堂派司铎诵初光祝」

### 大圣礼 vs 常规礼

- 洗礼、婚礼、葬仪等**大圣礼**须司铎 → 分区/乡村由大教堂**派司铎临时代行**，或信众赴城
- 初光祝**不属于**须司铎到场的大圣礼

### 写作触点

- 教义 **ambient 默认**（约 99% 信教）；勿长篇布道
- 触点：轮徽、远钟、教堂、温养院/圣息使闲谈
- **初光之选**：民间可附会光系净章——**非**教义强制、**非**教廷册封（保留伏笔）

## 卷一边界（硬 · 违反即错）

**卷一**：序章–第二十九章；6→7 岁；主场景领地 + 灰港第二幕。

### 可写

- 觉醒倒计时、家族日常、赴灰港、仪式、回领、赛温课表
- 提及婚约制度背景（「十二岁才订」），**无「我」订婚情节**
- 维洛 ambient：轮徽、远钟、乡村教堂礼拜闲谈

### 不写

- 盖伦一家**到场**（序章可耳闻）
- 灰港**实写**（序章）
- 净章结果、赛温、联姻情节发展、王室、学院入学
- 宅内教堂、教宗亲见、异端审判
- 联姻/订婚/婚约政治、王室及政治高层直接接触 → **中期**

### 序章特限（Day 0）

- **单日**、**不出领地**
- 空间：宅邸及紧连内庭
- 可写：记忆觉醒、莉安娜画像、觉醒名册耳闻、维洛 ambient
- 不写：仪场实写、净章、灰港实写

## 战力与数值（硬约束）

- **天赋净阶 = 上限**，≠ 即战力
- 6 岁净章**不能**碾压成年修习数十年的法师（如洛伦澄纹）
- 孩童高净阶（埃里克明印、莉莉娅净章）正面对抗**绝不能**胜成年法师
- 成长须体现：魔力强度、MP 池、咒语熟练度、经验
- 觉醒震撼写「**影响**」而非「碾压」

## R18 边界

| 类型 | 卷一幼年「我」 |
|------|----------------|
| 主角亲身 R18 | **禁止** |
| 目睹他人 | **允许**（outline 标【R18·目睹】） |
| 主角成年后 | 标【R18·主角】后再写 |

**目睹写法**：

- 内心：**前世的我**完全看懂
- 外在：装孩童困惑/害怕/懵懂（社交伪装）
- 双层叙述：外在反应 + 内心评判
- 须服务剧情，禁止无铺垫福利

## 卷一前期基调（第二–四章）

- **生活记录感**：日常所见所感为主

## 常见错误（立即改正）

| 错误 | 正确 |
|------|------|
| 领上司铎 / 领上执事 | 领上只有**教父、修女** |
| 觉醒须司铎到场 | **分区教堂执事**依例主持，常规仪礼 |
| 大教堂无执事辅祭 | 大教堂有司铎 **及** 完整下级编制 |
| 附块写教堂三级/司铎编制 | 主角不知→**不进附**；留 bible |
| 「这就是莉莉娅知道的事：……」 | **删**；记忆段后直接接场景 |
| 「我懂，是盖伦一家」/「那种慢」 | **删**；改亲闻亲见或具体动作感官 |
| 盖伦对洛伦称「哥」 | **改**；盖伦为 **伯父/兄长**，洛伦为弟；兄弟对话用「还是偏莉亚」「这话在理」等 |
| 夫人/伯母「布菜」 | **改**；**仆役/侍女**上菜，夫人 **照孩** |
| 到客宅举高戏耍孩童 | **改**；**先与主人见礼**，再 **及腰间**搂子，不举高 |
| 长辈点破「别装大人」 | **改**；**笑而不戳破**，读者自见 |
| 作者说明式「——因为……」 | **删**；只写动作与场面 |
