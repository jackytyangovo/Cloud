# 定稿正文（Finalized）

> **只读归档**：此处为已定稿章节快照，**不与** `drafts/` 自动双向同步。  
> **预览**：有定稿则同步本目录；无定稿时才读 `drafts/`。

## 规则（✓ 用户确认）

| 规则 | 说明 |
|------|------|
| **写入** | **仅当**用户明确说 **「章节定稿」**（或同等指令）时，Agent 才可复制/更新本目录 |
| **禁止** | 日常改稿、润色、预览重建 **不得** 修改 `finalized/` 下任何文件 |
| **草稿** | 继续写在 `drafts/`；定稿时 **复制快照** 到本目录，文件名与 drafts 对齐 |
| **预览** | **定稿优先**：`finalized/` 有该章 → 用定稿；否则用 `drafts/` 初稿 |

| **第N章** | `chapter-NNN.md` |
