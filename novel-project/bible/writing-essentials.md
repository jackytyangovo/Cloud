# 写作要领（纠察 / 写稿速查）

> **模仿对象（最高）**：[`finalized/chapter-001.md`](../finalized/chapter-001.md)——用户 **已满意的正叙开篇定稿**（原序章《错位的清晨》，2026-07-20 顺延为第一章）。写卷一/改稿时，**先读、对照、学语气与节奏**；本文件是从该定稿与后续手改 **提炼出的辅助清单**，**不能代替**读第一章定稿。  
> **用途**：写稿/纠察时的 **自检与红灯**——宜学/勿学、模仿卡、写场六步。  
> **阅读顺序**：  
> ① **先读第一章定稿** → ② **§一** 逻辑 → ③ **§三** 六步 → ④ **§三·附** 宜学/勿学 → ⑤ **§二** 红灯 → ⑥ **§〇** 卡（查漏/入库）→ ⑦ **§四** 自检。  
> **冲突优先**：用户最新手改 / 最新确认 > **第一章定稿语感** > 本文件模仿卡 > `style-guide` > `#N` 档案。  
> **手改入库**：每处 → **一张模仿卡（§〇）** + `user-style-iteration-log` `#N`；能硬化 → 红灯表。  
> **结构**：序章拟 **插叙**（暂空）；**正叙自第一章**。  
> **档案**：[`user-style-iteration-log.md`](user-style-iteration-log.md)；样章泛化技巧见 `style-reference`（**次于**第一章定稿）。

## 〇、用户手改 · 模仿卡（Agent 写前必读）

> **格式（固定，便于扫读）**  
> `### 卡名 · 一句话规则`  
> `✗` 用户删/打回的写法  
> `✓` 用户改定的写法  
> `→` 以后怎么写 / 禁什么  
> （可选）`为什么`：用户原话  
>  
> **原则**：一张卡只教一件事；优先贴 **真实改前/改后**；宁短勿空讲。

### 手改入库流程（硬）

1. **只对照用户改动**，不臆测未改处  
2. 每处手改 → **一张卡**（写入本节）+ log `#N`（改前/改后/提炼/为什么）  
3. 若成硬规则 → 同步 **红灯表** / `style-guide` 对应条  
4. **勿擅自改** `characters.md`（无用户点名）  
5. 用户说定稿 → 再同步 `finalized/`  
6. **发散表达／多种写法**（用户让「多想几种」「还有什么方式」等）→ 先列选项；**同轮询问**是否收入「写法备忘」；**未确认勿擅自收录**

### 读者看不懂 = 反例（硬 · ✓ 用户确认）

> 用户以 **读者视角** 问「××是什么 / 看不懂」→ 该词/该说法 **读者也看不懂** → **视为反例，正文须避免或改掉**。  
> Agent **同轮**：① 红灯表追加（或本条下「看不懂词表」）② 模仿卡一张（✗原词 ✓通俗替法）③ log 一条。  
> **改法**：换成一听就懂的说法；必要设定用 **简单词白说**，勿用生僻宅造词硬撑氛围。

| ✗ 看不懂（陆续追加） | ✓ 宜换 / 处理 |
|----------------------|----------------|
| **侧翼**（#104） | **客厢** / **客厢那边**；勿写「绳结在侧翼里」 |
| **叙述者无来源的全知句**（#105） | 须写清「我」怎么得知（亲耳/目睹/被告知），或删掉改由对话/眼前事带出 |
| **又满泥了吧？** 类（#106） | 改直说嗔怪：`又沾泥了！`；忌「……了吧？」假商量 |
| **举止比盖伦一系顺眼些**（#114） | 删；改可见：`眉眼生得软和`；禁「××一系」 |
| **尘气**（#122） | **干热气**；勿造「尘+气」含糊词——读者分不清在写尘还是气 |
| **你们这儿还是这么香**（#122） | 删；无情节/形象作用且读者看不懂在夸什么 |
| **烛花也爆了一下**（#132） | 删或改白话「烛火噼啪跳了一下」；「烛花」偏文言，读者易懵；若上句已有「菜换一轮」等时间交代则直接删 |
| **更硬／更坐实**（形容日子，#143/#146） | 若写压迫/紧张：**直写心口绷紧、躲不过**；勿含糊比较词藏着掖着 |
| **昨露的潮**（#134） | **一点潮气** |
| **嗓门高高兴兴**（#134） | **嗓门还是那么亮**；若前文有低声等对照，再写亮不算空复读（H46） |
| **离领的门槛**（#134） | **宅门已经落在车后**（白话可见） |
| **席散到后来**（#144） | 删；人已在场直接写「大人们还坐着……」；见卡 H45 |

### A · 感知与起笔

#### 卡A1 · 感官进身，少「我先」
- ✗ `我先闻见亚麻被褥的气味……`
- ✓ `涌入鼻腔的，是一股厚厚的亚麻被褥的气味……`
- → **视 → 嗅听 → 触**；气味/声音可直接扑面，少用「我先……」

#### 卡A2 · 外物先动，忌日记起笔
- ✗ `我追了猫。` / `我去了侧室。`
- ✓ `一只花猫从廊下窜了过来，我一时不知哪来的兴趣……` / `忽然想去看侧室里母亲的画像……`
- → 情节起笔：**外物/他人先动 → 我一时反应**；要即时感，不要流水账标题句

#### 卡A3 · 他人神态看脸，不写「语气里」
- ✗ `语气里带着一点打趣`
- ✓ `脸上透露着一点打趣`
- → 第一人称近环：**脸上/动作**；语气仅兜底

### B · 删 meta / 报告 / 替人总结

#### 卡B1 · 正文不出现章节 meta
- ✗ `与序章那些晨间热奶相比……` / `上一章……` / `男忆`
- ✓ 直接写气味、记忆、前世的我
- → 读者只活在当前场景里

#### 卡B2 · 禁止报告体归纳
- ✗ `所以我既知道……又……` / `两堆记忆缠在一起` / `一时松了，一时又绷着`
- ✓ 定名一句 / 顺叙一件事 / **一个**情绪落点
- → 不替读者做结构说明

#### 卡B3 · 禁止替人总结心理
- ✗ `像怕我也学舌` / `没拆台` / `像在说我多问也无妨` / `装出来的稳重垮了一截`
- ✓ 只写可见动作、对话、耳根红、尾音飘了
- → **动作写到即止**，不解释他人动机

#### 卡B4 · 禁止照办纲要入文
- ✗ `并不亲自动手` / `——不举高` / `——不抢主位` / `——不写让位旧事` / `**小把戏**`
- ✓ `仆役把菜一道道传上来；米拉替芬恩系上餐巾，低声嘱咐慢些`；搂孩子埋进呢料（不举高写成动作）
- → bible/大纲的「不×」、作者约束、**场景节拍词**，都不是正文句子；提纲只定情节。对白照搬节拍词 → 见 **H40**

### C · 一句一意 / 篇幅

#### 卡C1 · 多句禁止只表一意
- ✗ `不像父亲一系平常相貌，倒更近侧室油画里的母亲`（两截=像母亲）
- ✓ `侧室油画里的母亲，缩成了六岁的样子。`（一句说完）
- → 同一信息只出现一次；容貌用**可看见的具体**，忌眉眼软/唇色淡套话

#### 卡C2 · 默认扩写 2–3 句
- ✗ 用户改一词，Agent 跟 5–8 句解释
- ✓ 只改点名处；未指定字数 → **两三句**
- → 打字不便时的删改指令 = **按语义删整句/整段**

#### 卡C3 · 通俗易懂，忌 Agent 臃肿
- ✗ 冗长因果、文言腔、英文入正文（`bustle`）
- ✓ 口语白描，一听就懂
- → 行文口气像讲故事

#### 卡C4 · 部分提纲：按扩写密度，勿对齐整章总字数
- ✗ 用户只给**部分**情节短文，Agent 却把正文写到与完整第一章等长（三千字级）
- ✓ 参照的是「提纲→正文」的**扩写密度**；部分提纲目标约**一千多字**，不是对齐第一章总字数
- → 提纲未写到的后半（示法/回宅等）**不许提前写**；字数随已供提纲走
- 为什么：用户——我说一千多字，你这是不是有点多了……参考的是第一章提纲和正文的扩写密度，而不是对齐第一章的字数要求

### D · 内心与身魂

#### 卡D1 · 内心直写，删前置标签
- ✗ `我心里想……` / `忍不住吐槽……`
- ✓ 直接写内心句（如：`我不是男的吗？！`）
- → 人格=前世、记忆=莉莉娅；穿越用昨晚/今早口语，不当场论文

#### 卡D2 · 身魂要物+心事，宜侧面
- ✗ 只写`没胃口`/`不习惯`/`这一世长成这样，我别扭`
- ✓ `黑面包粗硬……与前两天比`；镜段写完容貌 → `指尖在凳沿上按了按，目光挪开`
- → 卷一未适应期对照**不吝笔墨**，但忌口号式「别扭」

#### 卡D3 · 场末一个落点
- ✗ 章末排比：空碗/站直/装乖/灰港/仪场 checklist
- ✓ `我已经搞清楚……只剩莉莉娅·莱恩菲尔`；或裙料 vs 裤管一点收束
- → 每场结束读者须知道「落在哪」

### H · 第一章手改（从第一段起 · 持续追加）

> 用户说「从第一章第一段开始」后开启。下列为开场已收紧处；**你的新手改**继续往下贴，按处补卡。

#### 卡H1 · 章首勿报告「不说记忆」
- ✗ `远客还没到，宅里却先忙了。我仍不对任何人说记忆的事；白日里……——仍是莉莉娅会做的那些，只是跑起来时，膝盖和裙角总比我记得的更容易沾泥。`
- ✓ `远客还没到，宅里却先忙了。白日里我在内庭和侧廊间跑……膝盖和裙角总比记忆里更容易沾泥。`
- → 用跑、喊水、沾泥**演**幼身；删「不说记忆」「莉莉娅会做的那些」报告句
- 为什么：用户手改开场，打回章首报告体（#102）

#### 卡H2 · 开场宜短句分行（外物先动）
- ✗ 绳结、仆役、父亲吩咐、艾娜交代挤在一两长句里
- ✓ 绳结一句 → 仆役一句 → 父亲吩咐 / 艾娜交代分行
- → 与序章开篇节奏对齐：一眼一事，少用分号串场
- 为什么：用户要求开场短句分行、外物先动（#102）

#### 卡H3 · 禁「侧翼」；写清是客厢、在绑行李
- ✗ `绳结在侧翼里勒紧又松开` / `侧翼里仆役来回搬铺盖`
- ✓ `客厢门口，行李绳勒紧又松开` / `客厢那边仆役来回搬铺盖`
- → **侧翼**读者不懂；地点用客厢/廊下等已出场词；绳子要落到**行李**上，勿悬空「绳结在×里」
- 为什么：用户（读者视角）问「侧翼是什么？为什么绳结在侧翼里？」

#### 卡H4 · 「我」得知的事须有渠道
- ✗ `父亲前两日吩咐过客厢。`（叙述直接抛事实，读者问：我怎么知道？）
- ✓ 删叙述句，改由艾娜对仆役说：「……老爷前天就吩咐过了，听见没有？」——「我」在柱根边听见
- → 限知：凡「我」知道的旧事，须 **亲耳/目睹/当时在场**；否则删，或让眼前对话带出。旁听大人却**听不懂内容** → 另见 **H42**（勿编琐事名目）
- 为什么：用户问「父亲前两日吩咐过客厢。我是怎么得知的？」

#### 卡H5 · 对话忌 AI 假商量尾
- ✗ `「哎哟我的小姐，您瞧瞧这鞋——又满泥了吧？」`
- ✓ `「哎哟我的小姐，瞧瞧您这鞋，又沾泥了！」`
- → 侍女嗔怪用 **直指+感叹**；忌「……了吧？」「满不满」式软确认（听着像 AI）
- 为什么：用户问「又满泥了吧？这是 ai 才会说的话吧？」

#### 卡H6 · 破折号外貌勿插进「却」字句
- ✗ `艾娜瞪我一眼——深褐发挽得紧——却把壶里温水分我半杯`
- ✓ `艾娜瞪我一眼，却把壶里温水分我半杯`（发色勿在此复读——序章已写，见 **H7** / #141）
- → **却**表转折，中间禁塞外貌补丁；已出场发色**不要**为拆句而另起一句复读
- 为什么：用户指出插句突兀，打乱「却」的转折结构；后手改删「她深褐发挽得紧」

#### 卡H7 · 发色序章已写，章内勿无故再点
- ✗ `又伸手替我把白金发梢那绺别到耳后`（章内已写白金；此处无新信息）
- ✓ `又伸手替我把耳后那绺头发别好`
- → 已出场形象 **不重复报色**；只写当下动作。对照需要时（如栗发一家 vs 白金发）再点
- 为什么：用户指出序章已提发色，这里多余

#### 卡H8 · 对话说明白，忌对人讲谜语
- ✗ 叙述可用：`远客还没到，宅里却先忙了。`  
  对话忌：`「远客要来呢，别在廊下疯跑啊」`
- ✓ `「盖伦老爷他们就要到了，别在廊下疯跑啊，听见没？」`
- → **环境叙述**可抽象（远客、那边）；**人物对「我」说话**须落到人名/关系，切忌谜语
- 为什么：用户指出「远客还没到」叙述没问题，但艾娜对我说话不该用「远客」

#### 卡H9 · 陌生新场：环境由远及近、动态写
- ✗ `午后，土路扬起尘，车马铃从坡底拖上来，一下，又一下。`（太薄）
- ✓ 日头/院石 → 坡底反光与黄尘 → 铃→蹄→车停院门、马喷白气（远→近，动起来）
- → 读者完全陌生的新环境，忌一句交代；要看见东西**过来**
- 为什么：用户指出新一场太简单，须由远及近动态描写

#### 卡H10 · 情节有头有尾，勿只写结果
- ✗ 人已在栏边看车（缺：怎么发现、怎么过来、车如何停、谁迎接）
- ✓ 院中玩 → 远处看见马车 → 好奇跑到栏边注视 → 车到门口停下 → 父亲出门迎接
- → 一场戏：**起因—过程—落点**写满；用户确认此动线饱满
- 为什么：用户描述并确认「这样有头有尾而且很饱满」

#### 卡H11 · 句末语气词须有明确口气
- ✗ `「站这儿看就行，别探出去，啊？」`（「啊？」说不清：求应？商量？软化？）
- ✓ `「站这儿看就行，别探出去。」` / 或偶用「听见没？」（**同场勿连用**，见 H36）
- → 语气词要能回答「想表达什么」；答不上来就换掉。忌悬空「，啊？」
- 为什么：用户问「最后一个语气词是想表达什么？」

#### 卡H12 · 禁电报式人物形象
- ✗ `先下来的是盖伦伯父——敦厚相，身形壮实，栗发，脸圆，笑时整张脸舒开。`

#### 卡H36 · 近距勿连用同一叮嘱套话 / 勿叠叙述

- ✓ `伯父已经吃完，靠在椅背上，跟父亲低声说着什么。`（「低声」可为后文嗓门亮留对照，见 H46）
- → 旁听若听不懂内容 → 只写**在说话**，勿编具体公务/琐事名目（与 H4 互补：H4＝有无得知渠道；本卡＝听见却不懂则勿写细）。人设再出现能否呼应 → **H46**
- 为什么：用户——伯父说什么琐事我肯定是听不懂的，这里写出来不恰当

#### 卡H43 · 城乡对照物须贴领地特色
- ✗ `他们却没见过我们领地上的坡和树`（哪儿都有坡和树，不够有领地特色）
- ✓ `他们却没见过我们领地上的牧场和牛羊`
- → 对举城里见闻时，领上物象要能代表**本领**（牧业、牲口、灰栅栏等），忌空泛山水词
- 为什么：用户——坡和树，不够有领地特色，换几样东西

#### 卡H44 · 用户点「笼统」须补具体感官（两三句）
- ✗ `累了就靠着粗树干坐，听叶子沙沙响`（止于笼统）；补细节时又写`路边草齐到小腿`（前文已有`草叶扫过小腿`）
- ✓ 树皮硌背、叶影风声混牧草热气、栅栏外牛羊挪蹄扬灰等；补环境时改`风一过，杂草就往后仰，又弹回来拍在裙摆上`
- → 用户说「有点笼统，多扩写两句」→ 按 **C2** 补两三句具体感官，勿只加空形容词；**对照本章前文**，换落点，忌同物同触复读
- 为什么：用户——有点笼统，多扩写两句；增添细节要对照本章前文避免重复

#### 卡H45 · 场切忌空转时间垫笔
- ✗ `席散到后来，大人们还坐在大厅里议事……`
- ✓ `大人们还坐在大厅里议事……`
- → 人已在场/场景已切，勿加「席散到后来／到后来／之后」等**无增量**时间套话
- 为什么：用户——席散到后来，删了

#### 卡H46 · 宜前后呼应；忌一味删除致单薄
- ✗ 见「嗓门亮」已写过 → 后文凡嗓门亮一律删（只剩「一拍椅背」等，文章变薄）
- ✓ 前文`跟父亲低声说着什么` → 后文`嗓门又亮起来`（一低一高，特征有着落）
- → 人设/感官**再出现**时，优先想能否与前文对照、呼应、反差；无对照的空复读才删。写作多采用前后呼应，一味删除只会让文章更单薄
- 为什么：用户——嗓门又亮了起来其实不用删……加上低声……这样一低一高形成照应，就不算重复了

#### 卡H47 · 说话词加「道」：生僻宜加，常见少加，控频
- ✗ `嚷：「好高——！」`；满篇`说道`/`问道`叠用
- ✓ 不常见：`嚷道：「好高——！」`；常见：`低声说：「慢些。」` / `转向父亲：「……」`（说、问一般不加道）；亦可单独`道：「你们去宅里逛逛罢。」`
- → **嚷、笑、喝、叹**等非常见说话词 → 习惯加**道**；**说、问**等常见词一般不加；单独「道」可表说话。全章**控制频率**，合理分配，避免「道」扎堆重复
- 为什么：用户——嚷这类不常见说话词以后加上嚷道；说、问一般不加道；有时单独一个道；要控制频率、合理分配

#### 卡H48 · 禁止主语不匹配
- ✗ `老橡树……——小丘顶上立着它，树冠又高又开`（后半「树冠」属树，前半结构却像挂在小丘上 → **主语不匹配**）
- ✓ `……——它遥遥立在一座小土丘上，树冠又高又开`（「它／树冠」同一主语：老橡树）
- → 一句（含破折号后续）里，前后成分必须挂在**同一清楚主语**上；禁主语错挂、张冠李戴。要学的是**禁止主语不匹配**，不是「禁倒装」或「必须沿用前句主语」
- 为什么：用户——禁止主语不匹配才是你要学到的东西

#### 卡H49 · 文学避复：同指多用词轮换
- ✗ 同场反复「眼眸」「眼眸」「眼眸」（或把眼／眼睛／眸一律改成同一个雅词）
- ✓ 眼／眼睛／眼眸／眸／眸子／瞳／目光／视线 等**错开使用**；除非强调或无合适替词，否则避免同一词高频复现
- → **文学式写法要避词汇重复**，不是「统一成一个词」；同义可指代处主动轮换
- 为什么：用户——眼睛和眼眸混用；文学式除非迫不得已要避免词汇重复频率过高；纠正 Agent「统一用眼眸」的误解

#### 卡H50 · 人称分轨：第一人称学章一/二；第三人称文学式
- ✗ 第三人称段写散装短判（「不是兔。体量不对。」）、报告体收束（「只剩一个决断：……」）、游戏腔（「单挑」）；或把第三人称写成卷一幼年「我」口吻
- ✓ **第一人称**对标第一章、第二章定稿语感；**第三人称**走文学式：融复句、同指避复、心理外化为神态动作，收束落在可见行动
- → 序章篝火「我」≠ 暗林旁白；两轨勿混
- 为什么：用户——第一人称参考文本是第一、二两章，第三人称以文学式描写为准

#### 卡H51 · 第一人称为难段：忌提纲式左右拆 + 习惯清单
- ✗ `两人话锋一撞……去接，怕A；不接，又怕B。……揉碎发……唇张了张……——这种场面我没见过，站谁那边，一时想不明白。`
- ✓ `我胸口一紧。她要是回不来呢？喉咙发干，唇张了张，到底一个字也没吐出来。表面上我还站在火边，心里却是一团乱麻，不知道该站谁那边。……`
- → 对标章一「表面上……一团乱麻」：冲突已在对白里就别再「话锋一撞」复述；左右为难用口语问句，勿「去接／不接」提纲对仗；章内已亮过的揉发等习惯勿当紧张清单再叠一遍；禁「这种场面我没见过」类自我标签
- 为什么：用户——这一段写的很差，你有参考第一二章的文本进行写吗？

### 写法备忘 · 小孩子表达得意的写法

> 引用名：**小孩子表达得意的写法**。六岁「我」得意时用**可见动作**，少空写「得意地」。同章换**落点**（脚／下巴／胸／手／步），忌复读同一肢体。  
> **备忘收录规则**：用户让发散多种表达时，Agent **先问是否收录**；确认后再写入本节类「写法备忘」。

| 写法 | 用法感 |
|------|--------|
| 脚在凳下轻轻晃 | 心里美、还坐着时；同章已用则换别的 |
| 扬起下巴／扬一下下巴尖 | 小得意、带点指挥感；可配`得意道`（见 H47） |
| 挺胸／肩膀往后一沉 | 把「我认路」摆到台面上 |
| 鼻尖微微一翘 | 小孩得意常用；勿连用 |
| 笑得眼睛弯起来，辫梢多晃一下 | 声貌一起到 |
| 双手往腰后一背 | 小大人装派头 |
| 抬脚顿一下再领路 | 强调「跟我走」 |
| 故意放慢一步，等他们跟上 | 用节奏显「我熟」 |
| 拍拍裙摆／拍拍手再带队 | 收拾完再领人的小得意 |

- → 优先换**动作落点**；「得意地＋同一肢体」同章勿叠。正文例：`「那当然。」我扬起下巴，得意道，「我带路。」`

## 一、纠察总原则

### 一句话

**感官进身 → 外物先动 → 内心直写 → 设定白说 → 身魂对照写透 → 场末一个落点；删 meta、删 Agent 废话、删东方宫廷语感。**

### 五层逻辑（用户手改在反复做的事）

| 层级 | 追求什么 | 典型操作 |
|------|----------|----------|
| **感知** | 读者跟着身体进场 | 涌入鼻腔；脸上而非语气里；视→嗅听→触 |
| **删 meta** | 正文只留可演画面 | 删报告体、「信不信」、前世毛病声明 |
| **口语白描** | 一听就懂 | 饭后非早膳；天赋/仪式直说；通俗对举 |
| **身魂线** | 卷一现代我 vs 莉莉娅身写透 | 「我不是男的吗」；午饭粗陋；熬夜 vs 早睡 |
| **场末落点** | 每场一个清楚收束 | 又多松一口气；躲不过的大事；我已经搞清楚 |

### Agent 与用户分歧（必记）

| Agent 习惯 | 用户改法 | 规则 |
|------------|----------|------|
| 扩写 5–8 句解释 | 删或 **2–3 句** | 未指定字数默认两三句 |
| 部分提纲写成整章篇幅 | **约一千多字** / 按密度 | 勿对齐第一章总字数（C4） |
| 提纲节拍词塞进对白 | 人物口语（「我带路」） | H40；提纲≠台词 |
| 叙述者称谓塞进别人嘴 | 按说话人立场改 | H41 |
| 「我心里…」「忍不住…」 | **直写**内心 | 省略前置标签 |
| 两堆/既知道/理不清 | **一团记忆 + 定名一句** | 忌报告体 |
| 早膳/用膳/小几/空箸 | **饭后/大厅/小桌/空匙** | 西方中世纪宅 |
| 我追了猫 / 我去了侧室 | **猫窜来 / 我忽然想** | 外物先动；我主动 |
| 帮用户「补全」未点名印象 | **整段撤回** | 只写用户点名的句意 |
| 章末归纳多天事项 | **身魂单段收** | 忌排比 checklist |
| 见过的词一律删 | **前后呼应／反差** | 空复读才删（H46）；忌删薄 |

### 卷一模仿优先级（高→低）

1. 身魂对照 · 感官链 · 内心直写  
2. 通俗易懂 + 2–3 句扩写 · 外物先动  
3. 中世纪用语 · 仆主应答  
4. 情绪单一落点 · 近距不重复  
5. 设定直说 · 首次称谓（堂哥/堂弟）  
6. 第一章：§〇 **H1–H39 / H45** + 红灯 #20–#57、#64  
7. 第二章近野：§〇 **C4 / H40–H44** + 红灯 #58–#63（提纲≠台词；称谓合说话人；部分提纲篇幅）

## 二、红灯表（见即打回）

| # | 违规 | 改法 |
|---|------|------|
| 1 | **meta**：写「序章」「上一章」「男忆」等跳出叙事层 | 删；正文只用读者能懂的说法 |
| 2 | **报告体**：「所以我既知道……」「两堆记忆」「一时松一时绷」 | 定名一句 / 顺叙 / **单一情绪落点** |
| 3 | **替人总结**：「像怕我也学舌」「没多戳破」「像在说我多问也无妨」 | 动作写到即止，不解释他人心理 |
| 4 | **照办纲要**：「并不亲自动手」「照孩」「#2」「**不写**××」「**不举高**」等 bible/大纲缩略或否定约束入文 | 改日常动作/对话；**禁止**把「不写/不×」提纲句与 markdown 加粗技法写进正文；节拍词入对白见 **#58** / 卡 H40 |
| 5 | **日记起笔**：「我追了猫」「我去了侧室」 | **外物/他人先动** → 我一时反应 |
| 6 | **身份标签滥写**：「是幼童特有的……」（全章至多一二处） | 用动作、心理、神态呈现 |
| 7 | **内心前置**：「我心里……」「忍不住吐槽」 | **直写**内心句 |
| 8 | **语气优先**：「语气里带着打趣」 | **脸上/动作** 近环；语气仅兜底 |
| 9 | **近距重复**：刚说过的地点再罗列一遍 | 用指代（「父亲说的那些地方」） |
| 10 | **东方宫廷语**：膳、餐室、空箸、小几、杂役 | **大厅、饭后、空匙、小桌、仆从** |
| 11 | **午饭在大厅/饭桌** | **端进卧房**；午后 **出了卧房** |
| 12 | **仆对主人单「嗯」** | **「好的，小姐。」**（可单独成行） |
| 13 | **只写没胃口/不习惯**（卷一未适应期） | **心事 + 具体物**（粗硬/咸/淡；与前两天比） |
| 14 | **场末 checklist** 排比回顾 | **一个落点**；「我已经搞清楚」 |
| 15 | **Agent 废话**：未点名扩写、5–8 句解释、英文入正文 | **2–3 句**；只写点名句意 |
| 16 | **【附】悬空**（前文无专名） | 先叙事引入专名，再附；无词则删附 |
| 17 | **高级知识**提前点破（澈冕、公会章程等） | 常识可写；高级等剧情到了再写 |
| 18 | **幼年主角亲身 R18** | 禁止；目睹须标【R18·目睹】且服务剧情 |
| 19 | **多句只表一意**（废话连篇）：两句/两截反复说同一意思 | **同一信息只写一次**；见下「反例」 |
| 20 | **读者看不懂的词**：用户以读者视角追问的词/说法 | **视为反例**；换通俗说法或简单白说；入库「看不懂词表」+ 模仿卡 |
| 21 | **无来源全知**：「我」未目睹/未听说却写出事实（如「父亲前两日吩咐过…」） | 写清得知渠道，或改由对话/眼前动作带出；见卡 H4 |
| 22 | **AI 腔对话**：软绵确认句、假商量尾（「……了吧？」「……呢吧？」） | 改成人口语：直指、感叹、嗔怪；见卡 H5 |
| 23 | **破折号插入打断转折**：`瞪我一眼——发色——却……` | 发色/外貌另句或前置；**却**前后只留动作对照；见卡 H6 |
| 24 | **已写过的发色/外貌再点一次**（无新信息） | 删；动作即可（「别好耳后那绺」） |
| 25 | **人物对话讲谜语**：用「远客」等抽象称呼对「我」说话 | 对话须说明白（人名/关系）；抽象词仅限环境叙述；见卡 H7–H8 |
| 26 | **新场环境一句了事**（陌生场景） | **由远及近、动态写**；见卡 H9 |
| 27 | **情节只有结果没有过程**（如人已在栏边） | 写清发现→靠近→抵达→应对，有头有尾；见卡 H10 |
| 28 | **悬空语气词**：句末「，啊？」说不清在求应、叮嘱还是软化 | 改成明确口气（「听见没？」/感叹号）；见卡 H11 |
| 29 | **电报式形象**：`——敦厚相，身形壮实，栗发，脸圆，……` | 外貌拆进动作/反应里写，忌破折号后顿号清单；见卡 H12 |
| 30 | **赶路/主客颠倒**：远来者问主人「路上顺不顺」 | 谁赶路谁答；主人问或来客自报；见卡 H13 |
| 31 | **说话动作用单字电报**：`我应：「……」` | 写成完整动作/神态+答（扬起脸、答得脆生等）；见卡 H14 |
| 32 | **设定黑话入文**：`盖伦一系`、`举止比…顺眼`（词不搭配/读者莫名） | 写可见眉眼/动作；禁「××一系」；见卡 H15 |
| 33 | **对话前只有动作链**：转向、伸手、理发，无「我」看见的神态 | 加可见脸/眼（漾笑、眉眼等）；见卡 H16 |
| 34 | **同场重复礼节无勾连**：第二次欠身仍写「我欠身」 | 用「再欠身」等与前文呼应；见卡 H17 |
| 35 | **堂/表称谓用错**：父系同姓写成「表哥/表妹/表姐」 | 盖伦房称 **堂哥/堂弟/堂姐/堂妹**；见卡 H18 |
| 36 | **假比喻废话**：用「像是…」包装已知客观事实（如白金发随母） | 事实直说或干脆不说；对照改「我」的所见/内心意象；见卡 H21 |
| 37 | **旁白式对照丢代入**：第三人称总结外貌差异，无「我」的看见/想象 | 以内心一闪的意象承载，对照完立刻回到「我」的动作；见卡 H21 |
| 38 | **场切末垫笔**：情节已入下一空间，仍堆仆役/声量等无关忙乱 | 删；下一场落地接动作（如「回到宅里，艾娜…」）；见卡 H22 / H23 |
| 39 | **对白缺称呼/主语**：`待会儿席上要乖啊` 类残句 | 补称呼与完整祈使（「小姐，……可别闹腾了」）；见卡 H22 |
| 40 | **含糊造词**：`尘气` 等一词两意、读者分不清指什么 | 拆成明白词（`干热气`）；入看不懂词表；见卡 H23 |
| 41 | **空对话**：不推进情节、不立形象、读者看不懂在说什么 | 删（连带无着落的应答）；见卡 H23 |
| 42 | **场标起笔**：`晚宴在大厅。` 类标签句 | 用进场动作/感官起笔；见卡 H24 |
| 43 | **假回调**：比附前文未写之事 | 只对照已写/已听；见卡 H24 |
| 44 | **大纲缩略入旁听**：赴城/住府/同程等节拍词串 | 改白话听见的内容；见卡 H25 |
| 45 | **近距复写同一光感**：窗棂烛火刚写完又写长桌烛火 | 换感官落点或删；见卡 H26 |
| 46 | **NPC 单向互动**：「我」被点名打趣后无回应，像木头旁观 | 补话/动作/神态，形成双向；见卡 H27 |
| 47 | **念台词短拍**：热闹场每人一句电报对白，无过程 | 写成连贯动作链 + 「我」看见/反应；见卡 H28 |
| 48 | **无动机复读语气标签**：章内反复「声音软」「柔声」 | 删标签，留动作+台词；见卡 H29 |
| 49 | **绕口感官/「眉眼里」**：俏皮谜语式触感；神态用眉眼绕开脸 | 改直白（碟边烫手）；近环写 **脸上**；见卡 H30 |
| 50 | **缺主语 / 散装短句 / 无增量重复**（叙述三铁律） | 补主语；融复句；删废话；见卡 H31 |
| 51 | **关键信息日记一笔带过**：觉醒日子/仪场等只写「问了便答」 | 对话+「我」反应写清，或整段不写；见卡 H33 |
| 52 | **现代游戏名 / 武侠时位**：石头剪刀布、三息等 | 猜拳口语；白话时位；见卡 H34 |
| 53 | **「我」对长辈扮鬼脸等失礼** | 改乖乖笑/回礼；鬼脸仅同辈孩童；见卡 H35 |
| 54 | **近距连用同一叮嘱套话 / 叠叙述**：听见没？×2；等车帘掀开→车帘一掀 | 换说法或删；等待与发生勿同词复述；见卡 H36 |
| 55 | **含糊「更硬／更坐实」藏压迫感**：读者仍不懂在强调什么 | 直写心口绷紧、事压到眼前；见卡 H37 |
| 56 | **同章「耳根红」连用过多** | 换靠柱/捂嘴/肩抖等可见动作；见卡 H38 |
| 57 | **滥「不是A，是B」心理纠偏句**（澄清眼前所见可留） | 一句话直说正意；见卡 H39 |
| 58 | **提纲情节词当台词**：如「有浅径」 | 改人物口语（「我带路」）；见卡 H40 |
| 59 | **对白称谓错位**：说话人用别人的亲属词（芬恩说「伯父府」） | 按说话人立场改（「家里」）；见卡 H41 |
| 60 | **「我」听不懂却写细**：大人公务/琐事名目塞进旁听 | 改「说着什么」；见卡 H42 |
| 61 | **部分提纲对齐整章总字数** | 按提纲→正文密度写（约一千多字级）；未供情节勿写；见卡 C4 |
| 62 | **对照物空泛无领地特色**：坡和树之类哪儿都有 | 换牧场/牛羊等贴地物象；见卡 H43 |
| 63 | **笼统感官止步**：用户已点笼统仍只写「叶子沙沙」 | 补两三句可触可闻可见；见卡 H44 |
| 64 | **场切空转时间垫笔**：「席散到后来」等 | 删套话，人在场直接写；见卡 H45 |
| 65 | **一味删除致单薄**：人设/感官再出现就砍，不思对照 | 优先前后呼应/反差；无对照的空复读才删；见卡 H46 |
| 66 | **说话词「道」失控**：嚷不加道；或说/问满篇说道问道 | 生僻加道、常见少加、单独道可用；控频；见卡 H47 |
| 67 | **主语不匹配**：一句内前后成分挂到不同主语上 | 理顺为同一主语；见卡 H48 |
| 68 | **同指词高频复读**：如通场只写「眼眸」 | 眼／眼睛／眼眸／眸／瞳／目光／视线等轮换；见卡 H49 |
| 69 | **人称混轨**：第三人称写成幼年「我」口吻，或散装短判／报告收束／游戏腔 | 第一人称对标章一/二；第三人称文学式；见卡 H50 |
| 70 | **为难段提纲腔**：话锋一撞＋去接/不接对仗＋习惯清单＋「这种场面」自评 | 口语问句＋表面/乱麻落点；见卡 H51 |

### 反例 · 多句只表一意（#95 · 铜镜段）

**✗ 打回（笼统老套 + 同义叠写）**  
> ……便撞上一张幼小的脸——眉眼软，唇色淡，鼻尖还带着一点未醒的红；编好的发贴着肩，整张脸不像父亲一系那种平常相貌，倒更近侧室油画里的母亲。

问题：①「眉眼软/唇色淡/鼻尖红」空泛套话；②「不像父系平常」与「更近母亲」**两截只表达「像母亲」一个意思**。

**✓ 宜学**  
> ……铜光里映出光洁的额角，两根没压住的碎发翘着；瞳仁深，睫毛投下一排细影，颊侧还鼓着软肉——侧室油画里的母亲，缩成了六岁的样子。

## 三、写场六步（对照序章定稿）

| 步 | 做什么 | 宜学例 |
|----|--------|--------|
| 1 | **视 → 嗅听 → 触**；少「我先……」 | 涌入鼻腔的，是一股厚厚的亚麻… |
| 2 | **外物/他人先动** | 花猫从廊下窜过来 → 一时不知哪来的兴趣 |
| 3 | **动作链**可连串；幼体加乖乖/下意识 | 刚一用力就酸…乖乖躺回去 |
| 4 | **对话** + 脸上/动作；仆敬称分行 | 艾娜脸上一点打趣；「好的，小姐。」 |
| 5 | **身魂**（卷一）：物 + 心事；**宜侧面**（动作/挪开视线），忌直说「这一世/别扭/不习惯」 | 黑面包粗硬…与前两天比；镜中只写容貌，不适用动作带过 |
| 6 | **单点收束** | 我已经搞清楚…只剩莉莉娅·莱恩菲尔 |

### 章末收束型（序章 #86–#87 · 宜学）

- **身份落点**：上一世荡然无存 → 只剩这一世的莉莉娅·莱恩菲尔  
- **判断完成态**：「至少有一件事**我已经搞清楚**」（非「清楚了」）  
- **身魂最后一击**：惯于熬夜 vs 中世纪睡得格外早 → 翻来覆去  
- **忌**：空碗/试额/装乖排比 checklist；场外再埋无关一线

## 四、交稿自检（两遍）

**落笔前 / 交稿前各扫一遍：**

1. 这段外物先动了吗？有无日记体？  
2. 有无报告体 / meta / 替人总结可删？  
3. 扩写是否超过三句，或写了用户没点的意思？部分提纲有无对齐整章总字数？（C4）  
4. 卷一有无身魂对照（还是只写没胃口）？  
5. 场末是不是一个落点？有无 checklist？  
6. 有无膳/小几/箸/餐室，或近距空复读？能呼应的人设勿一味删（H36 / H46）  
7. 对白有无照搬提纲节拍词？称谓是否合**说话人**立场？（H40 / H41）  
8. 「我」旁听是否写了听不懂的具体内容？（H42）对照物是否空泛无领地特色？（H43）  
9. 内心是否直写？他人神态是否先看脸？  
10. 有无英文、提纲语、bible 缩略入正文？  
11. 有无读者看不懂的词 / 含糊造词 / 空对话？（红灯 #20 #40 #41）  
12. 对话是否缺称呼主语？是否 AI「……了吧？」？（H5 / H22）  
13. 第一人称代入还在吗？有无假比喻「像是」包装事实？（H21）  
14. 父系称谓是否用「堂」？（H18）  
15. **三铁律**：叙述句是否缺主语？是否散装短句连发？是否有无增量废话／空转「到后来」？（H31 / H45）  
16. 为难段有无「去接／不接」提纲对仗、习惯清单、自我标签？（H51）

## 五、视角与设定（硬）

| 项 | 要领 |
|----|------|
| **人称** | 主段严格「我」；短段第三人称旁白可补设定/场面，单次宜短，结束立刻回「我」 |
| **限知** | 不写「我」当时不可能知道的事（除非事后交代）；旁听却听不懂 → 勿编琐事名目（H42） |
| **未启蒙** | 可写异象，不可用「我」点破术式/净阶定名；专名靠对话或后文启蒙 |
| **设定** | 先叙事引入专名 → 「A是……，B则是……」直说；【附】只释本节已出现词 |
| **常识 vs 高级** | 觉醒/四系/净阶民间档/维洛日常 = 常识；澈冕、教廷编制、MP 池等 = 高级 |
| **正文专名** | 只写中文；Western 仅留 bible |
| **四层** | 每章兼顾：动作、神态语言、环境、心理；序章环境约 45–55% |
| **字数** | 约 3000 字/章；约每 1000 字一处小高潮 |
