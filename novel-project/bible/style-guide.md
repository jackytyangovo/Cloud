# 文风指南（Style Guide）

## 叙事视角（用户确认）

### 主视角：第一人称（莉莉娅）

- 正文**默认**以 **「我」** 叙述，即莉莉娅·莱恩菲尔（Lilia Lenfiel）的第一人称主视角。
- 前世记忆、男转女摩擦、自嘲与心理活动可直接用「我」呈现，与用户样章语感一致（见 `style-reference.md`）。
- 读者所见所闻所感以「我」的感知为边界，**不写入「我」当时不可能知道的信息**（除非事后得知并明确交代）。

### 辅视角：偶尔插入第三人称限知旁白

- **偶尔**插入**短段**第三人称限知叙述，用于：
  - **旁白描写**（环境、氛围、场面调度等，第一人称不便展开时）
  - **短暂切到他人限知**（如仪式台上检测官所见、洛伦在别处的反应）——须与当前剧情直接相关
- **篇幅**：单次插入宜短（一般 **不超过一章的 20%**）；一章内不宜连续多段旁白。
- **切换标记**（正文统一采用）：空行 + `※`（单独一行）+ 空行，引导第三人称短节；旁白结束后再以 `※` 收尾，下一段恢复「我」。自 Ch.1 起沿用，全书统一，不再逐章讨论标记形式。
- **切回**：旁白段结束后，下一段恢复「我」，避免长期双视角并行。

### 视角硬性边界：主角心理绝不出第一人称（用户确认 · 硬性，全书适用）

- **莉莉娅的内心心理，任何情况下都只能用「我」呈现，绝不允许切到第三人称叙述。** 第三人称旁白（`※`）的使用范围**仅限**于：设定/世界观说明、纯环境与场面描写、他人（非莉莉娅）的限知视角与外在言行——**不得**用来描写莉莉娅本人的心理活动、情绪、判断或内心独白，哪怕只有一句。
- 判断标准：如果一句话是在描述"莉莉娅心里怎么想/怎么感觉/怎么判断"，无论篇幅长短，都必须留在「我」的叙述段里，不能挪进 `※` 旁白段。
- 旁白段内如果需要衔接主角反应，应当在旁白结束、`※` 收尾之后，另起一段用「我」呈现，不要在旁白内部夹带"她心想""她觉得"之类第三人称心理描写。
- 本条为叙事视角规则中的强制项，与"辅视角"及"设定补充的统一手法"两节共同生效，冲突时以本条为准。

### 设定补充的统一手法（用户确认 · 硬性，全书适用，特例授权直接写入本文件）

- 全书任何**设定/世界观说明**（觉醒制度、净阶体系、社会规则如成年/订婚年龄、势力格局等），**统一**通过**短段第三人称旁白**（`※` 标记）呈现，**不再**用「我」大段自述、复述规则来解释设定——避免主角变成"科普讲解员"，也避免同一件事被对话和内心独白各说一遍造成的冗余（Ch.1 净阶设定曾出现此问题，已修正，此后按本节执行）。
- **触发方式**：由对话或场景中的一个具体细节自然引出（如长辈一句闲话、仪式流程的一个动作），旁白紧跟其后补充背景，不脱离场景单独插入。
- **旁白前后**：「我」可保留**简短**的主观反应（心理、情绪、评价，一两句即可），但不重复旁白已经交代的事实本身。
- 本条是**从 Ch.1 起确立并沿用至全书**的统一写法，后续任何章节涉及设定补充直接套用本手法，不必每章重新讨论或请示。

### 撰写禁忌

- 不要用全知旁白揭穿「我」尚未知晓的阴谋（除非改为「我后来听说」）。
- 第三人称段内仍保持**平直简单**，不要突然变成百科词条体。
- R18、战力等硬约束在两种视角下均适用。

### 与样章的关系

- 用户文风样章即为**第一人称**；本作主视角与之对齐，**无需再做「她」的系统性改写**。
- 第三人称插入为**新增规则**，样章未覆盖的部分按本节执行。

## 文风基调

- **平直简单**：用直接、清楚的语言叙述，不堆砌辞藻，不刻意文艺腔。
- **可迭代调整**：初稿按本指南执行；用户审阅后按具体修改习惯（句式长短、细节密度、口语程度等）逐步微调，不必一次定死。
- **风格参考**：详见 [`style-reference.md`](style-reference.md)（基于用户样章分析：反套路自嘲、平直苦叙、列举结构、性别错位心理、世界观贴身处嵌入）。
- **综合型节奏**：升级、生存、权谋、冒险可交织，单章可偏重其一；觉醒震撼写「影响」而非「碾压」。

## 内容分级（用户确认 · R18）

本作定为 **R18**，面向成年读者，**可出现成人向内容**，包括但不限于：

- 暴力、伤亡的直白描写
- 情欲、亲密关系相关场面（**配角 / 他人**）
- 暗黑权谋、压迫、伦理边界议题
- 成人向心理与身体感受（**主角成年后**；男转女身份摩擦的成熟表达）

### R18 边界（用户确认 · 硬约束）

| 类型 | 卷一幼年「我」 | 说明 |
|------|----------------|------|
| **主角亲身参与** | **禁止** | 莉莉娅幼年（卷一 6 岁起）**不发生**任何涉及自身的性爱 / 自慰等 R18 描写 |
| **目睹他人** | **允许** | 可**撞见、偷听、部分看见**配角的成人向或暴力暗黑场面，用于推动情节 |
| **主角成年后** | 待定 | 随剧情年龄增长，经 `outline` 标【R18·主角】后再写；笔法见 `style-reference.md` 第七节 |

**目睹他人时的写法**：

- **「我」能看懂**：前世 **25 岁男性记忆**完整，对成人向 / 暗黑场面**内心完全明白**。
- **装不懂**：表面上装作孩童的困惑、害怕或懵懂——**社交伪装**，避免暴露记忆觉醒（见 `characters.md`）。
- 叙述可呈现**双层**：外在反应（孩童表演）+ 内心独白（成年认知、评判、恶心或冷静分析）。
- 须**服务剧情**（家族丑闻、权力压迫、把柄、信任崩塌等），禁止无铺垫福利。
- 过强场面仍可用**侧面进入**（先闻声、后瞥见），但「我」的内心清楚那是什么。
- 第三人称短插可补「我」未入镜的全貌，仍须克制。

**撰写原则**：

| 原则 | 说明 |
|------|------|
| 服务剧情 | 成人向内容须推动人物、冲突或世界观，避免无铺垫堆砌 |
| 节奏 | 卷一以身份、家族、觉醒为主线；**幼年主角无亲身 R18**；目睹他人须在 outline 标【R18·目睹】 |
| 文风一致 | 即使成人向场景，仍保持**平直简单**；目睹戏写孩童心理冲击 |
| 战力不变 | R18 不突破战力成长硬约束（见下节） |

> Sonnet 5 写正文时须遵守本节；具体章节须在 `outline.md` 标注【R18·目睹】或【R18·主角】（后者仅成年后）。

## 每章须兼顾的四层（用户确认）

写作时除推进剧情外，每章尽量覆盖以下四类内容（比重可随场景浮动）：

| 层次 | 要求 |
|------|------|
| **人物动作** | 具体可见的行为，尤其幼女身体的动作限制 |
| **神态与语言** | 表情、语气、对话；符合年龄与身份 |
| **环境变化** | 场景、天气、光线、声响、领地/城内陈设等随情节推移而变化 |
| **主角心理** | 「我」的内心反应：前世记忆与现世身份的摩擦、判断与情绪；**须给读者不知道的新信息，不得围绕已发生的客观事实重复解释**（用户确认，详见 `style-reference.md`「DO/DON'T」） |

> 背景与设定**融入**以上四层中交代，避免大段旁白式说明。

## 章节惯例

| 项目 | 规范 |
|------|------|
| 目标字数 | 约 **4000–5000 字/章** |
| 开篇 | 场景切入，尽快进入动作或对话 |
| 结尾 | 悬念断章 |
| 时间跳跃 | 章首简要标注（如「觉醒前二十三天」） |
| 开篇设定密度 | **前 2 章**完成主要背景与家族设定交代，不拖至第 6 章 |

## 战力与数值（撰写硬约束）

- **天赋净阶 = 上限**，不等于当前战力。
- 孩童高净阶（如埃里克明印、莉莉娅净章）**绝不能**在正面对抗中胜过成年修习数十年的法师（如洛伦澄纹）。
- 战力成长须体现：**魔力强度**、**魔力上限（MP 池）**、咒语熟练度、经验。
- 前期整体数值克制；高净阶概率指数级降低。

## 专有名词

- 首次出现：**中文（Western）**，如 莉莉娅·莱恩菲尔（Lilia Lenfiel）。
- 净阶、元素、地名保持一致，以 `worldbuilding.md` 为准。
- 未设定内容标注 `【随剧情补充】`，不在正文擅自定稿。

## 四条叙事线（章节配比参考）

1. **个人成长线** — 身份、修炼、天赋代价
2. **势力权谋线** — 家族、王国、帝国博弈
3. **世界真相线** — 禁忌、种族、历史（长线，慢热）
4. **情感羁绊线** — 【随剧情补充】；可含成人向关系线（R18）
