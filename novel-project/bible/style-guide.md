# 文风指南（Style Guide）

## 叙事视角（用户确认）

### 主视角：第一人称（莉莉娅）

> **最高优先级（✓ 用户确认）**：正文 **必须** 严格 **第一人称「我」**——所见、所闻、所感、所忆，均经 **「我」当下或可追溯的经验** 呈现；**禁止** 跳出叙事层（如「序章」「上一章」）、**禁止** 报告体归纳（「我懂，是……」「把……拼起来：……」）、**禁止** 替读者总结情节。

- 正文**默认**以 **「我」** 叙述，即莉莉娅·莱恩菲尔（Lilia Lenfiel）的第一人称主视角。
- 前世记忆、男转女摩擦、自嘲与心理活动可直接用「我」呈现，与用户样章语感一致（见 `style-reference.md`）。
- 读者所见所闻所感以「我」的感知为边界，**不写入「我」当时不可能知道的信息**（除非事后得知并明确交代）。
- **序章/未启蒙段**：环境描写 **仅感官与幼女常识**；**不得**用「我」之口点破魔法、咒痕、净阶、术式名——可写 **所见异象**，不可写 **定名判断**；专名由 **他人对话** 或 **后文启蒙** 带入。
- **设定附块**（✓ 用户确认）：若正文出现读者需对齐、而 **「我」当时说不深** 的名词，须在 **该词第一次出现处下方** 插入 **【附】…【/附】**，标题 **「附：（本节名词）」**。**常识类**（见下「设定知识分级」）主角本就知晓，【附】可 **略写细**；**高级知识** **不进正文、不进附**，除非经学习或特殊途径。**每条只解释该词**；**非**百科长文。**不写剧透**。**同一专名不重复插附**；「我」已自然说清则不插附。
- **世界观短插后忌总结复述**（✓ 用户确认）：第三人称记忆段落下 **禁止**「这就是 XX 知道的事：……」式 **报告/论文体** 收束——前文已写过的信息 **不再归纳罗列**；直接接 **具体场景、动作或感官** 切回叙事。

#### 设定知识分级（✓ 用户确认 · 硬规则）

> 写作前先判断：**常识** 还是 **高级知识**。  
> **常识** → 可随时出现在正文/对话/【附】；幼女视角可写「知道大概、说不深」。  
> **高级知识** → **不经学习、专业场合或特殊途径**，**不得**由「我」点破或写进【附】。

**常识（社会耳濡目染 · 6 岁贵族幼女亦可知）**

| 类别 | 可写内容 |
|------|----------|
| **觉醒** | 六岁统一检测；测 **元素** + **净阶**；要去城里 **仪场** |
| **元素** | 风、火、水、土四系最常见；**光、暗、电** 少见，但 **大人口中常当作稀罕名相**（知其名、知其少，未必懂规则）；家族祖传（如莱恩菲尔 **土系**） |
| **净阶** | 民间常提：**浊痕 → 蒙纱 → 澄纹 → 明印 → 净章**；大致好坏（浊/蒙偏弱、澄纹能正经学、明印好苗子、净章极高/仪场顶档）——**【附】可写细一点** |
| **社会** | 王国、领地、大城（灰港）；贵族与平民都要觉醒；魔法是大人的事 |
| **维洛教·日常** | 几乎人人都信；维耶洛、主日、教父、乡村教堂、初光轮徽 |
| **耳闻专名** | 温养院、圣息使——常作名词听到，功能 **只知大概** |
| **家族** | 两房亲戚、表哥觉醒过、大人爱拿 **土系明印** 当面子话 |

**高级知识（须学习 / 专业场合 / 特殊途径）**

| 类别 | 不得提前写（卷一前期示例） |
|------|---------------------------|
| **净阶·深** | 澈冕、无垢；净阶与 **即战力** 的关系；各档精确比例 |
| **元素·稀** | 冰、生命、死灵、空间之稀有度与规则；光/暗/电的 **精确比例与修习细节** |
| **教会·制** | 教堂三级，司铎/执事/辅祭编制，初光祝由谁主持 |
| **教会·深** | 圣息使按立路径，教廷/教宗/圣环城，初光之选教义争议 |
| **制度** | 魔法师/剑士公会章程，仪典册行政细节，Writ 招生文书流程 |
| **战力** | MP 池、术式名、咒语阶、战斗级人口比例 |
| **政治** | 教廷与诸国博弈、联姻政治、王室内幕 |
| **Western 原文** | **正文不写**；仅 `bible/` 保留中英对照 |

**【附】与分级**：常识（如净阶各档）可集中略写细；半常识（温养院、圣息使）各一句；高级知识 **等剧情到了再写**。

- **世界观短插**（序章场 2 等）：可用 **第三人称** 呈现 **莉莉娅原记忆** 中的 **常识**；**限于幼女所知**，忌百科；单次插入宜 **~1000 字内**，须 **※** 或空行标界，结束 **回「我」**。

### 辅视角：偶尔插入第三人称限知旁白

- **偶尔**插入**短段**第三人称限知叙述，用于：
  - **旁白描写**（环境、氛围、场面调度等，第一人称不便展开时）
  - **设定补充**（觉醒制度、净阶、势力格局等，避免主角大段科普腔）
  - **短暂切到他人限知**（如仪式台上检测官所见、洛伦在别处的反应）——须与当前剧情直接相关
- **篇幅**：单次插入宜短（一般 **不超过一章的 20%**）；一章内不宜连续多段旁白。
- **切换标记**（正文可选用以下之一，全书统一即可）：
  - 空行 + 第三人称段落（无「我」）
  - 或以 `※` / `——` 引导的独立短节（【随正文定稿时统一】）
- **切回**：旁白段结束后，下一段恢复「我」，避免长期双视角并行。

### 撰写禁忌

- 不要用全知旁白揭穿「我」尚未知晓的阴谋（除非改为「我后来听说」）。
- 第三人称段内仍保持**平直简单**，不要突然变成百科词条体。
- R18、战力等硬约束在两种视角下均适用。
- **容貌**：bible 可用内部标尺（5–6、7–8 等）；**正文不写数字打分**，用具体描写与旁人反应侧写。

### 用户手改与模仿（✓ · 写前优先）

- Agent 写稿/纠察 **先读** [`writing-essentials.md`](writing-essentials.md) **§〇 用户手改 · 模仿卡**（`✗`/`✓`/`→`）。
- 用户每处手改须 **同轮** 入库模仿卡 + `user-style-iteration-log.md`；冲突时 **最新手改优先**。
- **读者看不懂 = 反例**（✓）：用户以读者视角问「看不懂的词」→ 正文 **禁止再用**（或必须改成通俗说法）；同轮写入要领红灯 #20 与「看不懂词表」。
- **无来源全知**（✓ #105）：叙述不可写出「我」无从得知的事实；须有亲耳/目睹/在场渠道，或改由对话带出（红灯 #21）。
- **AI 腔对话**（✓ #106）：忌「……了吧？」等假商量、软确认；侍女/孩童口语宜直、嗔、感叹（红灯 #22）。
- **勿打断转折句**（✓ #107）：`却`/`但是` 前后只留对照动作；外貌、发色用破折号插在中间 = 反例（红灯 #23）。
- **形象不无故复读**（✓ #108）：序章已写的发色等，后文无对照需要勿再点（红灯 #24）。
- **对话忌谜语**（✓ #108）：环境叙述可抽象；人物对「我」说话须说明白——用人名/关系，不用「远客」这类谜语称呼（红灯 #25）。
- **陌生新场**（✓ #109）：环境 **由远及近、动态写**；情节须有发现→靠近→抵达→应对，忌只写结果（红灯 #26 #27）。
- **语气词须有明确口气**（✓ #110）：句末「，啊？」等若说不清意图 = 反例；艾娜叮嘱宜「听见没？」（红灯 #28）。
- **禁电报式形象**（✓ #111）：忌 `——敦厚相，身形壮实，栗发，脸圆……`；外貌嵌动作写（红灯 #29）。
- **主客/赶路逻辑**（✓ #112）：谁赶路谁答「路上顺不顺」；主人问或安置宿处，忌反客为主（红灯 #30）。
- **说话动作勿单字**（✓ #113）：忌 `我应：「……」`；写成神态/动作+答（红灯 #31）。

### 人物形象（✓ 用户确认）

- **恒定设定 + 按章区形象**：详见 `characters.md`；写 **第 N 章** 时只取 **对应章区** 行，人物可随章节变化。
- **发色**（✓ #93）：以 `characters.md` **§发色** 为准；**恒定设定**，正文用 **中文色名**；**不写** purple/lavender 等 Western 专名对照。
- **发型**（✓ #97）：**按章区** 登记于各人物 **容貌 / 神态 / 发型** 列；**可变**；写 **第 N 章** 只取 **该章区** 一行。**女性 / 侍女 / 夫人** 等宜按需写发型。
- **男子短发**（✓ #98）：本世界 **男性以短发为主**；**无特殊情况**（蓄长发、仪典、伤愈首理等）→ **不必着重写发型**；写 **栗发** 等 **发色** 即可。
- **发色与发型不必同场同句**（✓ #96）：可前后分开写，逐步完善印象。
- **首次出场**（该章区首次实写）：带容貌或体态 **一两笔**。
- **语言、神态、动作**：贴合 **当前章区**；用 **侧面描写** 烘托。
- 正文写出的新形象细节 → **勿擅自回填** `characters.md`；仅用户点名要求时再改设定文件。
- **贵族宅邸**：夫人/伯母 **照孩、督理内务**；**仆役或侍女布菜传盘**，夫人 **不**亲自动手。亲族到客宅 **先与主人见礼** 再顾妻儿；**不在主人家门前举高戏耍** 孩童。
- **两房称谓**：盖伦为 **伯父**（洛伦之兄）；盖伦对洛伦 **不叫「哥」**（避免与「我」视角的伯父身份混淆）。


### 与样章的关系

- 用户文风样章即为**第一人称**；本作主视角与之对齐，**无需再做「她」的系统性改写**。
- 第三人称插入为**新增规则**，样章未覆盖的部分按本节执行。

### 对话与节奏（样章 3 确认）

- **叙述为主**仍是默认；**社交/谈判段**对话可升至 **30–40%**（见 `style-reference.md` §五）。
- 对话须配**动作一行**与「我」的内心对照，避免纯话剧；**首次出场** 忌谜语式省略（须让读者知场景与安排）。
- 节间可用独立行 `*` 或空行分段，**全书统一**即可。

### 身体喜剧与打断（样章 3 确认 · 卷一尺度）

- 允许**突发的、丢脸的**小物理事故（绊裙、摔软垫、车门碰头）作节奏刹车；**6 岁尺度**，不用 R18 余韵。
- 「门外打断 + 内心窘境」可作章首钩子（见 `style-reference.md` §六）。

## 文风基调

- **平直简单**：用直接、清楚的语言叙述，不堆砌辞藻，不刻意文艺腔。**读者先看懂**——忌费解隐喻、拟人、象征式省略（如「油画替大人说话」「热闹日子的色块」）；意思能直说就直说。
- **长短句结合**（✓ 用户确认）：环境、神态、动作 **可写细、可写长**；但 **同一句内** 忌 **两三个字的短语连续铺陈**（如「窗大。光落。肩宽。指粗。」式堆叠）。宜以 **复句、从句** 串联，关键处再用 **短句** 点睛。
- **分段透气**（✓ 用户确认）：人物、环境描写 **宜勤分段**，方便手机阅读；**忌**把多组感官、多个动作或多人神态 **挤在同一段** 里臃肿难读。段内仍可用长句，但 **换场景、换焦点、换感官、对话前后、心理转折** 处应 **另起段**；单段一般 **不宜超过四五个完整意群**（约 150–250 字量级作参考，非硬限）。
- **对话口语化**（✓ 用户确认）：人物语言 **宜活、宜口语**，适当用 **语气词**（嘛、呢、呀、啊、哦、啦等）与 **口癖**，忌全员短句干巴巴、像念提纲。**各角色** 说话方式须有区分（盖伦声大热络、米拉软和、艾娜念叨、埃里克装稳、芬恩闹腾）。
- **禁提纲语入正文**（✓ 用户确认）：bible/大纲里的 **功能缩略**（如「照孩」「#2 轻埋」「侧写」）**不得**原样写入正文；须改 **读者能懂的日常说法**，或 **用动作、对话** 呈现（「照孩」→「照看两个孩子吃饭」「替芬恩擦嘴」等）。
- **严禁照办纲要**（✓ 用户确认 · **硬规则**）：`outline.md`、`characters.md` 章区表、bible 技法行是 **写前参考**，**不是**正文底稿。**禁止**把场次表、节拍表、伏笔编号、技法要点 **照译** 成叙述句或 **逐条填坑** 式写作。**`drafts/` 初稿即正文**——读者只应看到 **场景、对话、动作、感官**，不应读出「作者在完成纲要 checklist」。
- **汉语自然**（✓ 用户确认）：忌 **电报式省略**（如「发挽得紧」「今日安静」「不算最虔的人」）；比喻 **本体与喻体不可重复**；侍女/日常对话宜 **贴合口语** 并 **侧面写性格**。**少用单字指代或描写**（如单写「领」指领地、「声低」指说话声、「地还潮」指地面潮湿）——汉字多义，易误解；优先 **多字词语**（领地、领地上、声音压得很低、地面还潮湿等），意思写清楚。
- **忌强求对仗/排比**（✓ 用户确认）：勿为 **格式对齐** 硬凑并列短句（如「A声大，B带礼」）；**自然流畅、不绕口、不罗嗦** 优先于句式整齐。
- **身份冲突写法**（✓ 用户确认）：忌 **反复** 用「带着幼童……」「是幼童特有的……」等 **直接标签句**（**全章至多一二处**）；余以 **心理、神态、动作** 呈现错位。
- **第一人称·自写分寸**（✓ 用户确认）：「我」**看不见自己的脸**；自写 **神态宜少、宜简**，优先 **动作、触感、对话、内心**（如「我把脸别向一边，皱起鼻尖道」），**忌**外视角式堆叠（「眼睛亮了一下，声音又软又倔」连用）。**他人** 的神态、语言仍可写细——人物互动仍是重点。
- **第一人称·感官优先级**（✓ 用户确认 · 序章 pass #49）：「我」的感知 **视觉优先**，其次 **嗅觉、听觉**，最后 **触觉**。写他人情绪/态度 **先用视知觉近环**（脸、眼神、动作；如「脸上透露着一点打趣」），**勿**默认用「语气里带着……」等 **听觉后置、需多想一层** 的说法。**语气、语调** 等 **须思考才有明确答案** 的描写，**仅当** 视、听、嗅、触 **都提供不了有效信息** 时才写。
- **第一人称·内心独白**（✓ 用户确认 · 序章 pass #50）：**省略**「我心里……」「忍不住吐槽/想说」等 **前置标签**，**直写**内心句（读者默认是「我」所想）；**勿**先贴「内心独白」再开口。
- **第一人称·情绪落点**（✓ 用户确认 · 序章 pass #60–#61）：**忌**「一时 A 了，一时又 B 了」等 **并列相反状态**（读者不知当下落点）；择 **单一情绪** 写透，可用 **「又」** 接前文（如「又多松了一口气」）。
- **第一人称·情节起笔**（✓ 用户确认 · 序章 pass #66）：**外物/他人先动** → **「我」一时反应** → 再行动；**忌**日记体「我追了…/我去了…」平铺。
- **通俗易懂**（✓ 用户确认 · 序章 pass #26/#31）：像 **口头转述**，读者 **一听就懂**；Agent 扩写 **默认 2–3 句**；**忌**叠床架屋、未点名废话（#44）。
- **严禁多句只表一意**（✓ 用户确认 · 序章 #95 · **硬规则**）：同一信息 **只写一次**；禁止用两句（或一句内两截）反复说同一个意思，造成废话连篇。容貌、身世、情绪皆然。  
  - ✗「整张脸不像父亲一系那种平常相貌，倒更近侧室油画里的母亲」——两截都只在说「像母亲」。  
  - ✓「侧室油画里的母亲，缩成了六岁的样子」——一句说完。  
  - 容貌忌笼统老套堆砌（「眉眼软，唇色淡，鼻尖一点红」）；改 **可看见的具体**（额角、碎发、瞳仁、睫毛影、颊侧软肉等）。
- **设定直说**（✓ 用户确认 · 序章 pass #36–#37）：专名 **首次出现的叙事句保留** → 再接 **「A是……，B则是……」** 最简单白描；**不必**严格幼女限知；**勿删**引入专名的叙事句。
- **卷一·身魂对照**（✓ 用户确认 · 序章 pass #70–#71/#86）：第一卷、尚未适应期，遇 **不符前世现代认知** 之事 → **心事 + 具体物/礼俗对照**（如午饭 **粗陋难咽**、**与前两天** 比、**熬夜 vs 中世纪早睡**）；**忌**只写「没胃口/不习惯」；适应后再收。
- **近距不重复**（✓ 用户确认 · 序章 pass #64）：对话刚交代的 **地点/安排**，叙述 **用指代带过**（「父亲说的那些地方」），**忌**隔几行 **再罗列清单**。
- **西方中世纪宅用语**（✓ 用户确认 · 序章 pass #52/#62/#73）：**大厅**、**饭后/快吃完时**、**仆从**、**空匙**、**书斋/管事间/客厢/窗棂**、**小桌**；**忌**东方宫廷/古言体系（**膳**、**空箸**、**小几**、**杂役**、**餐室**）；**晨/晚** 一家 **大厅**，**午饭** **端进卧房**。
- **仆主应答**（✓ 用户确认 · 序章 pass #74）：仆对小姐 **「好的，小姐。」** 等敬称；**忌** 向主人 **单「嗯」**；重要应答 **可单独成行**。
- **场末收束**（✓ 用户确认 · 序章 pass #85–#87）：每场 **一个清楚落点**（如「躲不过的大事」「只剩这一世的莉莉娅·莱恩菲尔」）；**忌** checklist 式排比回顾；判断句宜 **「我已经搞清楚」** 等 **完成态口语**。
- **正文用词**：**不造未铺垫简称**（如「男忆」）；须写 **「前世的我」**「前世的记忆」等读者可懂说法。bible 内部提纲可用简称，**`drafts/` 正文禁用**。
- **可迭代调整**：初稿按本指南执行；用户审阅后按具体修改习惯（句式长短、细节密度、口语程度等）逐步微调，不必一次定死。
- **风格参考**：详见 [`style-reference.md`](style-reference.md)（基于用户样章分析；**持续更新**——用户发样文 → Composer 分析入库）。
- **综合型节奏**：升级、生存、权谋、冒险可交织，单章可偏重其一；觉醒震撼写「影响」而非「碾压」。
- **章内小高潮**（✓ 用户确认）：约 **每 1000 字** 设一处 **人物/情节小高潮**（如护短顶回、魔法演示被闹破、启程铃响），避免流水账；**提高人物描写占比**，删对形象与情节无用的环境铺陈。

### 卷一前期（第二章–第四章 · 用户确认）

> **日常成长期 4要4不要 + 章自查三问** → [`daily-growth-writing.md`](daily-growth-writing.md)（✓ 用户确认）。

- **生活记录感**：像随家族出行的日记/行记，**以日常所见所感为主**，不急于推主线冲突。
- **基调**：**温馨为主，偶有摩擦**（身体不便、孩童吵闹、无心比较、轻微社交冷落）；摩擦宜小不宜大，不写成持续虐点。
- **小危机夸张**（样章 5）：可用「空前危机 → 其实很小」开篇（抢窗、冷、挤、明日仪式）；**6 岁尺度**；前世对照 **仅在有具体落点时** 使用。
- **温馨 montage**（样章 5）：固定工序链 + 「自从……日子变快」；陪伴改变日常节奏（见 `style-reference.md` §12.3）。
- **旁观 + 拌嘴**（样章 8）：观战/演示宜 **快收**；战后高密度吐槽与「哄小孩的说法」—— 见 `style-reference.md` §15.7。
- **仪式 + 文书**（样章 9）：魔法启动感官栈、`*` 闪回、见官方信胃翻/想逃 —— §16；**卷二第三十章**用 **Writ of Matriculation**，非女王令。
- **抵达 + 登记 + 制服**（样章 10）：§17；**卷二**第三十四–三十五章；卷一无抵校。
- **季节 + 节庆/市集 + 夜话**（样章 11）：冬景开篇、八卦涟漪、浴想、吹发/梳头、第三人闯门 —— §18；**卷一第二–三章** 生活记录与盖伦府温馨段。
- **一日结构**（样章 4）：可写「从晨到夜」的**工序感**（重复句、第 N 次、收工后小杂务）；**理想宣言后同章或次章可现实打脸**（见 `style-reference.md` §11.4）。
- **世界观**：借**当地风貌**（地貌、物产、市集、码头、仪场）自然带入；禁止大段说明文、百科腔。

## 内容分级（用户确认 · R18）

本作定为 **R18**，面向成年读者，**可出现成人向内容**，包括但不限于：

- 暴力、伤亡的直白描写
- 情欲、亲密关系相关场面（**配角 / 他人**）
- 暗黑权谋、压迫、伦理边界议题
- 成人向心理与身体感受（**主角成年后**；男转女身份摩擦的成熟表达）

### R18 边界（用户确认 · 硬约束）

| 类型 | 卷一幼年「我」 | 说明 |
|------|----------------|------|
| **主角亲身参与** | **禁止** | 莉莉娅幼年（卷一 6 岁起）**不发生**任何涉及自身的性爱 / 自慰等 R18 描写 |
| **目睹他人** | **允许** | 可**撞见、偷听、部分看见**配角的成人向或暴力暗黑场面，用于推动情节 |
| **主角成年后** | 待定 | 随剧情年龄增长，经 `outline` 标【R18·主角】后再写；笔法见 `style-reference.md` §7（含 §7.7 驱身型、§7.9 情感离别型） |

**目睹他人时的写法**：

- **「我」能看懂**：**前世的我**（**刚毕业学生**，无履历线）对成人向 / 暗黑场面**内心完全明白**。
- **装不懂**：表面上装作孩童的困惑、害怕或懵懂——**社交伪装**，避免暴露记忆觉醒（见 `characters.md`）。
- 叙述可呈现**双层**：外在反应（孩童表演）+ 内心独白（成年认知、评判、恶心或冷静分析）。
- 须**服务剧情**（家族丑闻、权力压迫、把柄、信任崩塌等），禁止无铺垫福利。
- 过强场面仍可用**侧面进入**（先闻声、后瞥见），但「我」的内心清楚那是什么。
- 第三人称短插可补「我」未入镜的全貌，仍须克制。

**撰写原则**：

| 原则 | 说明 |
|------|------|
| 服务剧情 | 成人向内容须推动人物、冲突或世界观，避免无铺垫堆砌 |
| 节奏 | 卷一以身份、家族、觉醒为主线；**幼年主角无亲身 R18**；目睹他人须在 outline 标【R18·目睹】 |
| 文风一致 | 即使成人向场景，仍保持**平直简单**；目睹戏写孩童心理冲击 |
| 战力不变 | R18 不突破战力成长硬约束（见下节） |

> 撰写正文时须遵守本节；具体章节须在 `outline.md` 标注【R18·目睹】或【R18·主角】（后者仅成年后）。

## 每章须兼顾的四层（用户确认）

写作时除推进剧情外，每章尽量覆盖以下四类内容（比重可随场景浮动）：

| 层次 | 要求 |
|------|------|
| **人物动作** | 具体可见的行为，尤其幼女身体的动作限制；**符合人设** |
| **神态与语言** | 表情、语气、对话；符合年龄与身份；**首次出场宜带容貌/体态一笔** |
| **环境变化** | 场景、天气、光线、声响、领地/城内陈设等随情节推移而变化 |
| **主角心理** | 「我」的内心反应：前世记忆与现世身份的摩擦、判断与情绪 |

> 背景与设定**融入**以上四层中交代，避免大段旁白式说明。  
> **序章 / 初入新世界段落**（用户确认）：**环境认知层加重**——「我」所见所闻所触所嗅宜占全章 **约 45–55%**；心理 **短句穿插**；**重点在开启这一世生活**（见 `outline.md` 序章撰写比例）。  
> **前世对照**：**须有具体落点**（制度、物件、身体差异等）；**笼统模糊则不写**。

## 战力与数值（撰写硬约束）

- **天赋净阶 = 上限**，不等于当前战力。
- 孩童高净阶（如埃里克明印、莉莉娅净章）**绝不能**在正面对抗中胜过成年修习数十年的法师（如洛伦澄纹）。
- 战力成长须体现：**魔力强度**、**魔力上限（MP 池）**、咒语熟练度、经验。
- 前期整体数值克制；高净阶概率指数级降低。

## 专有名词

- **`bible/`**：专名并列 **中文 + Western**，如 莉莉娅·莱恩菲尔（Lilia Lenfiel）。
- **`drafts/` 正文**：**仅写中文**，**不展示** Western 对照（如不写 Grayport、Vitae Envoy）。
- 净阶、元素、地名保持一致，以 `worldbuilding.md` 为准。
- 未设定内容标注 `【随剧情补充】`，不在正文擅自定稿。
- 设定 **常识 / 高级知识** 分级见上文「设定知识分级」。

## 维洛教 · 写作默认（✓ 用户确认）

- **约 99%** 信教；**创世教义**（比照天主教）为 **社会底层逻辑**——誓言、历法、婚丧、道德常识 **ambient 默认**。
- **贵族宅不设教堂**；礼拜赴 **乡村教堂 / 分区教堂 / 大教堂**（见 `worldbuilding.md` §5.2.0 **教堂三级**）。
- **司铎** 为高级神职，**仅大教堂常设**，其下并有 **执事、辅祭** 等完整低级编制；**分区教堂** 仅 **执事、辅祭** 等；**乡村教堂** 仅 **教父、修女**。
- **六岁觉醒** 的 **初光祝** 由 **分区教堂** 依例主持（**常规**仪礼，**非**隆重大典）；**不必** 司铎到场。
- **莱恩菲尔**：**莉安娜画像** 在侧室；宅内可有 **初光轮徽**，**无** 宅内教堂。
- **初光之选**（✓ 保留伏笔）：民间可将 **光系净章** 附会为此——**非**教义强制。
- 勿角色长篇布道；触点用 **轮徽、远钟、教堂、温养院/圣息使闲谈** 即可。
