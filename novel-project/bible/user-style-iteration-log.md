### #3 · 2026-07-17 · 序章 · 起身失败

**用户指令**：整段替换为「我想坐起来，胳膊刚一用力就酸的不行，整个人也软绵绵的使不上劲，只好又乖乖躺了回去。」

**改前**：
> 我想坐起来，胳膊刚用力，腹背就酸了一下，使不上劲，我整个人软绵绵的，只好又躺回去。

**改后**：

**提炼（待入库）**：
- 幼体无力 **一句连串**（刚一用力→酸→软→使不上劲），少切分短句
- 语气词/副词点缀孩童顺从感（「乖乖躺了回去」）

### #4 · 2026-07-17 · 序章 · 记忆涌入（修订）

**用户指令**：改为「正躺在那里，脑子里忽然浮现了一团截然不同的记忆。」（修正 #4 初稿「两堆互不相干的记忆」）

**改前**：
> 我躺在那里，脑子里忽然涌进两堆互不相干的记忆，乱得一时理不清。

**改后**：
> 正躺在那里，脑子里忽然浮现了一团截然不同的记忆。

**提炼（待入库）**：
- 「正躺在那里」接续动作，少重复「我」起句
- 记忆用 **「浮现」** 而非「涌进」；**一团** 而非「两堆」——先统写，再分述（与后文「一堆/另一堆」衔接需用户后续定）
- 删「互不相干」「乱得一时理不清」等归纳句，**点到即止**

### #5 · 2026-07-17 · 序章 · 记忆结构（删一堆/另一堆）

**用户指令**：删去「一堆」「另一堆」；莉莉娅记忆前置接上；「所以我既知道」挪到记忆后面。

**改前**：

**改后**：

- 记忆叙述 **顺时间展开**，不用归纳式分条

**改前**：

## Agent 执行清单（每次用户指定修改后）

1. **只改**用户点名的句段/功能；不顺带润色他处
2. 在本文件 **改动日志** 追加一条（改前/改后/提炼）
3. 若用户要求同步预览：`build_standalone.py` + push
4. **定稿 pass 未结束前** 不擅自把「提炼」写入 style-guide（除非用户说「先入库这条」）
5. pass 结束时：完成 **汇总分析** → 用户确认 → 整合进规范并标 **✓ 用户文风 · 高优先级**
