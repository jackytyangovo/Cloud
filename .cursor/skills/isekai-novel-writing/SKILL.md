# 异世界重生小说 · 写作 Skill

本 skill 汇总当前定稿的**写作方法与硬约束**。细节以 `novel-project/bible/` 为准；本文件供 Agent **写正文前必读、改稿时对照**。

## 何时启用

- 撰写、润色、扩写 `novel-project/drafts/` 下章节
- 用户要求检查文风、附块、剧透、维洛教表述
- 修改正文后需重建 `preview/standalone.html`
- **用户手改 / 定稿 pass**：用户逐条修改 → 只改点名部分 → **同轮**写入 `writing-essentials` **§〇 模仿卡** + `user-style-iteration-log.md`

## 用户文风 · 高优先级

> **主读**：[`writing-essentials.md`](../../novel-project/bible/writing-essentials.md)  
> 阅读顺序：**§一**（逻辑+Agent分歧）→ **§三** 六步 → **§三·附** 宜学/勿学 → **§二** 红灯 → **§〇** 模仿卡 → **§四** 自检。  
> **档案**：[`user-style-iteration-log.md`](../../novel-project/bible/user-style-iteration-log.md)（查改前/改后）。  
> **样章桥**：`style-reference` §九·附；**政策层**：`style-guide`（视角/R18/附块）。

| 规则 | 说明 |
|------|------|
| **改动范围** | **仅**用户点名的句段；「全文」= 当前章（见 WORKFLOW） |
| **记录（硬）** | 每处手改 → 模仿卡一张 + log `#N` |
| **冲突优先** | 最新手改模仿卡 > style-guide > 旧档案 |

## 写前清单（按顺序）

0. `WORKFLOW`：目录边界、定稿/预览  
1. 当次「全文」= 当前章  
2. **`writing-essentials`** 按文首顺序通读（尤其 §三·附 宜学/勿学）  
3. `outline` 当前章：只取情节边界  
4. 日常章 → `daily-growth-writing`；大转折 → `narrative-structure`  
5. 读上一章衔接；规划【附】  
6. 交稿：essentials §四 + 红灯；政策疑问查 `style-guide`  
7. 用户手改：同轮模仿卡 + log

## 主角与家庭（撰写默认）

- **莉莉娅 / 莉亚**：6 岁女；男转女 + 序章觉醒**前世的我**（刚毕业男学生，**不展开**履历）
- **天赋（表）**：光系净章；**（隐）** 生命属性中期再写
- **光系来源**：遗传母亲莉安娜，非父亲土系
- **小名**：父亲/近侍称 **莉亚**；文书/仪场用 **莉莉娅**
- **莱恩菲尔家**：维洛信众、**非虔**；偶尔赴**乡村教堂**；宅内**无教堂**，有**初光轮徽**、**莉安娜画像**（侧室）
- **领上礼拜**：**教父**主持，**非**司铎常驻

## 维洛教 · 教堂三级（bible 高级知识 · 正文前期不写）

> 以下供 bible 对照；**卷一序章–前期正文属高级知识**，勿写进【附】或「我」之口。

> **编制逻辑**：**有高级神职的教堂** → 下辖**完整低级编制**；**仅设低级神职的教堂** → **不设**高级神职常驻。

| 层级 | 规模 | 常驻神职 |
|------|------|----------|
| **大教堂** | 都城 | **司铎**（高级）+ **执事、辅祭** + 礼颂官、圣器监、书记副官 |
| **分区教堂** | 大城市 | **执事、辅祭**、读经员、传谕使；**无司铎** |
| **乡村教堂** | 乡间聚落 | **教父、修女**；**无司铎、无执事** |

### 觉醒仪式（常规仪礼）

- **六岁觉醒**的 **初光祝** 由 **分区教堂** 依例主持
- 属**常规**仪礼，**非**隆重大典；**执事**即可，**不必司铎到场**
- **检测**由世俗官/法师主持
- ✗ 不写「须大教堂派司铎诵初光祝」

### 大圣礼 vs 常规礼

- 洗礼、婚礼、葬仪等**大圣礼**须司铎 → 分区/乡村由大教堂**派司铎临时代行**，或信众赴城
- 初光祝**不属于**须司铎到场的大圣礼

### 写作触点

- 教义 **ambient 默认**（约 99% 信教）；勿长篇布道
- 触点：轮徽、远钟、教堂、温养院/圣息使闲谈
- **初光之选**：民间可附会光系净章——**非**教义强制、**非**教廷册封（保留伏笔）

## 卷一边界（硬 · 违反即错）

**卷一**：序章–第二十九章；6→7 岁；主场景领地 + 灰港第二幕。

### 可写

- 觉醒倒计时、家族日常、赴灰港、仪式、回领、赛温课表
- 提及婚约制度背景（「十二岁才订」），**无「我」订婚情节**
- 维洛 ambient：轮徽、远钟、乡村教堂礼拜闲谈

### 不写

- 盖伦一家**到场**（序章可耳闻）
- 灰港**实写**（序章）
- 净章结果、赛温、联姻情节发展、王室、学院入学
- 宅内教堂、教宗亲见、异端审判
- 联姻/订婚/婚约政治、王室及政治高层直接接触 → **中期**

### 序章特限（Day 0）

- **单日**、**不出领地**
- 空间：宅邸及紧连内庭
- 可写：记忆觉醒、莉安娜画像、觉醒名册耳闻、维洛 ambient
- 不写：仪场实写、净章、灰港实写

## 战力与数值（硬约束）

- **天赋净阶 = 上限**，≠ 即战力
- 6 岁净章**不能**碾压成年修习数十年的法师（如洛伦澄纹）
- 孩童高净阶（埃里克明印、莉莉娅净章）正面对抗**绝不能**胜成年法师
- 成长须体现：魔力强度、MP 池、咒语熟练度、经验
- 觉醒震撼写「**影响**」而非「碾压」

## 常见错误（立即改正）

| 错误 | 正确 |
|------|------|
| 领上司铎 / 领上执事 | 领上只有**教父、修女** |
| 觉醒须司铎到场 | **分区教堂执事**依例主持，常规仪礼 |
| 大教堂无执事辅祭 | 大教堂有司铎 **及** 完整下级编制 |
| 附块写教堂三级/司铎编制 | 主角不知→**不进附**；留 bible |
| 「这就是莉莉娅知道的事：……」 | **删**；记忆段后直接接场景 |
| 「我懂，是盖伦一家」/「那种慢」 | **删**；改亲闻亲见或具体动作感官 |
| 盖伦对洛伦称「哥」 | **改**；盖伦为 **伯父/兄长**，洛伦为弟；兄弟对话用「还是偏莉亚」「这话在理」等 |
| 夫人/伯母「布菜」 | **改**；**仆役/侍女**上菜，夫人 **照孩** |
| 到客宅举高戏耍孩童 | **改**；**先与主人见礼**，再 **及腰间**搂子，不举高 |
| 长辈点破「别装大人」 | **改**；**笑而不戳破**，读者自见 |
| bible 缩略语入正文（「照孩」「侧写」等） | **改** 日常说法或动作对话 |
| 照办纲要/场次表/技法要点写正文 | **删**；只留场景与对话，初稿即正文 |
| 用户说「全文」却改了其他章 drafts | **撤销**；默认只改**当前章**，他章须点名 |
| 对话干巴巴、无语气词、全员一个调 | **改** 口语化，分角色口癖 |
| 作者说明式「——因为……」 | **删**；只写动作与场面 |
| 「马厫」等生僻词 | **改**「马厩」等常见说法，或写清所指 |
| 「序章那晚」「上一章」 | **删**；改「几日前」「打从…那天起」等「我」内时间 |
| 附块内 `**` 强调专名 | 正文/附块均**不加符号** |
| 「男忆闪过」 | **「前世的我」** |
| 「竟想耍赖」等成人化心理词 | 幼女能懂的白话（如想坐地上等人哄） |
| 百科段科普魔法 | 融入场景或【附】 |
| 笼统「不像前世」 | 删，或换具体落点对照 |
