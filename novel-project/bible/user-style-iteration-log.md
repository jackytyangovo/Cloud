## Agent 执行清单（每次用户指定修改后）

1. **只改**用户点名的句段/功能；不顺带润色他处
2. 在本文件 **改动日志** 追加一条（改前/改后/提炼）
3. 若用户要求同步预览：`build_standalone.py` + push
4. **定稿 pass 未结束前** 不擅自把「提炼」写入 style-guide（除非用户说「先入库这条」）
5. pass 结束时：完成 **汇总分析** → 用户确认 → 整合进规范并标 **✓ 用户文风 · 高优先级**
