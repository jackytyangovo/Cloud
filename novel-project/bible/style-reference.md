## 一、核心文风特征

### 1. 开篇：总结 + 反讽

- 用**时间跨度一句收束**（「满打满算十五个年头」）→ 立刻转折打脸读者预期。
- 先写「理应怎样」（美少女、帝王生活）→ 再写「实际怎样」→ 形成落差。
- **可借鉴**：卷一可用类似结构——先写「六岁觉醒本该怎样」，再写莉莉娅内心的错位与不安（不必抄句式）。

### 2. 叙述语气：平直里的苦

- 句子不华丽，但**情绪密度高**；幽默是冷的、自嘲的（「少年妄想」「我就是个笑话」）。
- 常用**短判词句**收束段落（「简言之」「也就是说」「正因如此」）。
- **可借鉴**：莉莉娅有前世 25 岁男性记忆，可用**成熟内心的冷幽默**对照幼女外表，与样章自嘲同源。

### 3. 结构：列举与分条

- 重大信息用**「其一、其二、其三」**或分条列出，读者一眼抓住。
- 回忆按**年龄节点**推进（四岁、九岁、十岁…），时间清晰。
- **可借鉴**：身份、家族、天赋规则可用分条嵌入回忆或对话，避免说明文。

### 4. 心理描写：不粉饰、承认跑题

- 内心**直白**写出不适、嫉妒、羞耻、错位，不强行「正能量」。
- 叙述者**自知跑题**并拉回（「有点跑题了」）→ 像真人思绪，降低说教感。
- **性别认知**：客观知自己是女，主观仍残留男性习惯——与莉莉娅设定高度相关，可重点借鉴。
- **可借鉴**：第三人称写法改为「她心想」「她很清楚那是……」；跑题感可用思绪自然跳跃呈现。

### 5. 对话：少而准

- 大段以叙述与心理为主；**对话占比低**，出现时多为家庭日常、关键一句。
- 母亲摸头夸奖等**小动作 + 短对话**即可传达关系。
- **可借鉴**：莱恩菲尔家场景不必话多；洛伦宠溺、盖伦一家来访，用少量对话 + 神态足够。

### 6. 环境 / 身体感受：贴情绪

- **饥饿、寒冷、火**等感受具体写在身体里（「袭进每一处血管」），不是空洞形容词。
- 环境变化（茅草屋顶、修缮后的房子、废墟火焰）**对应命运转折**。
- **可借鉴**：领地晨景、灰谷赴城、仪式场地——写出光线、温度、气味，服务情绪而非纯装饰。

### 7. 世界观：从个人经历长出

- 禁止饮酒、女性歧视、学费、阿塔姆（大学）等，全由**「我遇到过」**带出，无百科块。
- **可借鉴**：觉醒仪式、净阶、贵族门槛等，经莉莉娅眼睛与前世对比自然露出。

### 8. 悲剧与 R18（日常向）：克制直白

- 苦难、死亡、情欲窥探（视线、内衣、摩擦声）写**事实与感受**，不煽情堆砌，不猎奇渲染。
- 羞辱与创伤 **understatement**（「很想哭，却哭不出来」「默不作声地把衣服洗好」）。
- **可借鉴**：暗黑或暧昧日常仍用**平直、有因果**笔法；卷一前期以童年主线为主。

### 8b. R18 亲密场景笔法（用户第二段样章 · 见下节第七节）

- 与日常样章同源：**心理 > 肉体堆砌**；男转女身份冲突须贯穿。
- 正文不落库露骨原文，仅保留笔法条目。

### 9. 节奏与章末

- 段落偏长，**逗号串联的回忆推进**；关键处用短句刹车。
- 章末可落在**意象**（火焰、祈祷）或**情绪余韵**，不一定是动作悬念。
- **可借鉴**：与 `style-guide`「章末悬念」并用——可悬念，可余韵，视章节而定。

## 三、推荐句型模式（仿风格，非原文）

以下为**原创示例句**，仅演示节奏，禁止当作正文照抄：

**反讽开篇**  
> 再过一个月就是觉醒仪式。照理说，六岁、贵族之女、父亲宠溺——人生该从这一步开始变得轻松吧。莉莉娅很清楚，那只是没出过领地的人才会有的想法。

**分条总结**  
> 她能在心里把处境收成三条：前世是男人；这一世是女孩；而一个月后，整个王国都会来读她的天赋。

**性别错位**  
> 她知道自己是女儿身，可当洛伦把她抱到膝上时，身体记得被疼爱的温度，记忆里却有个更年长的男人在说：这不对。

**克制悲剧**  
> 火盆烧起来了。她看着，没有哭。领地里的冬天一向冷，她早就学会先把眼泪省掉。

**世界观嵌入**  
> 觉醒要花钱吗？不用。但结果要命——书上这么写，父亲从没当她的面说过。

## 四、写作时 DO / DON'T

### DO

- 用**具体感受**（冷、饿、羞、紧）代替空泛「很难过」
- 让前世记忆**自然打断**现世叙述
- 用**列举、年龄节点**理清信息
- 世界观从**规矩落在身上**的角度写（不能饮酒 → 女性枷锁）
- 保持**句子可读**：偏口语化书面语，不骈俪、不网文腔滥爽

### DON'T

- 不要大段旁白科普设定
- 不要一上来就龙傲天或全员宠溺台词
- 不要心理全是口号式励志
- 不要照抄样章情节（农户、轮椅、婚约等）
- 不要因 R18 就突然浮夸描写；仍服从「服务剧情、平直克制」

## 七、R18 亲密场景笔法参考（用户样章二）

> 基于用户提供的成人向样章提炼**写法**，**不收录原文**。  
> **时间约束**：莉莉娅卷一开局 6 岁，此类场景须在剧情年龄与情节成熟后书写；`outline.md` 定稿前不预设具体章节。

### 7.1 场景功能（先问为什么写）

样章中亲密戏**不是孤立福利**，同时承担：

| 功能 | 表现 |
|------|------|
| 性别认同 | 「仍想当帅气骑士 / 心底有男子气概」vs 女性身体敏感 |
| 身体例外 | 局部失去知觉 vs 私处仍有感受 → **错位感**（本作可换设定，学的是对比结构） |
| 自我说服 | 「只是舒缓压力」「绝对不是喜欢」→ 内心抗拒与身体反应的矛盾 |
| 事后羞耻 | 「下次不能再做了」「会回不去」→ 角色弧与禁忌感 |
| 世界观 | 女性只许穿裙、裤子属男性等，在更衣环节自然带出 |

**本作**：亲密场景须绑定莉莉娅的**男转女心理**与剧情压力，禁止无铺垫插入。

### 7.2 结构节奏（可复用模板）

```
1. 日常切入（洗浴、更衣、独处）
2. 服装 / 身体镜像 → 触发性别抵触或自嘲
3. 正当化内心独白（自言自语，带引号）
4. 动作递进（慢 → 快），穿插呼吸、声音、触感
5. 前世男性经验对比（「作男生时没有这种感觉」）
6. 失控节点（忍不住出声、担心被听见）
7. 高潮后乏力与意识飘散
8. 自责式收尾（禁令 + 「可是……」悬留）
```

### 7.3 语言与感官

| 维度 | 样章特征 | 本作（第三人称）改写 |
|------|----------|----------------------|
| 词汇 | 直白生理词，不隐喻堆砌 | 保持直白，但经「她感到 / 她听见」过滤 |
| 对话 | 几乎只有**自言自语** | 保留少量内心引语，可不读出唇 |
| 听觉 | 水声、呼吸、隔壁可能被听见 | 环境音参与紧张感 |
| 触觉 | 冷墙 vs 胸口燥热；局部无感 vs 局部过敏 | 温度对比、身体局部例外 |
| 视觉 | 镜子、裙长、曲线（与「不想被看见」绑定） | 服饰描写服务**身份焦虑**，非纯凝视 |

### 7.4 男转女核心句型（原创示例，非原文）

> 她对着镜子拉平裙摆，心里想的却是别种装束。二十五岁的那个男人从未为一条裙子费过心思，可这具身体却记得蕾丝边蹭过膝盖的痒。

> 「……只是解压。」她听见自己这么说，像说服另一个还留在前世的自己。

> 快感涌上来时，她恨的却不是快感本身，而是这具身体居然如此诚实。

### 7.5 DO / DON'T（R18 专条）

**DO**

- 场景前用**日常动作**落地（沐浴、换衣、独处）
- 始终维持**心理抗拒 ↔ 身体反应**张力
- 用**前世男性经验**作对照（莉莉娅 25 岁男忆）
- 写**事后心理**（羞耻、禁令、悬而未决）
- 平直叙述，不突然切换华丽文言或网文滥叫

**DON'T**

- 不要脱离角色的性别认同戏（纯肉体无心理）
- 不要无剧情压力的孤立福利段
- 不要在 `outline` 未标注的年龄阶段强行书写
- 不要照抄样章设定（石化、轮椅、骑士婚约等）
- 不要在 bible 中粘贴露骨正文全文

### 7.6 与 style-guide 的衔接

- R18 允许，仍服从 **平直简单** 与 **四层兼顾**（动作、神态、环境、心理）
- 亲密场景中**环境**（墙冷、房间静、隔壁）参与紧张
- 具体章节是否写、写到何种尺度 → 用户定稿后写入 `outline.md` 对应节拍，标 `【R18】`
